# 모델 라우팅을 비용 절감 프리미티브로

> 동적 브로커가 모든 요청 (작업 유형, 토큰 길이, 임베딩 유사성, 신뢰도)을 평가하고 단순한 쿼리를 저렴한 모델에 보내고 복잡한 것을 프론티어 모델로 에스컬레이션합니다. 모델 캐스케이드라고도 합니다. 프로덕션 사례 연구는 US/UK/EU 배포에서_iso-품질에서 20-60% 비용 절감을 보여줍니다; 대규모 SaaS에서 30% 라우팅 효율성 개선은 six-figure 연간 절감으로 이어집니다. 2026년 맥락은 LLM 추론 가격이 매년 ~10x 하락했다는 것입니다 — GPT-4급 토큰은 2022년 후반부터 2026년까지 ~$20/M에서 ~$0.40/M으로 하락했습니다. 대부분의 하락은 더 나은 서비스 스택 (Phase 17 · 04-09)이지 하드웨어가 아닙니다. 라우팅은 제품 회귀 없이 그 가격 하락을 마진으로 전환하는 방법입니다. 실패 모드는 저렴한 모델 드리프트입니다: 경로가 40%를 더 약한 모델로 밀어붙이고, 품질이 추론 작업에서 3-5% 하락하며, 아무도 분기 동안 notices하지 않습니다. 온라인 품질 메트릭으로 경로를 게이트하고 오프라인 평가 집합만으로는 아닙니다.

**유형:** 학습
**언어:** Python (stdlib, toy 캐스케이딩 라우터 시뮬레이터)
**선수 과목:** Phase 17 · 01 (Managed LLM Platforms), Phase 17 · 19 (AI Gateways)
**소요 시간:** ~60분

## 학습 목표

- 모델 캐스케이딩을 설명합니다: 저렴한 우선 + 신뢰도 확인, 낮은 신뢰도에서 에스컬레이션.
- 네 가지 라우팅 신호를 열거합니다 (작업 분류, 프롬프트 길이, 알려진-어려운 집합에 대한 임베딩 유사성, 첫 번째 패스의 자체 신뢰도).
- 목표 라우팅 분할 및 품질 손실 허용 범위에서 예상 혼합 비용을 계산합니다.
- 저렴한 모델 크리프를 잡는 드리프트 모니터링 메트릭 (온라인 품질 게이트)을 이름 짓습니다.

## 문제

GPT-5에서 서비스 비용이 $80k/월입니다. 분석에 따르면 쿼리의 70%는 단순합니다: "파리에 몇 시입니까?" "이 문장을 다시 표현하세요." Haiku 클래스 모델이 3% 비용으로 Perfect하게 처리합니다. 30%는 GPT-5의 추론이 필요합니다 — 코딩, 수학, 멀티스텝 계획.

70%를 저렴한 것으로, 30%를 비싼 것으로 라우팅하면 제품 품질이 동일하게 청구서가 ~65% 하락합니다. 이것이 라우팅입니다. 품질을 회귀하지 않고 브로커를 구축하는 것이 트릭입니다.

## 개념

### 네 가지 라우팅 신호

1. **작업 분류**: simple/complex/codegen/math/chat. 규칙 기반 분류기, 작은 LLM (Haiku 클래스 $0.25/M), 또는 레이블이 있는 버킷에 대한 임베딩 유사성일 수 있습니다. 출력: route = cheap / balanced / frontier.

2. **프롬프트 길이**: >4K 토큰 프롬프트는 종종 일관성을 위해 프론티어가 필요합니다. <500 토큰 프롬프트는通常 필요하지 않습니다.

3. **알려진-어려운 집합에 대한 임베딩 유사성**: 쿼리가 알려진-어려운 버킷에 가깝다면 (코사인 > 0.88), 직접 프론티어로 에스컬레이션합니다.

4. **첫 번째 패스의 자체 신뢰도**: 저렴한 것으로 보냅니다; 모델의 로그 확률이 낮은 신뢰도 OR 거절 OR 헤지 언어 출력을 보여주면 프론티어에서 재시도합니다. ~10% 트래픽에서 P95 지연 시간이 추가되지만 다른 90%에서 50%+를 절약합니다.

### 세 가지 패턴

**사전 라우트** (앞쪽 분류기): ~5-10ms 추가 지연 시간; 전체적으로 가장 빠름.

**캐스케이드** (저렴한 우선, 낮은 신뢰도에서 에스컬레이션): ~1.2x 중앙값 지연 시간 (저렴한 실행 plus 확인), 에스컬레이션된 ~2x (~10% 트래픽). 최상의 품질 플로어.

**앙상블 라우트** (샘플에서 저렴하고 프론티어를 병렬 실행, 보상 모델이 선택): 최고 품질, 최고 비용; 중요한 A/B에만 사용.

### 구현

AI 게이트웨이 (Phase 17 · 19)가 라우팅을 노출합니다. LiteLLM은 폴백 및 비용 라우팅이 있는 `router` 구성을 가집니다. Portkey는 가드 + 라우팅을 가집니다. Kong AI Gateway는 플러그인 기반 라우팅을 가집니다. OpenRouter의 모델 마켓플레이스가 권장 API를 노출합니다.

오픈소스: RouteLLM (LMSYS), Not Diamond (상업용), Prompt Mule.

### 2026년 가격 곡선

| 모델 클래스 | 2022년 후반 | 2026년 | 변경 |
|-------------|-----------|--------|--------|
| GPT-4급 품질 | ~$20/M | ~$0.40/M | 50x 저렴 |
| 프론티어 (GPT-5, Claude 4) | — | ~$3-10/M | 새로운 등급 |

개선의 대부분은 서비스 효율성 — Phase 17 · 04-09의 핵심 레슨이 공급업체 측 비용下跌로 전환되었습니다. 라우팅을 사용하면 모든 사용자가 저렴한 등급으로 마이그레이션할 때까지 기다리는 대신 앱 레이어에서 Those gains를 포착할 수 있습니다.

### 드리프트가 진정한 위험입니다

경로가 40%를 저렴한 모델로 보냅니다. 6개월 동안 작업 분포가 이동합니다 (사용자가 더 정교해지고, 더 긴 질문을 합니다). 라우터가 notices하지 않습니다 — 분류기가 Q1 데이터에서 훈련되었기 때문입니다. 품질이 자동으로 하락합니다. 불만받는 사람이 충분하지 않습니다. 경쟁 벤치마크에서 졌음을發現합니다.

온라인 품질 메트릭으로 경로를 게이트합니다:

- 경로별 사용자 엄지 첵업 / 엄지 아래.
- 샘플된 추출물에서 자동 LLM 판사 (~5%).
- 에스컬레이션율: 캐스케이드가 >30%에서 up-route하는 경우 저렴한 모델이 over-routed되고 있습니다.
- 경로별 거절율.

### 기억해야 할 숫자

-_iso-품질에서 2026년 라우팅 절감: 20-60% 사례 연구.
- 2022-2026 LLM 가격 하락: 매년 ~10x 집계.
- 2022년 대 2026년 GPT-4급: ~$20/M → ~$0.40/M.
- 캐스케이드 지연 시간 영향: 중앙값 ~1.2x, 에스컬레이션된 ~2x (~10% 트래픽).

## 활용

`code/main.py`는 혼합 작업에서 사전 라우트, 캐스케이드, 앙상블을 시뮬레이션합니다. 혼합 비용, 품질 손실, 에스컬레이션율을 보고합니다.

## 연습문제

1. `code/main.py`를 실행하세요. 어느 정확도 플로어에서 캐스케이드가 사전 라우트를 이깁니까?
2. 사용자 기반이 30% 기업 (복잡한 쿼리), 70% 무료 등급 (단순 쿼리)입니다. 라우팅 분할을 디자인하세요. 어떤 온라인 메트릭이 그것을 게이트합니까?
3. 경로가 품질을 2% 하락시키지만 40%를 절약합니다. 그것을 shipping합니까? 제품에 따라 다릅니다 — 양쪽 주장하세요.
4. OpenAI / Anthropic API의 로그 확률을 사용하여 신뢰도 검사를 구현하세요. 어떤 임계값으로 시작합니까?
5. 6개월 동안 에스컬레이션율이 8%에서 22%로 상승합니다. 세 가지 원인을 진단하고 각각에 대한 수정을 설명하세요.
