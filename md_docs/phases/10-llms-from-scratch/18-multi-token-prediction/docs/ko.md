# 다중 토큰 예측 (MTP)

> GPT-2부터 Llama 3까지 모든 자기회귀 LLM은 위치당 하나의 손실로 학습됩니다: 다음 토큰을 예측합니다. DeepSeek-V3는 위치당 두 번째 손실을 추가했습니다: 그 다음 토큰을 예측합니다. 추가된 14B 파라미터(671B 모델 기준)는 그래디언트 흐름을 통해 주 모델로 증류되었고, 학습된 MTP 헤드는 추론에서 80% 이상의 수락률을 가진 추측적 디코딩 초안자로 재사용되었습니다. 1.8배의 생성 처리량이 공짜로 따라왔습니다. 이 과는 DeepSeek 기술 보고서의 순차적 MTP 모듈을 구축하고, 손실과 공유 헤드 파라미터 레이아웃을 계산하며, Gloeckle et al.의 원래 병렬 MTP가 인과 사슬을 깨뜨린 반면 MTP가 왜 인과 사슬을 유지하는지 설명합니다.

**유형:** 구축
**언어:** Python (stdlib)
**사전 필요과목:** 10단계 04과 (미니 GPT 사전학습), 10단계 15과 (추측적 디코딩)
**시간:** ~60분

## 학습 목표

- MTP 학습 목적을 설명하고 예측 깊이에 따른 결합 손실을 유도할 수 있다
- Gloeckle et al.의 병렬 MTP 헤드(2024)와 DeepSeek-V3의 순차적 MTP 모듈의 차이점과 순차적 설계가 인과 사슬을 보존하는 이유를 설명할 수 있다
- 사전학습 실행에 MTP 모듈을 추가할 때의 파라미터 및 메모리 오버헤드를 계산할 수 있다
- 하나의 MTP 모듈(공유 임베딩, 깊이별 트랜스포머 블록, 투영, 공유 출력 헤드)을 처음부터 구현할 수 있다

## 문제

다음-토큰 예측은 표준 LLM 학습 목적입니다. 모든 은닉 상태는 정확히 한 가지를 예측하도록 지도됩니다: 바로 다음에 오는 토큰. 이것은 놀라울 정도로 약한 신호입니다. 시퀀스의 대부분 정보는 하나의 토큰을 넘어 확장됩니다 — 구조, 일관성, 사실성, 산술적 흐름. 모델은 수조 개의 토큰에 걸쳐 많은 단일-토큰 신호를 축적하여 이를 학습해야 합니다.

MTP는 질문합니다: 모든 은닉 상태가 한 번에 여러 미래 토큰을 예측하도록 지도된다면 어떨까? Gloeckle et al. (Meta, 2024)은 이것이 도움이 된다는 것을 보여주었습니다. 그들의 구현은 백본 위에 여러 개의 독립적인 출력 헤드를 배치했으며, 각각 다른 오프셋을 예측했습니다. 병렬적이고 간단하지만, 헤드는 계층적 개선 없이 동일한 은닉 상태를 보았고 — 예측이 인과적으로 연결되지 않아 추측적 디코딩에 사용할 수 없었습니다.

DeepSeek-V3 (2024년 12월)는 MTP를 각 예측 깊이에서 인과 사슬을 유지하는 순차적 모듈로 재설계했습니다. 모델은 `h_i^(0)`에서 `t+1`을 예측하고, `h_i^(0)`과 `E(t+1)` 임베딩을 결합한 새로운 은닉 상태 `h_i^(1)`에서 `t+2`를 예측하는 식입니다. 각 깊이는 자체의 작은 트랜스포머 블록입니다. 공유 임베딩과 공유 출력 헤드는 파라미터 오버헤드를 적당하게 유지합니다. DeepSeek-V3의 규모에서 671B 주 모델 가중치 위에 MTP 모듈에 걸쳐 14B의 추가 파라미터. 그 2% 오버헤드가 더 조밀한 학습 신호와 추론에서 즉시 사용 가능한 추측적 디코딩 초안을 모두 제공했습니다.

이 과는 단일 MTP 모듈과 D-깊이 손실을 처음부터 구축합니다. 수학은 깔끔합니다. 구현은 150줄입니다.

## 개념

### 순차적 MTP 레시피

DeepSeek-V3는 주 모델 위에 `D`개의 MTP 모듈을 추가합니다. 각 모듈 `k` (`k = 1..D`)는 깊이 `k`의 토큰, 즉 위치 `i`까지의 프리픽스가 주어졌을 때 `t_{i+k}`를 예측합니다.

모듈 `k`는 다음으로 구성됩니다:

- 자체 어텐션과 MLP를 가진 트랜스포머 블록 `T_k`.
- 이전 깊이의 은닉 상태와 다음 깊이의 정답 토큰 임베딩을 결합하는 투영 행렬 `M_k`.
- 공유 임베딩 `E` (주 모델과 동일).
- 공유 출력 헤드 `Out` (주 모델과 동일).

학습 시, 위치 `i`까지의 프리픽스에 대해 깊이별 은닉 상태는:

```
h_i^(0) = 주 모델 백본의 위치 i에서의 출력
h_i^(k) = T_k( M_k * concat(RMSNorm(h_i^(k-1)), RMSNorm(E(t_{i+k}))) )   for k >= 1
```

깊이별 예측은:

```
logits_{i+k} = Out(h_i^(k-1))   for k = 1..D
```

깊이별 손실은 정답 `t_{i+k}`에 대한 교차 엔트로피:

```
L_k = CE(logits_{i+k}, t_{i+k})
```

깊이에 따른 결합 손실:

```
L_MTP = (lambda / D) * sum_{k=1..D} L_k
```

`lambda`는 작은 가중치 계수입니다 — DeepSeek-V3는 학습 초기 10% 동안 0.3을 사용하고 이후 0.1을 사용합니다. 총 학습 손실은 `L_main + L_MTP`입니다.

### 왜 순차적이지, 병렬이 아닌가

Gloeckle의 원래 병렬 MTP는 D개의 출력 헤드를 가졌으며, 각각이 `h_i^(0)`에 직접 적용되었습니다. 각 헤드는 동일한 백본 은닉 상태에서 `t_{i+k}`를 예측합니다. 학습은 잘 되지만, 예측이 서로 조건화되지 않습니다. `head_1`의 출력을 `head_2`를 돕는 데 사용할 수 없습니다 — 헤드는 병렬로 실행됩니다.

DeepSeek-V3의 순차적 설계는 `h_i^(k)`를 `h_i^(k-1)`에 실제 다음-토큰 임베딩 `E(t_{i+k})`를 더하여 구축합니다. 이는 인과 사슬을 보존합니다: `t_{i+k+1}`을 예측하기 위해 깊이 `k+1`의 모듈은 `t_{i+k}`에 무엇이 있었는지 봅니다. 이는 구조적으로 자기회귀 디코더가 자신의 출력을 소비하는 방식과 동일합니다 — 따라서 MTP 모듈을 추측적 디코딩 초안자로 직접 사용할 수 있습니다.

추론 시: `h_i^(k-1)`과 초안 작성된 `t_{i+k}`를 모듈 `k+1`에 넣고 `t_{i+k+1}`에 대한 예측을 얻습니다. 반복합니다. 이것은 정확히 EAGLE 스타일의 초안으로, 학습된 MTP 모듈을 초안 네트워크로 사용합니다. DeepSeek-V3는 첫 번째 MTP 모듈에서 80% 이상의 수락률과 약 1.8배의 속도 향상을 보고합니다.

### 파라미터 계산

은닉 `h`와 어휘 `V`를 가진 모델의 경우:

- 주 모델: 수십억 파라미터, 크기 `V * h`의 출력 헤드 하나.
- 공유 출력 헤드: 주 모델의 헤드 재사용. 추가 파라미터 없음.
- 공유 임베딩: 주 모델의 임베딩 재사용. 추가 파라미터 없음.
- MTP 모듈당:
  - 투영 `M_k`: `(2h) * h = 2h^2`.
  - 트랜스포머 블록 `T_k`: 어텐션 (MHA의 경우 `4h^2`) + MLP (비율 8/3의 SwiGLU의 경우 일반적으로 `8h^2`). 블록당 약 `12h^2`.

모듈당 총 추가: `~14h^2`. DeepSeek-V3의 `h = 7168`, D = 1 모듈: `~14 * 7168^2 = ~720M` 파라미터 (이론상). DeepSeek-V3는 14B를 보고합니다 — 차이는 주로 MTP 모듈의 전문가 층도 MoE이기 때문입니다.

### 추측적 디코딩의 이점

사전학습 중 MTP 모듈은 학습을 약 10% 느리게 합니다(더 많은 순전파 연산, 추가 손실). 이점은 두 가지입니다:

1. 더 조밀한 학습 신호. 각 은닉 상태가 D+1개의 지도 목표를 봅니다. MMLU, GSM8K, MATH, HumanEval에서 측정된 효과: DeepSeek-V3의 절제 연구에서 일관된 몇 퍼센트 포인트 개선.

2. 추론에서 무료 추측적 디코딩 초안. MTP 모듈은 이미 다음 몇 개 토큰을 예측하도록 학습되었습니다. 초안 네트워크로 재사용될 때 80% 이상의 수락률을 제공합니다. 그 수준에서 N=3 또는 N=5 사양 디코딩은 1.8배의 처리량을 제공합니다. 10%의 학습 시간 비용은 추론을 처음 실행할 때 회수됩니다.

### EAGLE과의 관계

EAGLE은 사전학습 후에 작은 초안 모델을 별도로 학습합니다. MTP는 초안을 사전학습에 내장합니다. 두 접근법은 유사한 수락률에 수렴하지만 다른 파이프라인을 통해:

| 차원 | EAGLE-3 | MTP (DeepSeek-V3) |
|-----------|---------|------------------|
| 학습 시점 | 사전학습 후 | 사전학습 중 |
| 기존 가중치와 역호환 | 예 | 아니오 (재학습 필요) |
| 초안 파라미터 | 1-2개 트랜스포머 층 | 1개 트랜스포머 블록 + 투영 |
| 수락률 | 0.88-0.92 | 깊이 1에서 0.80+ |
| 속도 향상 외 이점 | 추측적 디코딩만 | 더 조밀한 학습 신호 + 속도 향상 |

## 직접 구현하기

`code/main.py`는 단일 MTP 모듈을 종단간 구축합니다: 공유 임베딩, 투영, 트랜스포머 블록, 공유 출력 헤드. 그런 다음 짧은 합성 시퀀스에서 깊이별 교차 엔트로피 손실을 계산하고 구성 요소별 파라미터 수를 출력합니다. 32개 토큰의 장난감 어휘는 숫자를 읽기 쉽게 유지합니다.

### 1단계: 공유 임베딩 테이블

단일 `vocab_size x hidden` 테이블이 주 모델과 모든 MTP 모듈의 모든 깊이에서 사용됩니다. 두 번째 복사본이 아닙니다 — 말 그대로 동일한 텐서입니다.

### 2단계: 깊이별 결합

```python
def combine(prev_hidden, next_token_embed, M_k):
    concat = rms_norm(prev_hidden) + rms_norm(next_token_embed)
    projected = matvec(M_k, concat)
    return projected
```

실제 DeepSeek-V3는 두 개의 RMSNorm된 벡터를 `[2h]`로 연결하고 `h x 2h` 행렬로 투영합니다. 장난감은 stdlib 간결성을 위해 벡터 덧셈을 사용합니다.

### 3단계: 깊이 k의 트랜스포머 블록

자기-어텐션 + MLP. 장난감에서는 1층 선형 어텐션 블록과 SwiGLU MLP가 numpy 없이도 구조를 보이게 합니다.

### 4단계: 공유 출력 헤드

주 모델의 출력 투영을 재사용합니다. 어휘에 대한 로짓.

### 5단계: 깊이별 손실

오프셋 `k`에서 정답 토큰에 대한 softmax(로짓)의 교차 엔트로피. `lambda / D` 스케일링 계수로 깊이에 걸쳐 집계합니다.

### 6단계: 파라미터 계산

총 파라미터 수, 공유(임베딩, 헤드) 수, 모듈당 추가 수를 출력합니다. MTP 추가 대비 주 모델 크기의 비율을 보여줍니다.

## 활용하기

MTP는 DeepSeek-V3 (2024년 12월)와 DeepSeek-R1 시리즈에 통합되어 있습니다. 추론 시:

- DeepSeek 자체 서빙 스택은 MTP 모듈을 즉시 추측적 디코더로 소비합니다.
- vLLM과 SGLang은 2026년 4월 기준 DeepSeek-V3 MTP를 위한 통합 경로를 가지고 있습니다.
- AMD의 ROCm SGLang 튜토리얼은 V3 체크포인트에서 측정된 1.8배 속도 향상과 함께 특정 MTP 추측적 디코딩 설정을 보여줍니다.

새로운 사전학습 실행에서 MTP를 사용해야 할 때:

- 전체 사전학습 파이프라인을 제어하고 더 조밀한 학습 신호를 얻고자 할 때.
- 모델을 대규모로 서빙할 것을 알고 추측적 디코딩을 공짜로 원할 때.
- 은닉 크기가 최소 4096 이상일 때. 1B 규모에서는 오버헤드가 이득보다 더 큽니다.

사용하지 말아야 할 때:

- 기존 사전 학습된 밀집 모델을 미세 조정할 때. MTP 모듈이 학습되지 않았습니다.
- 비교할 깨끗한 기준선을 원하는 연구 모델. MTP는 아키텍처를 변경합니다.

## 연습 문제

1. `code/main.py`를 실행하십시오. 합성 신호가 강해짐에 따라 깊이별 손실이 단조 감소함을 보이십시오. 고정 패턴을 사용하도록 합성을 수정하고 깊이-1과 깊이-2 손실이 모두 수렴하는지 확인하십시오.

2. D=1 MTP 모듈을 가진 밀집 70B 모델(hidden 8192, 80개 층)의 파라미터 오버헤드를 계산하십시오. DeepSeek-V3의 보고된 14B 오버헤드와 비교하십시오. DeepSeek의 숫자가 더 높은 이유를 설명하십시오: MTP 트랜스포머 블록이 동일한 MoE 구조를 상속하여 모듈당 파라미터 수가 증가합니다.

3. 장난감에서 D=2를 구현하십시오: h^(1)을 입력받아 `t_{i+2}`를 예측하는 두 번째 MTP 모듈을 추가하십시오. 결합 손실과 파라미터 계산이 DeepSeek 논문의 방정식 19-21과 일치하는지 확인하십시오.

4. 장난감을 병렬 MTP(Gloeckle 스타일)로 전환하십시오: 주 은닉 상태 위에 D개의 출력 헤드를 추가하고 각각 다른 오프셋을 예측합니다. 동일한 합성 신호에서 깊이별 손실이 순차적 버전과 어떻게 비교되는지 측정하십시오. 순차적 버전은 k > 1에 대해 더 낮은 깊이-k 손실을 생성해야 합니다. 중간 예측에 조건화되기 때문입니다.

5. 학습된 MTP 모듈을 EAGLE 스타일 초안으로 사용하십시오: 모듈 k를 호출하여 추론에서 `t_{i+k}`를 제안합니다. 보류 시퀀스에서 주 모델의 예측 대비 이 초안 토큰의 수락률을 측정하십시오. 장난감에서 50% 이상을 달성하면 MTP-초안 특성을 경험적으로 재현한 것입니다.

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|-------------------|-----------|
| MTP 모듈 | "추가 손실 블록" | 주 모델보다 `k` 위치 앞선 토큰을 예측하는 작은 트랜스포머 블록 + 투영 |
| 예측 깊이 | "어느 오프셋" | 모듈 `k`가 위치 `i`까지의 프리픽스에서 `t_{i+k}`를 예측하는 정수 `k` |
| 병렬 MTP | "Gloeckle 스타일" | 동일한 백본 은닉 상태 위의 D개의 독립적 헤드, 조건부 사슬 없음 |
| 순차적 MTP | "DeepSeek-V3 스타일" | 각 모듈이 이전 깊이의 은닉 상태와 다음 토큰의 임베딩에 조건화됨; 인과 사슬 유지 |
| 공유 출력 헤드 | "주 헤드 재사용" | MTP 모듈이 주 모델의 LM 헤드를 호출, 별도의 출력 투영이 아님 |
| 공유 임베딩 | "주 테이블 재사용" | 동일한 어휘 임베딩 테이블이 모든 곳에서 사용됨; 중복 파라미터 없음 |
| 투영 행렬 M_k | "은닉 + 다음-토큰 결합" | 이전 은닉 상태와 대상-토큰 임베딩을 다음 깊이의 입력으로 접는 `h x 2h` 선형층 |
| 결합 손실 L_MTP | "평균화된 추가 손실" | 깊이별 교차 엔트로피 손실의 산술 평균, `lambda`로 스케일링 |
| 깊이 1 수락률 | "MTP 초안이 얼마나 자주 맞는지" | D=1 MTP 모듈의 top-1 예측이 주 모델의 top-1 예측과 일치하는 비율; DeepSeek-V3에서 80%+ |
| Lambda 가중치 | "추가 손실 중요도" | 깊이별 스케일링 계수; DeepSeek-V3에서 학습 초기 0.3, 이후 0.1 |
