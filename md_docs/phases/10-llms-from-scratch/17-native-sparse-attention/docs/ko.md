# Native Sparse Attention (DeepSeek NSA)

> 64k 토큰에서 어텐션은 디코드 지연 시간의 70-80%를 차지합니다. 모든 오픈 모델 연구소는 이를 해결할 계획을 가지고 있습니다. DeepSeek의 NSA(ACL 2025 최우수 논문)가 정착된 솔루션입니다: 압축된 조립(coarse-grained) 토큰, 선택적으로 유지된 정밀(fine-grained) 토큰, 지역 컨텍스트를 위한 슬라이딩 윈도우의 세 가지 병렬 어텐션 분기를 학습된 게이트를 통해 결합합니다. 하드웨어에 정렬되고(커널 친화적), 기본적으로 학습 가능하며(추론에 덧붙이는 것이 아니라 사전학습에서 작동), 64k 디코드에서 FlashAttention보다 빠르면서 전체 어텐션 품질과 일치하거나 능가합니다. 이 과는 세 가지 분기를 종단간 구축하고 희소성이 종단간 미분 가능한 이유를 보여줍니다.

**유형:** 구축
**언어:** Python (stdlib)
**사전 필요과목:** 7단계 12과 (KV 캐시, flash-attention), 7단계 15과 (어텐션 변형), 10단계 16과 (차등 어텐션)
**시간:** ~60분

## 학습 목표

- NSA의 세 가지 어텐션 분기와 각각이 포착하는 것을 설명할 수 있다
- NSA가 이전의 희소 어텐션 방법이 추론 전용이었던 반면 "기본적으로 학습 가능"한 이유를 설명할 수 있다
- 64k 컨텍스트에서 NSA 대 전체 어텐션의 어텐션 계산 절감량을 압축 블록 크기와 선택 top-k의 함수로 계산할 수 있다
- 짧은 합성 시퀀스에서 stdlib Python으로 세 분기 결합을 구현하고 게이팅 가중치가 제대로 작동하는지 확인할 수 있다

## 문제

시퀀스 길이 N에서 전체 어텐션은 층당 `O(N^2)` 시간과 `O(N)` KV 캐시가 필요합니다. 64k 토큰에서 연산 및 메모리 대역폭 수치는 치명적입니다. NSA 논문의 측정된 이론적 추정: 64k에서 어텐션은 총 디코드 지연 시간의 70-80%를 차지합니다. 모든 하류 요소(TTFT, 토큰/초, 백만 토큰당 비용)는 어텐션 비용에 의해 지배됩니다.

희소 어텐션은 명백한 답입니다. 이전 시도는 두 가지 범주에 속합니다. 고정 패턴 희소성(슬라이딩 윈도우, 스트라이드, 블록-로컬)은 정보를 버리고 장거리 회상 작업에서 실패합니다. 추론 시점 희소성(KV 캐시 정리, H2O, StreamingLLM)은 밀집 어텐션으로 사전 학습된 모델에 적용되며, 모델이 희소 패턴을 통해 정보를 라우팅하도록 요청받은 적이 없기 때문에 잠재적 속도 향상의 일부만 회복합니다.

Native Sparse Attention (Yuan et al., DeepSeek + PKU + UW, ACL 2025 최우수 논문, arXiv:2502.11089)은 둘 다 수행합니다: 모델이 사전학습 중에 학습하는 희소성 패턴으로, 추론에서 실제 연산 절감을 제공하는 커널 정렬 알고리즘으로 구현됩니다. 2년 후면 NSA 또는 그 직접적인 후손이 모든 프런티어 긴 컨텍스트 모델의 기본 어텐션이 될 것입니다.

## 개념

### 세 가지 병렬 분기

각 질의에 대해 NSA는 KV 캐시의 세 가지 다른 뷰에 대해 어텐션을 세 번 실행합니다:

1. **압축 분기.** 토큰은 크기 `l`(일반적으로 32 또는 64)의 블록으로 그룹화됩니다. 각 블록은 작은 학습된 MLP를 통해 단일 요약 토큰으로 압축됩니다. 질의는 이 압축된 토큰들에 대해 어텐션을 수행하여 전체 시퀀스의 조립된 뷰를 얻습니다.

2. **선택 분기.** 압축 분기의 어텐션 점수를 사용하여 현재 질의에 가장 관련성 높은 상위 k개 블록이 식별됩니다. 해당 블록의 정밀(비압축) 토큰이 읽혀지고 질의는 모든 토큰에 대해 어텐션을 수행합니다. 압축 분기 어텐션을 선택을 위한 라우팅 신호로 생각하십시오.

3. **슬라이딩 윈도우 분기.** 질의는 지역 컨텍스트를 위해 가장 최근 `W`개의 토큰(일반적으로 512)에 주목합니다. 이 분기는 다른 두 분기가 놓칠 수 있는 구조-중심의 단거리 패턴(구문, 지역 공지시)을 포착합니다.

세 분기 출력은 학습된 위치별 게이트를 통해 결합됩니다:

```
out = g_cmp * out_cmp + g_sel * out_sel + g_win * out_win
```

`g_cmp, g_sel, g_win`은 질의에 대한 작은 MLP의 게이트 가중치입니다. 합이 1일 필요는 없습니다 -- 분기별로 독립적으로 가중치를 부여할 수 있습니다.

### 이것이 "기본적으로 학습 가능한" 이유

선택 단계(top-k 블록)는 이산적입니다. 이산 연산은 그래디언트 흐름을 차단합니다. 이전 희소 어텐션 연구는 선택을 통한 역전파를 건너뛰거나(학습 제한) 추론에서 실제 희소성을 제공하지 않는 연속 완화를 사용했습니다.

NSA는 이를 우회합니다: 압축 분기 어텐션은 전체 시퀀스에 대한 미분 가능한 조립 어텐션입니다. top-k 연산은 압축 분기의 최상위 어텐션 점수를 재사용하여 어떤 정밀 블록을 로드할지 선택합니다. 그래디언트는 압축 분기 점수를 통해 흐르며(압축 출력과 선택 로직 모두에 영향), 선택된 블록의 최종 출력 기여도 또한 미분 가능합니다. 미분 불가능한 `top_k` 연산은 순전파 계산 그래프에서 no-op입니다 -- 메모리에서 어떤 블록을 로드할지만 제어합니다.

이것이 NSA가 종단간 사전학습에 사용될 수 있는 이유입니다. 모델은 세 분기를 통해 정보를 라우팅하는 법을 공동으로 학습하여, 추론에서 실제로 약속된 속도 향상을 제공하는 희소 패턴을 생성합니다.

### 하드웨어 정렬 커널

NSA의 커널은 현대 GPU 메모리 계층 구조에 맞게 설계되었습니다. 커널은 GQA 그룹별로 질의를 로드하고(외부 루프), 그룹별로 해당하는 희소 KV 블록을 가져오고(내부 루프), SRAM에서 어텐션을 실행합니다. 각 질의 그룹이 동일한 선택된 블록을 보기 때문에(선택은 질의-헤드별이 아닌 질의-그룹별), KV 로드는 그룹 전체에 상각됩니다. 산술 강도가 높게 유지됩니다.

논문은 Triton 커널이 64k 디코드에서 FlashAttention보다 9배 빠르며, 속도 향상 비율이 시퀀스 길이에 따라 증가한다고 보고합니다. 순전파 및 역전파 커널이 모두 제공됩니다.

### 연산 예산

`N`을 시퀀스 길이, `l`을 압축 블록 크기, `k`를 top-k 선택 수, `w`를 슬라이딩 윈도우, `b`를 선택된 블록 크기(일반적으로 `l`과 동일)라고 하겠습니다.

- 압축 분기: 질의당 `O(N/l)`개의 키, 총 `O(N * N / l)`.
- 선택 분기: 질의당 `O(k * b)`개의 키, 총 `O(N * k * b)`.
- 슬라이딩 분기: 질의당 `O(w)`개의 키, 총 `O(N * w)`.

합계: `O(N * (N/l + k*b + w))`.

`N = 64k, l = 64, k = 16, b = 64, w = 512`: 질의당 비용은 `1000 + 1024 + 512 = 2536`개의 키입니다. 전체 어텐션은 `64000`개의 키입니다. 25배 연산 감소.

`N = 128k, l = 64, k = 16, b = 64, w = 512`: 질의당 비용은 `2000 + 1024 + 512 = 3536`개의 키입니다. 전체 어텐션은 `128000`개의 키입니다. 36배 감소. 이점은 시퀀스 길이에 따라 증가하는데, 이것이 바로 핵심입니다.

### 비교

| 방법 | 미분 가능 | 실제 추론 속도 향상 | 장거리 회상 |
|--------|---------------|----------------------|-------------------|
| 슬라이딩 윈도우 전용 | 예 | 예 | 실패 |
| 스트라이드 / 블록-희소 | 예 | 예 | 부분적 |
| KV 정리 (H2O, StreamingLLM) | N/A (추론 시점) | 예 | 부분적 |
| MoBA (Moonshot) | 부분적 | 예 | 좋음 |
| NSA | 예 (기본적으로) | 예 (64k에서 9배) | 전체 어텐션과 일치 |

MoBA (Moonshot, arXiv:2502.13189)는 동시에 발표되었으며 유사한 세-개가-하나보다-낫다 접근법을 취하여 MoE 원리를 어텐션 블록에 적용합니다. NSA와 MoBA는 2026년 긴 컨텍스트 사전학습을 위해 알아야 할 두 가지 아키텍처입니다.

## 직접 구현하기

`code/main.py`는 짧은 합성 시퀀스에서 세 분기를 구현하고 다음을 보여줍니다:

- 압축 MLP (교육적 명확성을 위해 간단한 평균 풀링 기준선 사용; 실제 NSA는 학습된 MLP 사용).
- 압축 분기 점수로 구동되는 top-k 블록 선택.
- 마지막 `w`개 토큰에 대한 슬라이딩 윈도우 어텐션.
- 게이트된 결합.
- 전체 어텐션과 비교하는 연산 카운트 출력.

### 1단계: 토큰을 블록으로 압축

```python
def compress(K, l):
    n = len(K)
    n_blocks = (n + l - 1) // l
    out = []
    for b in range(n_blocks):
        start, end = b * l, min((b + 1) * l, n)
        block = K[start:end]
        summary = [sum(row[d] for row in block) / len(block) for d in range(len(K[0]))]
        out.append(summary)
    return out
```

### 2단계: 압축 분기 어텐션

압축된 키에 대해 질의의 소프트맥스 어텐션을 실행합니다. 압축 분기 점수는 top-k 선택을 위한 신호 역할도 합니다.

### 3단계: top-k 블록 선택

가장 높은 점수를 받은 `k`개의 압축 블록의 인덱스를 선택합니다. 해당 블록의 원래 비압축 토큰을 로드하고 어텐션을 실행합니다.

### 4단계: 슬라이딩 윈도우 어텐션

마지막 `w`개 토큰을 가져와 표준 어텐션을 실행합니다.

### 5단계: 게이트 + 결합

질의에 대한 작은 MLP가 세 개의 게이트 가중치를 생성합니다. 최종 출력은 세 분기 출력의 가중 합입니다.

### 6단계: 연산 카운팅

분기별로 질의당 어텐션을 수행한 키 수와 총합을 출력합니다. `N`(전체 어텐션)과 비교합니다. `l = 32, k = 4, w = 128`인 1024-토큰 합성에서 NSA는 질의당 `32 + 128 + 128 = 288`개의 키를 확인하는 반면 전체 어텐션은 1024개입니다 -- 3.5배 더 적습니다.

## 활용하기

NSA는 DeepSeek 자체의 긴 컨텍스트 사전학습 파이프라인에서 사용 중입니다. 2026년 4월 기준 공개 추론 스택의 통합 현황:

- **DeepSeek 내부**: 네이티브, 공개된 가중치는 NSA 또는 그 후속 DSA(Deepseek Sparse Attention) 사용.
- **vLLM**: DeepSeek-V3.x 가중치를 위한 실험적 NSA 지원 개발 중.
- **SGLang**: NSA 벤치마크 발표됨; 프로덕션 경로는 vLLM을 따름.
- **llama.cpp / CPU**: 지원되지 않음; 커널 분해의 오버헤드가 CPU 처리량에서 가치가 없음.

NSA를 사용해야 할 때:

- 상당한 연산 예산으로 64k 이상 컨텍스트를 목표로 하는 사전학습 또는 지속 학습 실행.
- DeepSeek 자체 긴 컨텍스트 체크포인트의 추론. 가중치는 NSA-네이티브.

사용하지 말아야 할 때:

- 기존 밀집 어텐션 사전 학습된 모델 서빙. 지속 학습 없이 NSA를 개조할 수 없음.
- 16k 미만 컨텍스트. 세 분기 오버헤드가 절감을 압도.
- 배치-1 대화형 채팅. 지연 시간에 민감한 디코드가 이점을 보지만 긴 컨텍스트에서만.

## 연습 문제

1. `code/main.py`를 1024-토큰 합성에서 실행하십시오. 세 가지 프리셋으로 `(l, k, w)`를 변화시키고 연산 횟수를 출력하십시오. needle-in-haystack 테스트에서 전체 어텐션 대비 95% 회상을 유지하면서 질의당 가장 낮은 키 수를 달성하는 프리셋을 식별하십시오.

2. 평균 풀링 압축기를 작은 학습된 MLP(2층, 은닉 32)로 대체하십시오. 신호가 블록의 평균인 합성 작업에서 학습시키십시오. 보류 데이터에서 평균 풀링 기준선 대비 퍼플렉서티 차이를 측정하십시오.

3. 게이트 MLP를 구현하십시오. 질의를 입력으로 받아 세 개의 스칼라를 출력합니다. 게이트가 합리적으로 동작함을 보이십시오: 무작위 질의에서는 거의 균일한 가중치, 먼 블록의 질의에서는 선택 분기에 높은 가중치.

4. NSA가 활성화된 70B 모델의 128k 컨텍스트에서 KV 캐시 메모리 예산을 계산하십시오. KV 헤드 8, 헤드 차원 128, BF16. 전체 어텐션 및 MLA와 비교하십시오(10단계 14과에서 MLA 수치를 보여줌). NSA의 정밀 분기 KV 캐시가 전체 어텐션과 같아지는 시퀀스 길이를 식별하십시오.

5. NSA 논문(arXiv:2502.11089)의 섹션 4를 읽고, 압축 분기의 어텐션 점수가 별도의 라우팅 점수를 계산하지 않고 top-k 선택에 재사용되는 이유를 세 문장으로 설명하십시오. 답을 그래디언트 흐름과 연결하십시오.

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|-------------------|-----------|
| 압축 분기 | "조립 뷰" | 블록 평균 키에 대한 어텐션으로, 질의당 O(N/l) 키로 전역 컨텍스트 제공 |
| 선택 분기 | "Top-k 블록" | 압축 분기 점수가 가장 높은 `k`개 블록에 대한 정밀 어텐션 |
| 슬라이딩 윈도우 | "지역 컨텍스트" | 단거리 패턴을 위한 마지막 `W`개 토큰에 대한 어텐션 |
| 기본 학습 가능성 | "희소성을 켠 상태로 사전학습" | 희소성 패턴이 추론에 덧붙이는 것이 아니라 사전학습 중에 학습됨 |
| 압축 블록 크기 l | "조립 뷰의 그룹 크기" | 여러 토큰이 하나의 요약으로 병합되는 크기; 일반적으로 32-64 |
| Top-k | "유지할 블록" | 비압축 토큰을 읽을 압축 블록의 수; 일반적으로 16 |
| 슬라이딩 윈도우 W | "지역 어텐션 반경" | 일반적으로 512; 더 짧으면 지역 응집력이 손상되고, 더 길면 연산 낭비 |
| 분기 게이트 | "세 가지를 혼합하는 방법" | 세 분기의 기여도에 가중치를 부여하는 위치별 MLP 출력 |
| 하드웨어 정렬 | "커널 친화적 희소성" | 실제 GPU 커널이 이론적 속도 향상을 달성하도록 선택된 희소 패턴 |
| DSA | "NSA의 후속" | Deepseek Sparse Attention, DeepSeek 계보에서 NSA를 따른 아키텍처 |
