# 추측적 디코딩과 EAGLE-3

> 7단계 16과에서 수학을 증명했습니다: Leviathan 기각 규칙은 검증기의 분포를 정확히 보존합니다. 이 과는 2026년 프로덕션 추측적 디코딩의 학습 스택 관점입니다. EAGLE-3는 초안 모델을 저렴한 근사치에서 검증기 자체의 은닉 상태로 학습된 목적 구축형 초소형 네트워크로 바꾸었고, 학습 분포와 추론 분포를 정렬하는 학습-시간 테스트 루프를 추가했습니다. 결과: 종단간 3배에서 6.5배 속도 향상, 채팅에서 토큰당 수락률 0.9 이상, 분포적 트레이드오프 없음. 2026년의 모든 프로덕션 추론 스택은 이를 기본으로 탑재합니다.

**유형:** 구축
**언어:** Python (stdlib)
**사전 필요과목:** 7단계 16과 (추측적 디코딩 수학), 10단계 12과 (추론 최적화)
**시간:** ~75분

## 학습 목표

- Leviathan 정리를 한 문장으로 기술하고 추측적 루프가 검증기와 동일하게 분포된 샘플을 생성함을 증명할 수 있다
- 바닐라 추측적 디코딩(Leviathan 2023)에서 EAGLE, EAGLE-2, EAGLE-3까지의 2년 발전 과정을 설명하고 각 단계에서 제거된 정확한 한계를 명명할 수 있다
- 수락률 `α`와 초안 대 검증기 비용 비율 `c`로부터 기대 속도 향상을 계산하고 각 영역에 대한 최적의 초안 길이 `N`을 선택할 수 있다
- 전체 추측적 루프(초안 작성, 검증, 잔차에서 기각 샘플링, KV 캐시 롤백, 완전 수락 시 보너스 토큰 방출)를 처음부터 구현할 수 있다

## 문제

70B 모델에서 자기회귀 디코딩은 H100에서 초당 약 35개 토큰으로 실행됩니다. GPU는 포화 상태와는 거리가 멉니다. 메모리 대역폭이 한계입니다: 모든 토큰이 70B의 가중치를 HBM에서 로드하고, 한 단계의 연산을 수행하고, 하나의 float을 생성합니다. 연산 유닛은 대부분 유휴 상태입니다.

추측적 디코딩은 이를 실제로 해결 가능한 처리량 문제로 바꿉니다. 저렴한 초안이 `N`번의 작은 순전파로 `N`개의 토큰을 제안합니다. 검증기는 프리픽스와 모든 `N`개의 초안에 대해 한 번 실행됩니다. 위치 `i`에서 검증기의 분포가 초안과 (통계적으로 정밀하게 만들 것임) 일치하면 수락하고, 그렇지 않으면 기각하고 잔차 분포에서 수정을 샘플링합니다. 단일 대형 모델 순전파가 하나 대신 최대 `N+1`개의 수락된 토큰을 생성합니다.

중요한 정리는 Leviathan, Kalman, Matias (ICML 2023)입니다: 출력 분포는 검증기에서 직접 샘플링한 것과 동일합니다. 근사가 아닙니다. 동일합니다. 이것이 추측적 디코딩이 프로덕션에서 허용되는 전체 이유입니다 -- 품질 트레이드오프 없이 순수한 지연 시간 최적화입니다.

7단계 16과가 제공한 것은 수학이었습니다. 이 과가 제공하는 것은 학습 스택입니다. 좋은 초안은 저렴한 초안보다 2배 더 큰 속도 향상을 가져옵니다. EAGLE, EAGLE-2, EAGLE-3 (Li et al., 2024–2025)는 "초안 = 동일 모델의 더 작은 버전"을 정밀한 엔지니어링 분야로 바꾸었습니다. 2026년 프로덕션 추론 서버는 기본적으로 EAGLE-3를 사용합니다.

## 개념

### 불변: Leviathan 기각 샘플링

`p(t)`를 어떤 프리픽스가 주어졌을 때 초안의 다음 토큰 분포, `q(t)`를 검증기의 분포라고 하겠습니다. 초안 토큰 `d ~ p`를 샘플링합니다. 확률 `min(1, q(d) / p(d))`로 수락합니다. 기각 시 잔차 분포 `(q - p)_+ / ||(q - p)_+||_1`에서 샘플링합니다. 결과 샘플은 `q`에 따라 분포됩니다. `p`가 아무리 나쁘더라도 이는 참입니다 -- 더 나쁠수록 더 자주 기각하지만, 출력은 정확합니다.

`prefix + d_1 + ... + d_N`에 대해 하나의 검증기 순전파를 사용하여 `N`개의 이러한 호출을 연속적으로 쌓습니다. 검증기는 `q_1, q_2, ..., q_{N+1}`을 동시에 반환합니다. 왼쪽에서 오른쪽으로 진행합니다. 위치 `j`에서 첫 번째 기각 시 `residual(q_j, p_j)`에서 샘플링하고 중단합니다. 완전 수락 시 `q_{N+1}`에서 보너스 토큰 하나를 샘플링합니다.

### 속도 향상을 결정하는 요소

`α`를 초안 토큰당 기대 수락률이라고 하겠습니다. `c = cost(초안) / cost(검증기)`를 비용 비율이라고 하겠습니다. 검증기 순전파당 기대 수락 토큰 수:

```
E[accepted] = (1 - α^(N+1)) / (1 - α)
```

수락된 토큰당 기대 총 벽시계 시간은 `(N * c + 1) / E[accepted]`입니다. 이를 `N`에 대해 최소화하면 최적점을 얻습니다. `α = 0.8, c = 0.05`일 때: 최적 `N`은 약 5–7, 속도 향상은 3.2배입니다. `α = 0.95, c = 0.02`일 때: 최적 `N`은 약 8–10, 속도 향상은 5배에 근접합니다.

가장 큰 단일 레버는 `α`입니다. 고정 `N = 5`에서 `α = 0.6`(바닐라 초안)에서 `α = 0.9`(EAGLE-3)로 가면 검증기 순전파당 기대 수락 토큰이 2.2에서 4.1로 증가합니다. 동일한 검증기에서 거의 2배의 처리량 향상입니다.

### 2년간의 발전

**바닐라 추측적 (Leviathan, 2023).** 초안 모델은 동일 패밀리에서 독립적으로 학습된 더 작은 LLM입니다. 연결이 쉽고, `α ≈ 0.6`, 속도 향상은 기껏해야 약 2배입니다.

**EAGLE-1 (Li et al., 2024).** 초안은 일반적으로 1~2개 층의 초소형 트랜스포머로, 검증기의 마지막 층 은닉 상태를 입력으로 받아 다음 토큰을 직접 예측합니다. 초안이 검증기의 특징 표현을 볼 수 있기 때문에 그 분포가 검증기에 훨씬 더 가깝습니다. `α`가 0.7–0.8로 상승합니다.

**EAGLE-2 (Li et al., 2024).** 동적 초안 트리를 추가합니다: 단일 시퀀스의 `N`개 토큰을 제안하는 대신, 작은 후보 트리를 제안하고, 각각을 하나의 순전파(트리 어텐션)로 검증기에서 평가하고, 가장 높은 확률의 경로를 따라갑니다. 초안 길이가 단계별로 적응적이 됩니다. 수락된 경로 토큰당 `α`가 0.85 이상으로 상승합니다.

**EAGLE-3 (Li et al., 2025, NeurIPS).** 두 가지 추가 변경. 첫째, 특징 예측 손실을 완전히 제거합니다 -- EAGLE-1/2는 초안이 검증기의 은닉 상태와 일치하도록 학습시켰는데, 이는 데이터가 도움이 되는 정도에 상한을 두었습니다. EAGLE-3는 토큰 예측에 직접 학습합니다. 둘째, 학습-시간 테스트(TTT): 초안 학습 중에 초안이 추론에서와 동일하게 여러 단계에 걸쳐 자신의 이전 예측을 입력으로 피드백합니다. 이는 학습 분포와 테스트 분포를 정렬하고 오류 누적을 막습니다. 측정된 속도 향상: 채팅에서 최대 6.5배, H100의 SGLang에서 배치 64 기준 처리량 38% 향상.

### KV 캐시 롤백

검증은 검증기의 KV 캐시를 한 번에 `N`개 항목만큼 확장합니다. 위치 `j`에서 기각이 발생하면 `j-1` 이후의 캐시 내용은 이제 잘못된 것입니다. 두 가지 일반적인 구현 방식: 스크래치 버퍼에 쓰고 수락 시 커밋(vLLM, TensorRT-LLM), 또는 물리적 KV 캐시와 논리적 길이를 유지하고 기각 시 잘라내기. 어느 쪽이든 롤백 비용은 층당 헤드당 바이트로, 순전파 비용에 비해 무시할 만합니다.

EAGLE-2 트리 검색의 경우 검증기는 트리 토폴로지를 존중하는 비-인과 마스크로 어텐션을 실행합니다. 엔지니어링은 까다롭지만 계산은 사용자 정의 마스크가 있는 표준 flash-attention 호출입니다.

### 2026년의 초안 아키텍처

| 전략 | 초안 유형 | `α` | 속도 향상 | 학습 비용 |
|----------|-----------|-----|---------|---------------|
| 바닐라 | 별도의 작은 LLM | 0.55-0.70 | 1.8-2.3배 | 없음 (기존 작은 모델 재사용) |
| Medusa | 검증기의 추가 LM 헤드 | 0.65-0.75 | 2-3배 | ~1B SFT 토큰 |
| EAGLE-1 | 은닉 상태 기반 1층 트랜스포머 | 0.70-0.80 | 2.5-3배 | ~60B 토큰 |
| EAGLE-2 | EAGLE-1 + 동적 초안 트리 | 0.80-0.88 | 3-4배 | ~60B 토큰 |
| EAGLE-3 | 다층 특징 융합 + TTT | 0.88-0.92 | 3.5-6.5배 | ~60-200B 토큰 |
| Lookahead | 초안 없음 (Jacobi 반복) | N/A | 1.3-1.6배 | 없음 |

2026년 프로덕션에서: vLLM과 SGLang은 EAGLE-3를 사용할 수 있으면 기본값으로, 그렇지 않으면 EAGLE-2를 사용합니다. TensorRT-LLM은 Meta와 NVIDIA 공개 모델을 위한 가장 빠른 Medusa 경로를 가지고 있습니다. llama.cpp는 CPU 배포를 위해 바닐라 초안을 제공합니다.

## 직접 구현하기

`code/main.py`를 참조하세요. 모든 요소(N개의 초안, 검증기 병렬 패스, 위치별 기각, 잔차 샘플링, 보너스 토큰, KV 롤백, 출력 분포가 `q`에서 직접 샘플링한 것과 일치함을 검증하는 경험적 확인)를 갖춘 전체 Leviathan 추측적 루프입니다.

### 1단계: 기각 규칙

```python
def accept(q_prob, p_prob, u):
    if p_prob <= 0:
        return True
    return u < min(1.0, q_prob / p_prob)
```

### 2단계: 잔차 분포

```python
def residual(q, p):
    raw = [max(0.0, qi - pi) for qi, pi in zip(q, p)]
    s = sum(raw)
    if s == 0:
        return list(q)
    return [r / s for r in raw]
```

### 3단계: 전체 추측적 단계

`spec_step` 함수는 `p`에서 `N`개의 토큰을 초안으로 작성한 다음, 하나의 병렬 `q` 평가에서 모두 검증합니다. 각 초안 토큰에 기각 규칙을 적용하고, 첫 번째 기각 시 잔차에서 수정을 샘플링합니다. 모든 것이 수락되면 `q_{N+1}`에서 보너스 토큰을 방출합니다.

### 4단계: KV 롤백 부기

시뮬레이터는 워커당 논리적 `kv_length`를 추적합니다. `k`개의 초안이 수락되면 `kv_length += k`입니다. 위치 `j`에서 기각 시 캐시는 이미 `j` 이후로 쓰여졌지만, 논리적 길이는 `prefix_length + j + 1`로 설정됩니다 -- 수정 토큰 다음 위치입니다. 이후 읽기는 논리적 길이로 잘라냅니다.

### 5단계: Leviathan 검증

50,000번의 추측적 단계를 실행합니다. 수락된 토큰의 경험적 분포를 셉니다. `q`에서 직접 50,000번 샘플링한 것과 비교합니다. 카이제곱 통계량이 임계값보다 훨씬 낮아야 합니다. 정리는 실제로도 성립합니다.

### 6단계: α에 따른 속도 향상

`p`를 `q`로부터 다른 진폭으로 섭동시켜 초안 품질을 변화시킵니다. `α`를 측정한 다음, 검증기 호출당 기대 토큰 수를 `α`와 `N`의 함수로 플로팅합니다. 코드는 EAGLE-3 급 초안 품질(`α ≈ 0.9`)이 검증기 호출당 4–5개의 토큰을 어떻게 가능하게 하는지 보여주는 표를 출력합니다.

EAGLE-3를 사용한 프로덕션 레벨 `vllm serve`:

```bash
vllm serve meta-llama/Llama-3.3-70B-Instruct \
  --speculative-config '{
    "model": "yuhuili/EAGLE3-LLaMA3.3-Instruct-70B",
    "num_speculative_tokens": 5,
    "method": "eagle3"
  }'
```

H100에서 배치 64의 SGLang with EAGLE-3: EAGLE-3 논문에 따르면 배치 64 바닐라 디코딩보다 약 1.38배 더 많은 처리량.

추측적 디코딩을 사용해야 할 때:

- p50 지연 시간이 최대 처리량보다 중요한 대화형 채팅 워크로드.
- 코드 생성 및 구조화된 출력(JSON, SQL). 대상 분포가 매우 예측 가능하므로 `α`가 0.9 이상입니다.
- 긴 형식 생성(수천 개의 토큰). 상각된 속도 향상이 계속 이어집니다.

사용하지 말아야 할 때:

- 매우 작은 모델(< 3B). 초안이 검증기보다 훨씬 저렴하지 않습니다.
- 소형 배치-1 CPU 배포. 초안 모델의 메모리 오버헤드가 가치가 없을 수 있습니다.
- `α`가 붕괴되는 매우 높은 온도의 창의적 샘플링.

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|-------------------|-----------|
| Leviathan 규칙 | "min(1, q over p)" | 확률 `min(1, q(d)/p(d))`로 베르누이 수락/기각, 기각 시 잔차에서 샘플링하면 검증기 분포가 정확히 보존됨 |
| 잔차 분포 | "(q minus p) plus, 정규화됨" | 0 이하를 클리핑하고 재정규화한 `(q - p)_+` -- 기각 시 샘플링할 올바른 분포 |
| 수락률 α | "초안이 얼마나 자주 맞는지" | 기각 규칙 하에서 토큰당 기대 베르누이 성공 확률, 모든 속도 향상 수학을 결정 |
| EAGLE-1 | "은닉 상태 초안" | 검증기의 마지막 층 은닉 상태에 조건화된 초소형 트랜스포머 초안 (Li et al., 2024) |
| EAGLE-2 | "동적 초안 트리" | EAGLE-1에 하나의 검증기 순전파에서 트리 어텐션으로 평가된 후보 연속 트리를 추가 |
| EAGLE-3 | "학습-시간 테스트" | 특징 예측 손실을 제거하고, 학습 중 초안이 자신의 출력을 입력으로 받는 직접 토큰 예측 학습 |
| 학습-시간 테스트 (TTT) | "노출 편향 수정" | 학습 중에 초안을 자기회귀적으로 실행하여 학습과 테스트 입력 분포를 일치시킴 -- scheduled sampling의 직접적 유사체 |
| KV 롤백 | "기각된 초안 취소" | 기각 후 검증기의 KV 캐시를 수락된 프리픽스 길이로 재설정하는 부기 |
| 보너스 토큰 | "공짜 토큰" | 모든 `N`개 초안이 수락되면 추가 검증기 비용 없이 `q_{N+1}`에서 하나를 더 샘플링 |
| 트리 어텐션 | "여러 후보를 한 번에 검증" | 초안 트리의 토폴로지를 존중하는 비-인과 마스크를 사용한 어텐션; 하나의 순전파로 트리의 모든 노드에 대해 `q_i`를 계산 |
