# 투표, 자기 일관성 및 Debate 토폴로지

> 가장 저렴한聚合: N개의 독립적 에이전트를 샘플링하고 다수결 투표합니다. Wang et al. 2022 자기 일관성이 이를 하나의 모델을 N번 샘플링하여 수행했습니다. 멀티에이전트는 monoculture를 탈출하기 위해 **이기종** 에이전트로 확장합니다 — 다른 모델, 다른 프롬프트, 다른 온도, 다른 컨텍스트. 다수결beyond, debate 토폴로지가 중요합니다: MultiAgentBench (arXiv:2503.01935, ACL 2025)가 별 / 체인 / 트리 / 그래프 조정을 평가하고 **그래프가 연구에 최고**를 발견했으며, ~4 에이전트 이후 "조정 세금"이 있습니다. AgentVerse (ICLR 2024)는 두 가지 창발 패턴을 문서화합니다 — 자원자 행동과 conformity 행동 — 그리고 conformity는 기능(합의 발견)과 위험(集体思考, Lesson 24) 모두입니다. 이 레슨은 토폴로지 공간을 매핑하고, 각 변형을 구축하고, 조정 세금을 측정합니다.

**유형:** 학습 + 실습
**언어:** Python (stdlib)
**선수 과목:** Phase 16 · 07 (Society of Mind and Debate), Phase 16 · 14 (Consensus and BFT)
**소요 시간:** ~75분

## 문제

Debate는 정확도를 개선할 수 있습니다 (Du et al., arXiv:2305.14325). 그것은 또한 저하시킬 수 있습니다. Debate가 도움이 되는지는 네 가지 구조적 선택에 따라 다릅니다:

1. 누가 누군가와 이야기하는지 (토폴로지).
2. 얼마나 많은 라운드 (Du 2023: 라운드와 에이전트 모두 독립적으로 중요합니다).
3. 에이전트가 이기종인지 여부 (다른 기본 모델이 monoculture를 깨뜨립니다).
4. 적대적 목소리가 존재하는지 여부 (steel-manning 대 straw-manning).

"5 에이전트를 실행하고 투표"를 작업에 붙이는 팀은 often 단일 에이전트 대비 퇴행합니다. 실패는 무작위가 아닙니다. 그들은 토폴로지와 이기종을 추적합니다. 이 레슨은 토폴로지 맵입니다.

## 개념

### 자기 일관성, 단일 모델 기준

Wang et al. 2022 ("자기 일관성이 CoT 추론을 개선함")는 temperature > 0에서 동일한 모델을 N번 샘플링하고 추론 경로 답변에 대해 다수결 투표했습니다. GSM8K에서의 결과: 단일 탐욕적 디코딩보다 N=40 샘플에서 상당한 개선. 자기 일관성은 멀티에이전트 투표의 단일 에이전트 선행자입니다.

한계: 자기 일관성은 하나의 기본 모델을 사용합니다. 오류는 구성에 의해 상관됩니다. 모델에 체계적 편향이 있으면 모든 N 샘플이 그것을 공유합니다.

### 멀티에이전트 투표, 이기종 확장

N 샘플을 N *다른* 에이전트로 교체합니다. 다른 기본 모델 (Claude, GPT, Llama), 다른 프롬프트, 다른 도구 액세스. 이점: 상관되지 않은 오류. 비용: 다른 에이전트가 다른 금액이 들습니다; 조정 비용이 추가됩니다.

2026년의 표준 이름은 이기종 debate를 위해 **A-HMAD** — 적대적 이기종 멀티에이전트 Debate입니다. 보편적으로 채택되지는 않았지만, 논문에서 " monoculture崩塌에서 상관된 오류를 줄이는 다른 모델 debate"에 대한 용어를 사용합니다.

### 네 가지 토폴로지

```
star                chain               tree                graph

    ┌─A─┐           A─B─C─D         ┌──A──┐              A───B
    │   │                           │     │              │ × │
    B   C                           B     C              D───C
    │   │                          / \   / \
    D   E                         D   E F   G           (완전히 연결됨)
```

별: 하나의 허브, 다른 모두가 허브와만 이야기합니다. 백 채널 없는 수퍼바이저-워커와 동등합니다.
체인: 선형, 각 에이전트가 이전 에이전트의 출력을 봅니다. 파이프라인과 유사합니다.
트리: 계층적, 계층적 에이전트 시스템에서 사용됩니다 (Lesson 06).
그래프: 임의의-to-임의. 완전한 연결 클리크와 임의 DAG를 포함합니다.

### 조정 세금 (MultiAgentBench)

MultiAgentBench (MARBLE, ACL 2025, arXiv:2503.01935)가 연구, 코딩, 계획을 포함한 작업 스위트에서 별, 체인, 트리, 그래프를 벤치마크했습니다. 주요 측정 결과:

- **그래프** 토폴로지가 연구 작업에서 이깁니다. 정보가 임의의-to-임의로 흐릅니다; 에이전트가 서로 비판할 수 있습니다.
- **별**이 빠른 답변 사실 작업에서 이깁니다. 허브가 필터링하고 통합합니다.
- **체인**이 단계별 파이프라인(단계별 정제)에서 이깁니다.
- ~4 에이전트 이후에서 조정 세금이 나타납니다. 벽시계와 토큰 비용이 품질보다 빠르게 증가합니다.

4-에이전트 천장은 경험적이지 않고 기본적입니다. 2026 LLM 컨텍스트 용량을 반영합니다: 각 에이전트의 컨텍스트가 동료의 출력으로 채워지고, everyone이 everyone을 볼 수 있으면 N+1 에이전트 추가의 한계 가치가 떨어집니다.

### 멀티에이전트 Debate 전략 ("我们应该去 MAD?")

arXiv:2311.17371은 2023년 MAD 전략 조사입니다. 주요 발견 replicated by others: *구조적으로 자기 일관성과 유사한* (독립적 샘플링 +聚合) MAD 변형은 동일한 예산을 사용할 때 often 자기 일관성보다 성능이 저하됩니다. MAD는 에이전트가 진정으로 이기종이고 debate에 적대적 구조가 있을 때 (하나의 에이전트가 것에 동의contra) 가장 많이 도움이 됩니다.

### AgentVerse 창발 패턴

AgentVerse (ICLR 2024, https://proceedings.iclr.cc/paper_files/paper/2024/file/578e65cdee35d00c708d4c64bce32971-Paper-Conference.pdf)는 명시적 설계 없이도 멀티에이전트 debate에서 나타나는 두 가지 동작을 문서화합니다:

- **자원자.** 에이전트가 자발적으로 도움을 제공합니다 ("다음 단계를 수행할 수 있습니다"). 유용함: 가장有能力한 에이전트에게 하위 작업을 할당합니다.
- **Conformity.** 에이전트가 비평가와 일치하도록 stance를 조정합니다, 비록 비평가가 틀리더라도. 이것은 debate版本的 시코판시입니다 (Lesson 14).

Conformity가 debate-until-agreement가 불량자를reward하는 이유입니다. 제한된 라운드와 별도의 판정자가 완화합니다.

### 이기종: 실제 정확도를 이동하는 노브

2024-2026년 실용 문헌의 패턴: N 에이전트 중 하나를 다른 기본 모델로 교체하면 N을 1 늘리는 것보다 더 큰 정확도 bump를 제공합니다. 직관력은 monoculture입니다 — 각 새로운 독립적 오류 소스는 추가 상관된 샘플보다 더 worth합니다.

한계에서 이기종이 다수성을 이깁니다. 세 개의 다른 모델이 대부분의 깔끔한 ground truth가 있는 작업에서 하나의 모델 5개 사본보다 낫습니다.

### 배심원 방법

Sibyl 프레임워크 (Minsky-LLM 문헌에서 인용됨)는 "배심원" — 각 단계에서 투표로 답변을 구체화하는 전문화된 에이전트의 작은 집합을 형식화합니다. 평범한 다수결 투표와 달리, 배심원은 역할이 있습니다: 하나의 에이전트가 변문하고, 하나가 컨텍스트를 제공하고, 하나가 plausibility에 점수를 매깁니다. 배심원 방법은 평범한 투표(저렴, monoculture 발생 가능)와 완전한 MAD(비싸고, conformity 발생 가능) 사이의 중간입니다.

### 투표-및-debate가 지배하는 경우

- 질문에 ground truth가 있습니다 (사실, 수학, 코드 동작). 투표 수렴이 의미 있습니다.
- 에이전트가 다른 소스 또는 도구에 액세스할 수 있습니다 (이기종이 利用可能함).
- 라운드가 제한됩니다 (typically 2-3) 그리고 별도의 판정자 또는 검증자가 있습니다.
- 예산이 3-5 에이전트를 허용합니다. 5-7 이상의 그래프 토폴로지에서 조정 세금이 지배합니다.

### 투표-및-debate가 해로운 경우

- 질문이 의견 형성입니다. 에이전트가 가장 확신하는 것이 아니라 가장 올바른 답변에 수렴합니다.
- 모든 에이전트가 기본 모델을 공유합니다. Monoculture가 consensus를 의미 없게 합니다.
- 라운드가 무제한입니다. Conformity가 매번 이깁니다.
- 작업이 단순합니다. N=5에서 자기 일관성을 사용하는 단일 에이전트가 더 저렴하고同样히 정확합니다.

## 실습

`code/main.py`가 구현합니다:

- `run_star(agents, hub, question)` — 허브가 각 워커를 폴링하고聚合합니다.
- `run_chain(agents, question)` — 순차적 정제.
- `run_tree(root, children, question)` — 깊이-2聚合이 있는 계층적.
- `run_graph(agents, question, rounds)` — 제한된 라운드로 모든-대-모든 debate.
- 스크립트된 이기종 다이얼: 각 에이전트가 체계적 잘못을 나타내는 `error_bias`를 가집니다.
- N=3, 5, 7에서 각 토폴로지를 실행하고 (정확도, total_tokens, wallclock_simulated)를 보고하는 측정 하니스.

실행:

```
python3 code/main.py
```

예상 출력: 토폴로지 × N → (정확도, 토큰, 지연)의 표. 그래프가 N=3-5에서 연구 스타일 작업에서 이깁니다; 별이 빠른 사실 작업에서 이깁니다; N=7에서 그래프가 조정 세금을 보입니다 (지연이 정확도보다 빠르게 증가합니다).

## 활용

`outputs/skill-topology-picker.md`가 작업 설명을 읽고 토폴로지 (별 / 체인 / 트리 / 그래프), N (에이전트 수), 이기종 프로파일 (사용할 기본 모델), 라운드 제한을 권장하는 스킬입니다.

## 결과물

모든 앙상블에 대해:

- **N=5에서 자기 일관성으로 시작합니다** 하나의 강한 기본 모델 사용. 이것은 저렴한 기준입니다.
- **정확도가 중요하면 N=3에서 이기종 투위로 업그레이드합니다.** 델타를 측정합니다.
- **작업에 구조가 있고 (연구, 다단계) 제한된 라운드가 가능한 경우에만 debate 토폴로지로 업그레이드합니다.**
- **항상 minority 클러스터를 로그합니다.** minority가persistently 올바른 경우, 다양성 신호가 있습니다.
- **정확도와 함께 벽시계와 토큰을 벤치마크합니다.** "10배 비용에서 더 나은 정확도"는 사업 결정입니다.

## 연습 문제

1. `code/main.py`를 실행합니다. 그래프 토폴로지에 대한 조정 세금 곡선을 플롯합니다: 정확도 대 N, 토큰 대 N. 곡선이 만곡하는 N은 어느 것입니까?
2. A-HMAD를 구현합니다: 의도적으로 다른 편향을 가진 세 에이전트. 단일 모델 베이스라인과 A-HMAD가 Lesson 14의 monoculture 공격에서 어떻게 비교합니까?
3. 그래프 토폴로지에 "판정" 역할을 추가합니다 — 투표하지 않고 최종 consensus에만 점수를 매깁니다. 이것이 창발 conformity 동작을 변경합니까?
4. AgentVerse 논문 (ICLR 2024)을 읽습니다. 구현이 가장 강하게Exhibit하는 창발 동작이 Which인지 식별합니다. 프롬프트 변경으로 반대 동작을 유도할 수 있습니까?
5. MultiAgentBench (arXiv:2503.01935) 섹션 4 (토폴로지 실험)를 읽습니다. 논문의 작업 중 하나에서 "그래프-이기는-연구" 결과를 사용자 하니스을 사용하여 재현합니다.
