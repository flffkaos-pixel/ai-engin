# 스케일링 법칙

> 2020년 Kaplan 논문은 말했다: 더 큰 모델, 더 낮은 손실. 2022년 Hoffmann 논문은 말했다: 당신은 교육이 부족했다. 계산은 두 개의 버킷으로간다 — 매개변수와 토큰 — 그리고 분할은 명확하지 않다.

**유형:** 학습
**언어:** Python
**선수 과목:** Phase 7 · 05 (Full Transformer), Phase 7 · 07 (GPT)
**소요 시간:** ~45분

## 문제

교육 계산 C FLOP가 있고 최상의 모델을 원할 때, 두 개의 손잡이가 있다:

1. **얼마나 많은 매개변수 (N)?** 더 큰 모델, 더 높은 용량.
2. **얼마나 많은 교육 토큰 (D)?** 더 많은 데이터, 더 나은 용량 활용.

FLOP는 약 `6 × N × D`로 스케일. N을 올리고 D를 내리거나, D를 올리고 N를 내릴 수 있다. 어느 것이 더 나은가?

2022년 이전, 답은 "N을 세게 밀어라"였다. GPT-3 (2020)는 ~300B 토큰에서 교육된 175B 매개변수였다. 약 1.7 토큰 per 매개변수 비율. Kaplan 스케일링 법칙이 이것을 뒷받침했다.

Hoffmann et al. (2022)는 Chinchilla라는 작은 모델 패밀리를 교육하여 다른 것을 발견했다: 최적 비율은 **토큰당 20개**에 가깝다. GPT-3는 10× 교육 부족이었다. Chinchilla (70B 매개변수, 1.4T 토큰)는 2.5× 더 적은 추론 비용으로 모든 벤치마크에서 GPT-3 (175B, 300B 토큰)를 이겼다.

2026년은 Chinchilla의 세계이다 — 하나의 중요한 반전과 함께. Llama 3 8B는 15조 토큰에서 교육되었으며, 매개변수당 1,875 토큰의 비율이다. Chinchilla 최적의 94배. 추론 비용은 규모로 사용될 모델의 교육 비용보다 중요하다. 따라서 더 작은 배치 가능한 발자국이 있는 더 작은 모델을 더 오래 교육하는 것 (Chinchilla 이상)은 2026년 기본값이다.

## 개념

![Chinchilla 곡선: 다양한 N/D 비율에서 손실 vs 계산](../assets/scaling-laws.svg)

### Hoffmann 법칙

Chinchilla 논문에서, 손실은 다음과 같이 따른다:

```
L(N, D) = A / N^α + B / D^β + E
```

- `N` = 매개변수 (non-embedding).
- `D` = 교육 토큰.
- `α ≈ 0.34`, `β ≈ 0.28` (대략 대칭).
- `E ≈ 1.69`, 불가역적인 손실 한도.
- `A ≈ 406`, `B ≈ 411`.

두 항이 스케일할 때 서로 trade. 고정된 계산 (C = 6ND)에서 N에 대해 미분하고解いて:

```
N_opt ≈ 0.6 × (C/6)^0.5
D_opt ≈ 0.6 × (C/6)^0.5
D_opt / N_opt ≈ 20
```

계산 최적: 토큰당 20개 매개변수.

### 그래도 초과 교육하는 이유

Chinchilla 최적은 교육 FLOP당 교육 손실을 최소화한다. 하지만 교육 비용은 한 번만 지불한다; 추론 비용은 영원히 지불한다.

월 1조 토큰을 제공하는 채트봇의 경우, 추론이 총 비용을 지배한다. Llama의 접근 방식: 더 작게, 더 길게 교육. 15T 토큰의 8B는 심하게 추론 최적화되어 있다:

- 소비자 GPU에 적합.
- 지연 시간이 70B Chinchilla 최적의 일부이다.
- 품질은 대부분의 작업에 충분히 가깝다.

DeepMind의 2024년 논문 ("초과 교육이 새로운 최적이다")은 이것을 공식화했다. 추론 중심 워크로드의 경우, 올바른 비율은 서빙 볼륨에 따라 토큰당 100–500에 가깝다.

### 출현 vs 부드러움

주장: 특정 능력 (산술, 다단계 추론, chain-of-thought 따르기)은 어떤 규모에서 갑자기 "출현"한다.

Schaeffer et al. (2023)은 이것이 측정 인공물이라고 주장했다: 출현 메트릭은 기본 로짓의 부드러운 개선을 숨기는 불연속 스코어링 (정확한 일치, 임계값의 정확도)을 사용한다. 연속 메트릭 (cross-entropy)은 부드러운 곡선을 보여준다.

2026년 합의: 연속 손실을 통한 예측이 신뢰할 수 있다. 벤치마크 점프는 종종 스코어러 인공물이다. 연속 메트릭에 대해 예산을 계획한다.

### 2026년 그림

스케일링 법칙은 여전히 작동하지만:

| 요소 | 변경된 방식 |
|--------|-------------|
| 데이터 품질 | "좋은" 토큰 큐레이션 (Phi 스타일)은 >2× 유효 계산을 이동 |
| MoE | 총 매개변수가 활성 FLOP에서 분리; 활성 FLOP당 스케일링 법칙 |
| 사후 교육 | 일부 능력 (지시 따르기, 코드)은 사전 교육보다 SFT+RLHF로 더 이동 |
| 멀티모달리티 | 이미지 + 텍스트 토큰이 함께 스케일; 모달리티당 별도 곡선 |
| 합성 데이터 | 모델이 교육 데이터를 생성; 유효한 계산이 합성될 수 있다 |

Muon 옵티마이저 (Kimi Moonlight, 2024)는 AdamW와 일치하는 데이터에서 ~2× 유효 계산Gain을 보였다. 2026년 일부 교육 실행은 기본적으로 Muon을 사용한다. 법칙의 모양이 아닌 스케일링 법칙의 절대 상수를 변경한다.

## 실습

`code/main.py`를 참조. Chinchilla 손실 방정식을 구현하고 여러 계산 예산 각각에 대해 계산 최적 `(N, D)`를解いて.

### Step 1: Chinchilla 손실

```python
def chinchilla_loss(N, D, A=406.4, B=410.7, alpha=0.34, beta=0.28, E=1.69):
    return A / N ** alpha + B / D ** beta + E
```

고정 `C = 6ND`에서 `(N, D)`에 대해 `L`을 등고선으로 플롯한다. 최소값을 찾는다.

### Step 2: 계산 최적 프론티어

`1e17`에서 `1e25` FLOP까지의 계산 예산에 대해, `6ND = C` 조건으로 손실을 최소화하는 `(N, D)`를 찾는다. 비율 `D/N ≈ 20`을 확인한다.

### Step 3: 초과 교육 비용

최적 N의 1/10, 최적 D의 10배인 10× 더 작은 모델을 교육하기 위해 지불하는 추가 손실을 계산한다. 교환으로 추론 FLOP 절감 (N에 비례)을 보고한다.

### Step 4: 실제 모델과 비교

알려진 `(N, D)` 쌍 (GPT-3, Chinchilla, Llama 3 8B, DeepSeek-V3 (활성 매개변수))을 놓고 예측 vs 보고된 손실을 비교한다.

## 활용

프론티어 모델을 직접 교육할 가능성은 낮다. 하지만 스케일링 법칙은 다음과 같이 알려준다:

1. **fine-tune에 충분한 데이터가 있는지.** 작업 관련 데이터가 기본 모델의 매개변수당 20 토큰 미만이면, 어떤 손실 바닥에서 포화될 것으로 예상한다.
2. **더 큰 기본 모델을 선택할지 여부.** 추론에 모든 예산을 쓴다면, 더 작고 오래 교육된 모델을 선호한다.
3. **수익이 감소하는 곳.** Chinchilla 최적의 1000× 이상에서, log-loss 변경이 노이즈가 된다.

**2026년 연구 궤적:**

- **데이터 제약 체제.** 웹에는 고품질 토큰의 수가 제한되어 있다 (~5–10조 영어 필터링 후). 프론티어 사전 교육은 이 한도에 접근하고 있다. 합성 데이터, 다국어, 멀티모달 및 RLHF 스케일 fine-tuning이 다음 지렛대이다.
- **계산 승수 트릭.** Muon 옵티마이저, MoE, 더 나은 데이터 큐레이션 — 각각이 절대 상수를 이동시키고, asymptote는 아니다.
- **RL의 스케일링 법칙.** 열린 질문. 초기 증거는 사전 교육과 매우 다른 지수를 가진 RL 샘플에서 멱법칙을 제안한다.

## 연습 문제

1. **쉬움.** `code/main.py`를 실행한다. 계산 예산 `1e20`, `1e22`, `1e24`에 대한 Chinchilla 최적 `(N, D)`를 인쇄한다. 실제 모델 테이블과 비교한다.
2. **보통.** Hoffmann 손실-계산 곡선을 구현한다. 계산 최적 프론티어에 대해 `log10(C)`에 대한 손실을 플롯한다. 법칙이 다음 0.1 감소를 위해 `>10^28` FLOP가 필요할 것으로 예측하는 시점을 식별한다.
3. **어려움.** 동일한 데이터 세트에서 교육된 5개의 작은 모델 (100K ~ 10M 매개변수)에 자체 스케일링 법칙을 피팅한다. `α`와 `E`를 추정한다. 귀하의 지수가 게시된 것과 얼마나 잘 일치하는가?

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|-----------------|-----------------------|
| Parameters (N) | "모델 크기" | Non-embedding 가중치 수; 용량을 결정. |
| Tokens (D) | "교육 데이터" | 본 교육 토큰 수; 매개변수가 얼마나 잘 사용되는지를 결정. |
| Compute (C) | "지출한 FLOP" | 표준 transformer에 대해 약 `6 × N × D`. |
| Chinchilla-optimal | "D/N ≈ 20" | 교육 FLOP당 손실을 최소화하는 비율. |
| Over-training | "Chinchilla 이후" | 추론 FLOP를 절약하기 위해额外的 교육 FLOP를 지출; D/N >> 20. |
| Irreducible loss | "바닥" | 스케일링 법칙의 `E` 항; 데이터 자체의 엔트로피. |
| Emergent capability | "규모에서 갑작스러운 점프" | 종종 스코어러 인공물; 연속 손실은 부드럽다. |
| Effective compute | "교육 효율성 승수" | 더 나은 데이터 / 옵티마이저 / 아키텍처가 FLOP가 얼마나 멀리 가는지를 곱한다. |
