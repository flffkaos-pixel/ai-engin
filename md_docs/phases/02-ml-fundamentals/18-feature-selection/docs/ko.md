## 학습 목표

- 필터 방법(분산 임계값, 상호 정보량, 카이제곱)과 래퍼 방법(RFE, 전진 선택)을 처음부터 구현
- 상호 정보량이 상관관계가 놓치는 비선형 특성-타겟 관계를 포착하는 이유 설명
- L1 정규화(임베디드 선택)와 RFE(래퍼 선택) 비교, 계산 트레이드오프 평가
- 여러 방법을 결합한 특성 선택 파이프라인 구축, 홀드아웃 데이터에서 일반화 향상 시연

## 개념

### 세 가지 접근법

**필터 방법**: 모델 독립적. 각 특성을 통계적으로 순위 매김:
- 분산 임계값: 거의 상수인 특성 제거
- 상관관계: 높은 중복 특성 제거
- 상호 정보량: I(특성; 타겟) — 비선형 관계 포착
- 카이제곱: 범주형 특성용

**래퍼 방법**: 모델 성능으로 특성 부분집합 평가:
- **RFE (재귀적 특성 제거)**: 중요도 가장 낮은 특성 재귀적 제거
- **전진 선택**: 가장 좋은 특성 하나씩 추가
- 계산 비용 높지만 더 나은 부분집합

**임베디드 방법**: 훈련 중 특성 선택:
- **L1/LASSO**: 작은 가중치 → 0으로 축소 = 자동 특성 선택
- **트리 기반 중요도**: 분할 사용 빈도 기반 순위
- **순열 중요도**: 특성 섞었을 때 성능 저하

### 상호 정보량 vs 상관관계

- **Pearson 상관**: 선형 관계만. y=x²에서 r≈0
- **상호 정보량**: 비선형 포함 — y=x²에서 높은 MI

## 빌드하기

```python
def mutual_information(X, y, n_bins=10):
    """연속 특성에 대한 근사 MI"""
    mi_scores = []
    for col in range(X.shape[1]):
        x_binned = np.digitize(X[:, col], np.histogram_bin_edges(X[:, col], bins=n_bins))
        mi = 0
        for xi in np.unique(x_binned):
            for yi in np.unique(y):
                p_xy = np.mean((x_binned == xi) & (y == yi))
                p_x = np.mean(x_binned == xi)
                p_y = np.mean(y == yi)
                if p_xy > 0:
                    mi += p_xy * np.log(p_xy / (p_x * p_y))
        mi_scores.append(mi)
    return np.array(mi_scores)
```

## 주요 용어

| 용어 | 실제 의미 |
|------|----------|
| 필터 | 모델 독립 — 빠르지만 최적 아님 |
| 래퍼 | 모델 기반 — 최적 부분집합, 계산 비용 높음 |
| 임베디드 | 훈련 중 선택 — L1/트리 중요도 |
| 상호 정보량 | 비선형 의존성 측정 — 상관보다 우수 |
| RFE | 가장 약한 특성 재귀적 제거 |
