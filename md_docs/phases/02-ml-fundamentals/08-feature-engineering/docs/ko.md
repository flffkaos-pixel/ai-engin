## 개념

### 특성 공학 파이프라인

원시 데이터 → 결측치 처리 → 수치 변환 + 범주형 인코딩 + 텍스트 특성 → 특성 상호작용 → 특성 선택

### 수치 변환

| 변환 | 공식 | 사용 시기 |
|------|------|----------|
| 표준화 | (x-μ)/σ | 평균 0, 분산 1 — 정규성 가정 알고리즘 |
| 최소-최대 | (x-min)/(max-min) | [0,1] 범위 — 거리 기반 알고리즘 |
| 로그 | log(x+1) | 치우친 분포 교정 |
| 비닝 | 구간화 | 연속→범주형 — 비선형 관계 포착 |

### 범주형 인코딩

- **원-핫**: 각 범주 = 이진 열. 고유값 많으면 희소해짐
- **레이블**: 범주 → 정수. 트리 모델 OK, 선형 모델은 거리 왜곡
- **타겟**: 범주 → 목표 평균. **⚠️ 검증 세트로 분리 안 하면 데이터 누수!**

### TF-IDF

`TF-IDF(w,d) = TF(w,d) * log(N / DF(w))`

- **TF**: 문서에서 단어 빈도
- **IDF**: 역문서 빈도 — 모든 문서에 나오면 패널티. "the" 같은 단어 억제

### 특성 선택 방법

| 방법 | 작동 방식 |
|------|----------|
| 분산 임계값 | 거의 상수인 특성 제거 |
| 상관관계 | 높은 상관 특성 중 하나 유지 |
| 상호 정보량 | 특성-타겟 의존성 측정 — 비선형 포착 |
| SelectKBest | 상위 K개 특성 유지 |

## 빌드하기

```python
def tfidf_vectorize(docs):
    # 문서-단어 행렬
    vocab = sorted(set(w for doc in docs for w in doc))
    tf = np.array([[doc.count(w)/len(doc) for w in vocab] for doc in docs])
    df = np.array([sum(1 for doc in docs if w in doc) for w in vocab])
    idf = np.log(len(docs) / (df + 1)) + 1  # 평활화
    return tf * idf
```

## 주요 용어

| 용어 | 실제 의미 |
|------|----------|
| 표준화 | 평균 0, 분산 1 — 정규 분포 가정에 필요 |
| TF-IDF | 단어 중요도 — 흔한 단어 페널티 |
| 원-핫 | 범주 → 이진 벡터 — 메모리 소비 큼 |
| 타겟 인코딩 | 범주 → 평균 타겟값 — 누수 주의! |
