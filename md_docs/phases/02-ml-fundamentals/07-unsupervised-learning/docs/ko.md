## 개념

### K-평균

```
1. K개 중심점 무작위 초기화
2. 각 점을 가장 가까운 중심점에 할당
3. 중심점을 할당된 점들의 평균으로 재계산
4. 수렴할 때까지 2-3 반복
```

**단점**: K 지정 필요, 구형 클러스터 가정, 이상치에 민감, 초기화 의존 (K-평균++로 개선).

### DBSCAN (밀도 기반)

두 파라미터: ε(이웃 반경), min_pts(핵심점 최소 이웃).

- **핵심점**: ε 내에 ≥ min_pts 이웃
- **경계점**: 핵심점에 연결, 자체 이웃 부족
- **노이즈점**: 어느 클러스터에도 속하지 않음

**장점**: 임의 형태 클러스터, 노이즈 처리, K 지정 불필요. **단점**: 밀도가 다양한 데이터에 어려움.

### GMM (가우시안 혼합 모델)

데이터가 K개 가우시안 분포 혼합에서 생성된다고 가정. EM 알고리즘으로 적합. 소프트 할당(각 점이 확률로 각 클러스터에 속함).

### 평가

- **엘보우 방법**: K에 따른 관성(WCSS) 그래프 — "팔꿈치" = 최적 K
- **실루엣 점수**: -1~1. 높을수록 좋음. 클러스터 응집도와 분리도 측정

## 빌드하기

```python
def kmeans(X, k, max_iter=100):
    centroids = X[np.random.choice(len(X), k, replace=False)]
    for _ in range(max_iter):
        dists = np.array([np.sum((X - c)**2, axis=1) for c in centroids])
        labels = np.argmin(dists, axis=0)
        new_centroids = np.array([X[labels == i].mean(axis=0) for i in range(k)])
        if np.allclose(centroids, new_centroids): break
        centroids = new_centroids
    return labels, centroids
```
