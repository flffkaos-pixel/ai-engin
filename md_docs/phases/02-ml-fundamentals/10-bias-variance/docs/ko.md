## 학습 목표

- 예측 오차의 편향-분산 분해 유도, 불가역적 노이즈의 역할 설명
- 훈련 및 테스트 오차 패턴으로 높은 편향 vs 높은 분산 진단
- 정규화 기법(L1, L2, 드롭아웃, 조기 종료)이 편향과 분산을 교환하는 방법 설명
- 복잡도가 증가하는 모델에서 편향-분산 트레이드오프 시각화 실험 구현

## 개념

### 세 가지 오차 원천

```
기대 예측 오차 = Bias² + Variance + Noise² (불가역적)
```

- **편향**: 단순화 가정으로 인한 체계적 오차. 모델이 참 패턴을 놓침
- **분산**: 훈련 데이터 작은 변화에 대한 과민반응. 다른 데이터셋에서 예측이 크게 달라짐
- **노이즈**: 데이터 자체의 불가역적 무작위성 — 제어 불가

### 진단

| 상황 | 훈련 오차 | 테스트 오차 | 의미 |
|------|----------|-----------|------|
| 높은 편향 | 높음 | 높음 (비슷) | 과소적합 — 더 복잡한 모델 필요 |
| 높은 분산 | 낮음 | 높음 (큰 갭) | 과적합 — 정규화/더 많은 데이터 필요 |

### 정규화와 트레이드오프

- **L1/L2**: 가중치 축소 → 편향 증가, 분산 감소
- **드롭아웃**: 랜덤 뉴런 비활성화 → 앙상블 효과, 분산 감소
- **조기 종료**: 검증 오차 증가 전 중지 → 분산 제한
- **앙상블**: 여러 모델 평균 → 분산 감소 (편향 불변)

### 그림으로 보는 트레이드오프

모델 복잡도 증가 → 편향 감소, 분산 증가. 최적 복잡도 = 총 오차 최소 지점.

## 주요 용어

| 용어 | 실제 의미 |
|------|----------|
| 편향 | 평균 예측과 참값의 차이 — 단순화 오차 |
| 분산 | 예측의 변동성 — 다른 훈련 세트에 대한 민감도 |
| 불가역적 노이즈 | 데이터 자체의 무작위성 — 제어 불가 |
| 과소적합 | 높은 편향, 낮은 분산 — 패턴을 잡지 못함 |
| 과적합 | 낮은 편향, 높은 분산 — 노이즈를 학습함 |
