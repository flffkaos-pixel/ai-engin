# 이상 탐지

> 정상을 정의하는 건 쉽습니다. 비정상은 맞지 않는 모든 것입니다.

**유형:** 빌드
**언어:** Python
**선수 과목:** Phase 2, Lessons 01-09
**시간:** ~75분

## 학습 목표

- Z-점수, IQR, 고립 포레스트 이상 탐지 방법을 처음부터 구현하기
- 점 이상, 맥락 이상, 집단 이상 구분하고 각각에 적절한 탐지 방법 선택
- 이상 탐지가 이상 분류보다 정상 데이터 모델링으로 구성되는 이유 설명
- 비지도 이상 탐지와 지도 분류 비교, 새로운 이상 커버리지와 정밀도 간 트레이드오프 평가

## 개념

### 접근법의 전환

지도 학습: 이상 클래스 예측 — 이상이 너무 적어(<0.1%) 불가능.
이상 탐지: 정상 모델링 → 벗어나면 이상. 레이블 불필요.

### 방법

**통계적 방법**:
- **Z-점수**: |x-μ|/σ > 3 → 이상
- **IQR**: Q1-1.5IQR 미만 또는 Q3+1.5IQR 초과
- **마할라노비스**: 다변량 버전으로 상관관계 고려

**거리/밀도 기반**:
- **k-NN 거리**: k번째 이웃까지 거리 > 임계값
- **LOF (Local Outlier Factor)**: 지역 밀도가 이웃보다 낮음

**앙상블/트리 기반**:
- **고립 포레스트**: 이상은 무작위 분할로 더 빨리 고립됨 → 짧은 평균 경로 길이

### 이상 유형

- **점 이상**: 단일 관측치가 정상에서 멀리 떨어짐
- **맥락 이상**: 문맥에서만 이상 (여름에 30°C 정상, 겨울이면 이상)
- **집단 이상**: 개별은 정상이나 집합이 비정상 (연속된 작은 트랜잭션 = 사기)

### 평가 과제

- 클래스 불균형 극심 (99.9% 정상)
- 정밀도 vs 재현율: 오탐지(정상→이상)가 너무 많으면 알람 피로
- 정답 레이블이 보통 없음 → 실무자 피드백에 의존

## 빌드하기

```python
def z_score_detection(data, threshold=3):
    mean, std = np.mean(data), np.std(data)
    z_scores = np.abs((data - mean) / std)
    return z_scores > threshold

def iqr_detection(data, k=1.5):
    q1, q3 = np.percentile(data, 25), np.percentile(data, 75)
    iqr = q3 - q1
    return (data < q1 - k*iqr) | (data > q3 + k*iqr)
```

## 주요 용어

| 용어 | 실제 의미 |
|------|----------|
| 이상 탐지 | 정상 학습 → 벗어난 것 탐지 |
| 고립 포레스트 | 무작위 트리 분할 — 이상은 얕은 리프 |
| Z-점수 | 표준편차 단위 거리 — 단변량 |
| 오탐지율 | 정상이 이상으로 분류 — 알람 피로 유발 |
