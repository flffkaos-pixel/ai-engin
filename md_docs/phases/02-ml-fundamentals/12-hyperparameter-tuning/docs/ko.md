# 하이퍼파라미터 튜닝

> 하이퍼파라미터는 훈련 시작 전에 돌리는 손잡이입니다. 잘 돌리면 평범한 모델과 훌륭한 모델의 차이를 만듭니다.

**유형:** 빌드
**언어:** Python
**선수 과목:** Phase 2, Lesson 11
**시간:** ~90분

## 학습 목표

- 그리드 서치, 랜덤 서치, 베이지안 최적화를 처음부터 구현하고 표본 효율성 비교하기
- 대부분의 하이퍼파라미터가 낮은 유효 차원을 가질 때 랜덤 서치가 그리드 서치를 능가하는 이유 설명
- 대리 모델과 획득 함수로 검색을 안내하는 베이지안 최적화 루프 구축하기
- 적절한 교차 검증으로 검증 세트 과적합을 방지하는 하이퍼파라미터 튜닝 전략 설계

## 개념

### 파라미터 vs 하이퍼파라미터

- **파라미터**: 훈련 중 학습됨 (가중치, 편향)
- **하이퍼파라미터**: 훈련 전 설정 (학습률, 트리 깊이, λ)

### 주요 하이퍼파라미터

| 하이퍼파라미터 | 제어 대상 | 일반적 범위 |
|--------------|---------|-----------|
| 학습률 | 단계 크기 | 10⁻⁴ ~ 10⁻¹ |
| 트리 깊이 | 모델 복잡도 | 3 ~ 15 |
| 정규화 λ | 가중치 페널티 | 10⁻³ ~ 10³ |
| 배치 크기 | 기울기 노이즈 | 16 ~ 512 |

### 검색 전략

**그리드 서치**: 모든 조합 시도. H개 하이퍼파라미터, 각각 K값 → K^H 조합. 비효율적 — 중요 파라미터에 할당된 예산이 랜덤 서치보다 적음.

**랜덤 서치**: 무작위 조합 샘플링. 대부분의 문제에서 중요 파라미터가 소수이므로 그리드보다 우수.

**베이지안 최적화**: 1) 확률적 대리 모델(보통 가우시안 프로세스)로 목표 함수 근사, 2) 획득 함수(예: Expected Improvement)로 다음 시도 지점 선택. 3) 결과로 대리 모델 업데이트. 적은 평가로 좋은 하이퍼파라미터 찾음.

### 중첩 교차 검증

하이퍼파라미터 튜닝 시 검증 세트 과적합 방지:
- **외부 루프**: 일반화 추정을 위한 K-겹
- **내부 루프**: 최적 하이퍼파라미터 선택

## 빌드하기

```python
def random_search(param_space, objective_fn, n_iter=50):
    best_params, best_score = None, float('inf')
    for _ in range(n_iter):
        params = {k: np.random.choice(v) if isinstance(v, list) else np.exp(np.random.uniform(*np.log(v)))
                  for k, v in param_space.items()}
        score = objective_fn(params)
        if score < best_score:
            best_score, best_params = score, params
    return best_params, best_score
```

## 주요 용어

| 용어 | 실제 의미 |
|------|----------|
| 그리드 서치 | 모든 조합 — K^H 폭발 |
| 랜덤 서치 | 무작위 샘플링 — 더 적은 예산으로 우수 |
| 베이지안 최적화 | 과거 평가에서 학습 — 가장 표본 효율적 |
| 획득 함수 | 탐색 vs 활용 균형 조정 |
