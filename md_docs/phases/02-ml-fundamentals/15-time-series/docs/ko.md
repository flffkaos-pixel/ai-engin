# 시계열 기초

> 과거 성과는 미래 결과를 예측합니다 — 먼저 정상성을 확인한다면.

**유형:** 빌드
**언어:** Python
**선수 과목:** Phase 2, Lessons 01-09
**시간:** ~90분

## 학습 목표

- 시계열을 추세, 계절성, 잔차 성분으로 분해하고 정상성 검정하기
- 지연 특성과 이동 통계량으로 시계열을 지도 학습 문제로 변환하기
- 미래 데이터가 훈련으로 누수되는 것을 방지하는 전진 검증 프레임워크 구축
- 시계열에 무작위 분할이 유효하지 않은 이유 설명, 시간적 분할과의 성능 차이 시연

## 개념

### 정상성

정상 시계열: 평균, 분산, 자기상관이 시간에 따라 일정. 대부분의 모델이 이를 가정.

**검정**: ADF(Augmented Dickey-Fuller) — p<0.05면 정상.
**비정상 → 정상**: 차분(Δyₜ = yₜ - yₜ₋₁), 로그 변환, 계절 분해.

### 시계열 분해

```
y(t) = Trend(t) + Seasonality(t) + Residual(t)
```

- **추세**: 장기 방향
- **계절성**: 규칙적 순환 (일별/주별/월별)
- **잔차**: 설명되지 않는 노이즈

### 지연 특성

t 시점 예측 = 이전 k 시점 특성으로. 시계열을 표 형식 변환:

| y(t) | y(t-1) | y(t-2) | y(t-3) |
|------|--------|--------|--------|
| y₄ | y₃ | y₂ | y₁ |

### 전진 검증

전통적 교차 검증 대신: 과거로 훈련 → 미래로 테스트, 시간순 확장 창.

```
iter 1: train[0:30]  test[30:40]
iter 2: train[0:40]  test[40:50]
iter 3: train[0:50]  test[50:60]
```

### 흔한 실수

- **무작위 분할**: 미래를 과거로 유출 → 비현실적 성능
- **표준화 누수**: 전체 시계열 평균/표준편차 사용
- **정상성 무시**: 비정상 데이터로 훈련 → 허위 회귀

## 빌드하기

```python
def create_lag_features(data, target_col, n_lags=7):
    df = data.copy()
    for lag in range(1, n_lags + 1):
        df[f'lag_{lag}'] = df[target_col].shift(lag)
    return df.dropna()
```
