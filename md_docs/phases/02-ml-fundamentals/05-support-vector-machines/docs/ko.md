## 개념

### 최대 마진 분류기

데이터를 분리하는 초평면 w^T x + b = 0. 점에서 초평면까지 거리: `|w^T x + b| / ||w||`.

무한히 많은 직선이 가능 → **가장 큰 마진을 가진 것** 선택. 마진이 넓을수록 일반화가 더 좋음.

### 힌지 손실 (소프트 마진 SVM)

`Loss = max(0, 1 - y*(w^T x + b)) + λ||w||²`

올바른 쪽에 있고 마진 밖 → loss=0. 마진 안 또는 잘못된 쪽 → loss>0. `C = 1/λ`가 규제-오차 트레이드오프 제어.

### 커널 트릭

비선형 결정 경계: 데이터를 고차원으로 매핑하지 않고 선형 SVM 적용. `K(x, z) = φ(x)·φ(z)`:

- **선형**: K(x,z) = x·z
- **다항식**: K(x,z) = (x·z + c)^d
- **RBF**: K(x,z) = exp(-γ||x-z||²) — 가장 널리 사용됨

### 파라미터

| 파라미터 | 효과 |
|---------|------|
| C (큼) | 마진 좁음, 오분류 적게 — 과적합 위험 |
| C (작음) | 마진 넓음, 오분류 용인 — 단순 모델 |
| γ (큼/RBF) | 작은 영향 반경 — 복잡한 결정 경계 |
| γ (작음/RBF) | 큰 영향 반경 — 부드러운 결정 경계 |

## 빌드하기

```python
class LinearSVM:
    def __init__(self, C=1.0, lr=0.001, epochs=1000):
        self.C, self.lr, self.epochs = C, lr, epochs

    def fit(self, X, y):
        y_svm = np.where(y <= 0, -1, 1)
        n, d = X.shape
        self.w = np.zeros(d); self.b = 0.0
        for _ in range(self.epochs):
            margins = y_svm * (X @ self.w + self.b)
            loss_mask = margins < 1
            dw = self.w - self.C * (X[loss_mask].T @ y_svm[loss_mask])
            db = -self.C * np.sum(y_svm[loss_mask])
            self.w -= self.lr * dw / n
            self.b -= self.lr * db / n
```

## 주요 용어

| 용어 | 실제 의미 |
|------|----------|
| 마진 | 결정 경계에서 가장 가까운 점까지의 거리 |
| 서포트 벡터 | 마진 위에 있는 학습 점 — 모델 정의 |
| 커널 트릭 | 고차원 계산 없이 비선형 분리 가능 |
| C 파라미터 | 규제 강도 — 마진 크기 vs 오차 허용 |
