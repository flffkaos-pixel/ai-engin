- 평균 제곱 오차에 대한 경사하강법 업데이트 규칙 유도하고 선형 회귀를 처음부터 구현하기

- 특성 표준화로 다중 선형 회귀 모델 구축하고 학습된 가중치 해석하기
- Ridge 회귀(L2 정규화)가 큰 가중치를 페널티로 과적합을 방지하는 방법 설명하기

## 문제

집 크기와 판매 가격 데이터가 있습니다. 크기로 새 집 가격을 예측하려면 최적선이 필요합니다.

선형 회귀가 그 선을 제공합니다. 더 중요하게, 전체 ML 훈련 루프를 소개합니다: 모델 정의 → 비용 함수 정의 → 파라미터 최적화. 모든 ML 알고리즘이 이 동일한 패턴을 따릅니다.

## 개념

### 모델

`y = wx + b` (단일 특성) 또는 `y = w^T x + b` (다중 특성)

- **w (가중치/기울기)**: x가 1 증가할 때 y의 변화량
- **b (편향/절편)**: x=0일 때 y 값

### 비용 함수 (평균 제곱 오차, MSE)

`MSE = (1/n) Σ(ŷ - y)²`

제곱을 사용하는 이유: 큰 오차에 더 큰 페널티를 주고, 매끄럽고 미분 가능한 함수라 최적화가 간단합니다. MSE 곡면은 볼록 포물면(그릇 모양) — 바닥 = 최적 파라미터.

### 경사하강법

```python
# MSE 기울기
dw = (2/n) * np.sum((y_pred - y) * x)
db = (2/n) * np.sum(y_pred - y)

# 업데이트
w = w - lr * dw
b = b - lr * db
```

### 정규방정식 (해석적 해)

`w = (X^T X)^(-1) X^T y`

한 번에 해를 구함. 경사하강법보다 빠르지만 O(n³) — 큰 n에는 부적합.

### Ridge 회귀 (L2 정규화)

`J = MSE + λ Σw_i²`

λ가 클수록 가중치를 0에 가깝게 축소 → 과적합 방지. 정규방정식: `w = (X^T X + λI)^(-1) X^T y`.

## 빌드하기

```python
class LinearRegression:
    def __init__(self, lr=0.01, epochs=1000):
        self.lr, self.epochs = lr, epochs

    def fit(self, X, y):
        n, d = X.shape
        self.w = np.zeros(d); self.b = 0.0
        for _ in range(self.epochs):
            y_pred = X @ self.w + self.b
            dw = (2/n) * X.T @ (y_pred - y)
            db = (2/n) * np.sum(y_pred - y)
            self.w -= self.lr * dw
            self.b -= self.lr * db

    def predict(self, X):
        return X @ self.w + self.b
```

## 주요 용어

| 용어 | 실제 의미 |
|------|----------|
| MSE | 평균 오차 제곱 — 큰 오차 페널티 |
| 경사하강법 | 반복적으로 기울기 따라 내려가며 최소값 찾기 |
| 정규방정식 | 직접 해 — O(n³), 작은 데이터셋에 적합 |
| Ridge | L2 페널티 — 가중치 축소로 과적합 방지 |
