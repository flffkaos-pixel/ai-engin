# 모델 평가

> 모델은 그것을 측정하는 방식만큼만 좋습니다.

**유형:** 빌드
**언어:** Python
**선수 과목:** Phase 1, Phase 2 Lessons 1-8
**시간:** ~90분

## 학습 목표

- K-겹 및 계층화 K-겹 교차 검증을 처음부터 구현, 불균형 데이터에 계층화가 중요한 이유 설명
- 정밀도, 재현율, F1, AUC-ROC, 회귀 지표(MSE, RMSE, MAE, R²)를 처음부터 계산
- 학습 곡선 해석으로 높은 편향 vs 높은 분산 진단
- 데이터 누수, 잘못된 지표 선택, 테스트 세트 오염 등 일반적인 평가 실수 식별

## 개념

### Train / Validation / Test

- **Train**: 모델 학습 (60-80%)
- **Validation**: 하이퍼파라미터 튜닝, 조기 종료 (10-20%)
- **Test**: 최종 평가 — 한 번만 사용! (10-20%)

### 교차 검증

데이터를 K개 fold로 분할. 각 fold가 한 번씩 검증 세트 역할. K=5 또는 10. 계층화: 각 fold에 클래스 비율 유지 — 불균형 데이터에 필수.

### 분류 지표

| 지표 | 공식 | 용도 |
|------|------|------|
| 정확도 | (TP+TN)/Total | 균형 데이터 |
| 정밀도 | TP/(TP+FP) | 오탐지 비용이 클 때 |
| 재현율 | TP/(TP+FN) | 미탐지 비용이 클 때 |
| F1 | 2PR/(P+R) | 정밀도-재현율 균형 |
| AUC-ROC | 곡선 아래 면적 | 임계값 무관 순위 품질 |

### 회귀 지표

- **MSE**: (1/n)Σ(ŷ-y)² — 큰 오차 페널티
- **RMSE**: √MSE — 원래 단위, 더 해석 가능
- **MAE**: (1/n)Σ|ŷ-y| — 이상치에 강건
- **R²**: 설명된 분산 비율 — 1이 완벽

### 학습 곡선 진단

- **높은 편향**: train/test 오차 모두 높고 수렴 → 더 복잡한 모델
- **높은 분산**: train 오차 낮음, test 오차 높고 갭 큼 → 더 많은 데이터/정규화

### 흔한 실수

- 테스트 세트로 튜닝 → 오염
- 불균형 데이터에 정확도 사용
- 시계열 데이터 무작위 분할 → 미래로 과거 예측

## 주요 용어

| 용어 | 실제 의미 |
|------|----------|
| 교차 검증 | K fold 순환 — 안정적 성능 추정 |
| 혼동 행렬 | TP/FP/FN/TN — 모든 지표의 기초 |
| AUC-ROC | 모든 임계값에서의 분류기 품질 |
| 학습 곡선 | 편향 vs 분산 진단 도구 |
