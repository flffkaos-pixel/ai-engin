## 문제

손실 함수가 있고 기울기가 있습니다. 이제 내리막길을 걷는 전략이 필요합니다.

단순한 접근법: 기울기의 반대 방향으로 이동. 학습률로 스텝 크기 조정. 반복. 이것이 경사하강법이고 작동합니다. 하지만 "작동한다"에는 주의사항이 있습니다. 학습률이 너무 크면 계곡을 완전히 지나쳐 벽 사이를 튕깁니다. 너무 작으면 수천 번의 불필요한 스텝으로 답을 향해 기어갑니다.

딥러닝의 모든 옵티마이저는 같은 질문에 대한 답입니다: 어떻게 더 빠르고 더 안정적으로 계곡 바닥에 도달할 수 있을까?

## 개념

### 경사하강법 (기본형)

```
w = w - lr * gradient
```

전체 알고리즘입니다. 한 줄.

### 학습률: 가장 중요한 하이퍼파라미터

- **너무 큼**: 오버슈트, 발산
- **너무 작음**: 수렴이 매우 느림
- **적당함**: ~100스텝 내 수렴

공식은 없습니다. 실험으로 찾습니다. 일반적인 시작점: Adam은 0.001, 모멘텀 SGD는 0.01.

### SGD vs 배치 vs 미니배치

| 변형 | 배치 크기 | 기울기 품질 | 스텝당 속도 | 노이즈 |
|------|----------|-----------|-----------|-------|
| 배치 GD | 전체 데이터셋 | 정확 | 느림 | 없음 |
| SGD | 1 샘플 | 매우 노이즈 | 빠름 | 높음 |
| 미니배치 | 32-256 | 좋은 추정 | 균형 | 중간 |

SGD/미니배치의 노이즈는 버그가 아닙니다. 얕은 지역 최소값과 안장점에서 탈출하는 데 도움이 됩니다.

### 모멘텀: 내리막길을 구르는 공

```
v = beta * v + gradient
w = w - lr * v
```

바닐라 SGD는 현재 기울기만 봅니다. 지그재그(좁은 계곡에서 흔함)에서는 진행이 느립니다. 모멘텀은 과거 기울기를 속도 항으로 누적하여 이를 해결합니다. beta=0.9가 일반적입니다.

### Adam (Adaptive Moment Estimation)

모멘텀 + 적응적 학습률의 결합:

```python
# Adam 업데이트 규칙
m = beta1 * m + (1 - beta1) * gradient      # 1차 모멘트 (모멘텀)
v = beta2 * v + (1 - beta2) * gradient**2   # 2차 모멘트 (적응적 스케일링)
m_hat = m / (1 - beta1**t)                   # 편향 보정
v_hat = v / (1 - beta2**t)
w = w - lr * m_hat / (sqrt(v_hat) + epsilon)
```

각 가중치가 자체 학습률을 가집니다. 자주 업데이트되는 가중치는 작은 걸음을, 드물게 업데이트되는 가중치는 큰 걸음을 갖습니다.

### 학습률 스케줄

- **단계 감쇠**: N 에포크마다 lr을 γ만큼 곱함
- **코사인 어닐링**: lr이 코사인 곡선을 따라 0으로 감소. 트랜스포머 훈련의 표준
- **웜업**: 처음 K 스텝 동안 lr을 0에서 목표까지 선형 증가. 큰 배치/깊은 모델 안정화

## 빌드하기

### Adam from-scratch

```python
class Adam:
    def __init__(self, params, lr=0.001, beta1=0.9, beta2=0.999, eps=1e-8):
        self.params = list(params)
        self.lr, self.beta1, self.beta2, self.eps = lr, beta1, beta2, eps
        self.m = [0.0] * len(self.params)
        self.v = [0.0] * len(self.params)
        self.t = 0

    def step(self):
        self.t += 1
        for i, p in enumerate(self.params):
            if p.grad is None: continue
            g = p.grad
            self.m[i] = self.beta1 * self.m[i] + (1 - self.beta1) * g
            self.v[i] = self.beta2 * self.v[i] + (1 - self.beta2) * g * g
            m_hat = self.m[i] / (1 - self.beta1 ** self.t)
            v_hat = self.v[i] / (1 - self.beta2 ** self.t)
            p.data -= self.lr * m_hat / (v_hat ** 0.5 + self.eps)
```

### 볼록 vs 비볼록

- **볼록**: 모든 지역 최소값이 전역 최소값. 하나의 골짜기
- **비볼록**: 많은 골짜기, 안장점. 신경망은 비볼록 — 그러나 고차원(수백만 가중치)에서는 실제 문제가 거의 되지 않음

안장점: 어떤 방향은 위, 어떤 방향은 아래. SGD 노이즈가 밀어내는 데 도움.

| 용어 | 실제 의미 |
