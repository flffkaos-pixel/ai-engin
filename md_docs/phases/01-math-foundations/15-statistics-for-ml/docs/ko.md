# 머신러닝을 위한 통계

> 통계는 모델이 실제로 작동하는지 아니면 그냥 운이 좋았는지 아는 방법입니다.

**유형:** 빌드
**언어:** Python
**선수 과목:** Phase 1, Lessons 06-07
**시간:** ~120분

## 학습 목표

- 기술 통계, Pearson/Spearman 상관관계, 공분산 행렬을 처음부터 계산하기
- 가설 검정(t-검정, 카이제곱)을 수행하고 p-값과 신뢰 구간을 올바르게 해석하기
- 분포 가정 없이 모든 측정 지표에 대한 신뢰 구간을 구성하기 위해 부트스트랩 재표집 사용하기
- 효과 크기 측정을 사용하여 통계적 유의성과 실제적 유의성 구별하기

## 문제

두 모델을 훈련했습니다. 모델 A는 테스트 세트에서 0.87, 모델 B는 0.89. 모델 B를 배포합니다. 3주 후 프로덕션 지표가 더 나빠집니다.

모델 B가 실제로 모델 A를 능가하지 않았습니다. 0.02 차이는 노이즈였습니다. 테스트 세트가 너무 작거나 분산이 너무 높았거나 둘 다였습니다. 개선으로 포장된 무작위성을 배포한 것입니다.

통계는 신호와 노이즈를 구별하는 도구를 제공합니다.

## 개념

### 기술 통계: 데이터 요약

**중심 경향성 측정** — "중간이 어디인가?"

| 측정치 | 의미 | 사용 시기 |
|--------|------|----------|
| 평균 | 균형점 | 대칭 분포 |
| 중앙값 | 절반 지점 | 편향된 데이터, 이상치 존재 |
| 최빈값 | 가장 빈번한 값 | 범주형 데이터 |

평균과 중앙값이 갈라지면 분포가 편향된 것입니다.

**산포도 측정** — "데이터가 얼마나 퍼져 있는가?"

- **분산**: σ² = (1/n)Σ(xᵢ-μ)² (표본에서는 n-1로 나눔 — 베셀 보정)
- **표준편차**: σ = √σ² — 데이터와 같은 단위, 더 해석 가능
- **IQR**: Q3 - Q1 — 중간 50% 범위, 이상치에 강건

**백분위수**: ML 추론 지연 시간에 중요 — P50(중앙값), P95, P99(꼬리 지연 시간)

### 상관관계

- **Pearson**: 선형 관계 측정, -1에서 1. 정규성 가정
- **Spearman**: 순위 기반, 단조 관계 측정. 이상치에 더 강건

`상관관계 ≠ 인과관계`: 두 변수가 함께 움직인다고 해서 하나가 다른 하나를 유발하는 것은 아님.

### 가설 검정

1. **귀무가설(H₀)**: "차이 없다" (기본 가정)
2. **p-값**: H₀가 참일 때 관측된(또는 더 극단적인) 결과를 볼 확률
3. **α = 0.05**: p < 0.05이면 귀무가설 기각

**p-값이 알려주지 않는 것**: 효과의 크기, 결과의 실용적 중요성, 대립가설이 참일 확률.

### 부트스트랩

```python
import numpy as np

def bootstrap_ci(data, statistic=np.mean, n_bootstrap=10000, ci=95):
    stats = []
    n = len(data)
    for _ in range(n_bootstrap):
        sample = np.random.choice(data, size=n, replace=True)
        stats.append(statistic(sample))
    lower = np.percentile(stats, (100 - ci) / 2)
    upper = np.percentile(stats, 100 - (100 - ci) / 2)
    return lower, upper
```

모든 측정 지표(정확도, F1, AUC)의 신뢰 구간 계산. 분포 가정 필요 없음.

### 효과 크기

- **Cohen's d**: (μ₁ - μ₂) / σ_pooled. 0.2=작음, 0.5=중간, 0.8=큼
- **통계적 유의성**: "차이가 0이 아닐 가능성이 높다"
- **실제적 유의성**: "차이가 관심을 가질 만큼 충분히 큰가"

큰 표본은 사소한 차이도 통계적으로 유의하게 만듭니다. 효과 크기가 실제로 중요한지 알려줍니다.

## 주요 용어

| 용어 | 실제 의미 |
|------|----------|
| p-값 | H₀ 하에서 관측된 결과의 확률 — 차이의 크기나 중요성을 측정하지 않음 |
| 신뢰 구간 | 참 값이 있을 가능성이 높은 범위 |
| 부트스트랩 | 신뢰 구간을 위한 재표집 방법 — 분포 무관 |
| Cohen's d | 표준화된 차이 — 0.2 작음, 0.5 중간, 0.8 큼 |
| 베셀 보정 | 표본 분산에 n 대신 n-1 사용 — 불편 추정량 |
