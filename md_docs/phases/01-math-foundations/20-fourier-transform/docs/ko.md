- DFT를 처음부터 구현하고 O(N log N) Cooley-Tukey FFT와 비교 검증하기
- 진폭, 위상, 전력 스펙트럼을 신호에서 추출하여 주파수 계수 해석하기

## 문제

오디오 녹음은 시간에 따른 압력 측정의 시퀀스입니다. 이미지는 공간에 대한 픽셀 강도의 격자입니다. 모두 시간 영역(또는 공간 영역)의 데이터입니다.

그러나 많은 패턴은 시간 영역에서 보이지 않습니다. 이 오디오 신호는 단일 톤인가 화음인가? 이 이미지에 반복되는 텍스처가 있는가? 이러한 질문은 주파수 내용에 관한 것이며, 시간 영역은 이를 숨깁니다.

푸리에 변환은 데이터를 시간 영역에서 주파수 영역으로 변환합니다. 신호를 받아 서로 다른 주파수의 사인파로 분해합니다.

## 개념

### DFT 정의

```
X[k] = Σ_{n=0}^{N-1} x[n] * e^(-2πi·k·n/N)  (k = 0, 1, ..., N-1)
```

- **X[0] (DC 성분)**: 신호의 평균/상수 오프셋
- **X[1..N/2-1]**: 양의 주파수. k가 클수록 높은 주파수
- **X[N/2] (나이퀴스트)**: N개 샘플로 표현 가능한 최고 주파수. 이 이상 = 에일리어싱
- **X[N/2+1..N-1]**: 음의 주파수. 실수 신호의 경우 X[N-k] = conj(X[k])

### 역 DFT

```
x[n] = (1/N) Σ_{k=0}^{N-1} X[k] * e^(2πi·k·n/N)
```

### 주요 속성

- **선형성**: FFT(ax + by) = a·FFT(x) + b·FFT(y)
- **합성곱 정리**: FFT(x ⊛ y) = FFT(x) * FFT(y) (요소별 곱)
- **주파수 이동**: 시간 영역 변조 = 주파수 영역 이동
- **파스발 정리**: 총 에너지는 양 영역에서 동일

### ML에서의 응용

- **CNN**: 합성곱은 주파수 영역에서의 곱셈. 큰 커널에 더 빠름
- **Transformer 위치 인코딩**: sin/cos 함수가 DFT의 기저 함수
- **스펙트로그램**: 시간-주파수 표현 — 모든 오디오 모델의 입력
- **특징 추출**: 푸리에 설명자, 시간-주파수 분석

## 빌드하기

### DFT (O(N²))

```python
import cmath

def dft(x):
    N = len(x)
    X = [0] * N
    for k in range(N):
        X[k] = sum(x[n] * cmath.exp(-2j * cmath.pi * k * n / N)
                    for n in range(N))
    return X
```

### Python에서 FFT (O(N log N))

```python
import numpy as np

x = np.array([1.0, 2.0, 1.0, -1.0, 0.5])
X = np.fft.fft(x)        # DFT
x_recon = np.fft.ifft(X)  # 역 DFT
magnitude = np.abs(X)     # 진폭 스펙트럼
phase = np.angle(X)       # 위상 스펙트럼
```

### 합성곱 정리

```python
# 시간 영역 합성곱 대신:
conv_result = np.fft.ifft(np.fft.fft(a) * np.fft.fft(b))
# 큰 신호에 대해 O(N log N) vs O(N²)
```

## 주요 용어

| 용어 | 실제 의미 |
|------|----------|
| DFT | 신호 → 주파수 성분. 각 X[k]는 복소수 |
| FFT | DFT의 빠른 구현 — O(N log N) |
| 진폭 스펙트럼 | |X[k]| — 각 주파수의 강도 |
| DC 성분 | X[0] — 평균/상수 오프셋 |
| 나이퀴스트 | X[N/2] — 표현 가능한 최고 주파수 |
| 합성곱 정리 | 주파수 영역 곱셈 = 시간 영역 합성곱 |
