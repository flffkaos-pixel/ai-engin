그래프 신경망(GNN)은 딥러닝에서 가장 빠르게 성장하는 영역입니다. 신약 발견, 소셜 추천, 사기 탐지, 지식 그래프 추론을 지원합니다.

## 개념

### 그래프: 노드와 엣지

G = (V, E). V는 정점(노드), E는 엣지.

| 그래프 유형 | 예시 |
|-----------|------|
| 무향, 비가중 | Facebook 친구 네트워크 |
| 유향, 비가중 | Twitter 팔로우 네트워크 |
| 무향, 가중 | 도로 지도 (거리) |
| 유향, 가중 | 웹 페이지 링크 (PageRank) |

### 인접 행렬

A[i][j] = 엣지가 있으면 1(또는 가중치), 없으면 0. 무향 그래프는 A가 대칭.

### 그래프 라플라시안

L = D - A. D는 차수 행렬(대각선에 각 노드의 차수).

속성: L은 대칭 양의 준정부호. 0의 개수 = 연결 성분 수. 두 번째로 작은 고윳값(λ₂, Fiedler 값) = 그래프 연결성 측정. 해당 고유벡터(Fiedler 벡터)로 그래프 분할 가능.

### 메시지 전달 (GNN의 핵심)

```
H^(l+1) = σ(D̂^(-1/2) * Â * D̂^(-1/2) * H^(l) * W^(l))

Â = A + I (자기 루프 추가)
D̂ = Â의 차수 행렬
H^(l) = 레이어 l의 노드 특성
W^(l) = 학습 가능한 가중치
σ = 활성화 함수
```

직관: 각 노드가 이웃으로부터 메시지를 받아 자신의 표현을 업데이트.

### 스펙트럼 클러스터링

1. 그래프 라플라시안 L 계산
2. L의 첫 k개 고유벡터 계산
3. 이 고유벡터로 행렬 형성 (행 = 노드)
4. k-평균으로 행 클러스터링

Fiedler 벡터(두 번째 고유벡터)만으로도 이진 분할 가능 — 부호로 분리.

## 빌드하기

```python
class Graph:
    def __init__(self, n_nodes, directed=False):
        self.n = n_nodes
        self.directed = directed
        self.adj = [[0]*n_nodes for _ in range(n_nodes)]

    def add_edge(self, u, v, weight=1):
        self.adj[u][v] = weight
        if not self.directed:
            self.adj[v][u] = weight

    def bfs(self, start):
        visited = [False] * self.n
        queue = [start]; visited[start] = True; order = []
        while queue:
            v = queue.pop(0); order.append(v)
            for u in range(self.n):
                if self.adj[v][u] and not visited[u]:
                    visited[u] = True; queue.append(u)
        return order
```

3. Fiedler 벡터로 두 클러스터 그래프 분할. 각 노드가 올바른 쪽에 있는지 확인

## 주요 용어

| 용어 | 실제 의미 |
|------|----------|
| 인접 행렬 | A[i][j] = 노드 i→j 엣지 |
| 차수 행렬 | D[i][i] = 노드 i의 엣지 수 |
| 라플라시안 | L = D - A. 스펙트럼 분석의 핵심 |
| Fiedler 벡터 | λ₂의 고유벡터 — 최적 그래프 분할 |
| 메시지 전달 | 이웃 특성 집계 — GNN 작동 방식 |
