## 문제

푸리에 변환 논문을 열면 모든 곳에 `i`가 있습니다. 트랜스포머 위치 인코딩을 보면 서로 다른 주파수의 sin과 cos — 복소 지수의 실수부와 허수부. 양자 컴퓨팅을 읽으면 모든 것이 복소 벡터 공간으로 표현됩니다.

복소수는 추상적으로 보입니다. i² = -1에 기반한 수 체계는 수학적 트릭처럼 느껴집니다. 하지만 트릭이 아닙니다. 회전과 진동의 자연스러운 언어입니다.

## 개념

### 복소수란?

z = a + bi (a는 실수부, b는 허수부, i² = -1). 수직선을 평면으로 확장합니다.

### 복소수 산술

- **덧셈**: (a+bi) + (c+di) = (a+c) + (b+d)i
- **곱셈**: (a+bi)(c+di) = (ac-bd) + (ad+bc)i

### 극 형식

z = re^(iθ) = r(cos θ + i sin θ). r = 크기, θ = 각도(위상).

곱셈: `r₁e^(iθ₁) * r₂e^(iθ₂) = r₁r₂ * e^(i(θ₁+θ₂))`. 크기는 곱하고 각도는 더함.

### 오일러 공식

`e^(iθ) = cos θ + i sin θ` — 지수, 삼각법, 복소수를 통합하는 "수학에서 가장 아름다운 공식". e^(iπ) + 1 = 0.

### AI에서의 응용

**RoPE (회전 위치 임베딩)**: 쿼리/키 벡터를 위치에 비례하는 각도로 회전:
```
f(x, pos) = x * e^(i*pos*freq)  — 복소 평면에서 회전
```

**사인파 위치 인코딩**: 원본 Transformer — 서로 다른 주파수의 sin/cos.

**DFT**: 신호를 서로 다른 주파수에서의 복소 상관관계로 분해.

### Python에서

```python
import cmath

z = 3 + 4j
print(f"크기: {abs(z)}")       # 5.0
print(f"위상: {cmath.phase(z)}")  # 0.927 rad

# 오일러
theta = cmath.pi / 4
z_rot = cmath.exp(1j * theta)  # 45도 회전
```
