## 문제

모든 분류 모델에서 `CrossEntropyLoss()`를 호출합니다. 모든 언어 모델 논문에서 "perplexity"를 봅니다. VAE, 증류, RLHF에서 KL 발산에 대해 읽습니다. 이것들은 별개의 개념이 아닙니다. 모두 다른 모자를 쓴 같은 아이디어입니다.

정보 이론은 불확실성, 압축, 예측에 대해 추론할 수 있는 언어를 제공합니다. Claude Shannon이 1948년 통신 문제를 해결하기 위해 발명했습니다. 신경망 훈련도 통신 문제입니다: 모델이 학습된 가중치의 노이즈 채널을 통해 올바른 레이블을 전송하려는 것입니다.

## 개념

### 정보량 (놀라움)

확률 p인 사건의 정보량: `I(x) = -log(p(x))`

| 사건 | 확률 | 놀라움 (비트) |
|------|------|-------------|
| 공정한 동전 앞면 | 0.5 | 1.0 |
| 주사위 6 | 0.167 | 2.58 |
| 1000분의 1 사건 | 0.001 | 9.97 |
| 확실한 사건 | 1.0 | 0.0 |

### 엔트로피 (평균 놀라움)

`H(P) = -Σ p(x) * log(p(x))`

분포의 불가역적 불확실성을 측정합니다. 이 이하로 압축할 수 없습니다.

공정한 동전: 1.0 비트. 편향된 동전(99% 앞면): 0.08 비트.

### 교차 엔트로피 (매일 사용하는 손실 함수)

`H(P, Q) = -Σ p(x) * log(q(x))`

P는 실제 분포(레이블), Q는 모델의 예측. 분류에서 P는 원-핫 벡터 → `H(P,Q) = -log(q(정답_클래스))` — 이것이 바로 음의 로그 가능도입니다.

### KL 발산

`KL(P || Q) = Σ p(x) * log(p(x)/q(x)) = H(P,Q) - H(P)`

P 대신 Q를 사용할 때 추가되는 놀라움. 비대칭적이며 KL(P||Q) ≠ KL(Q||P).

- **순방향 KL**: Q가 P를 지원하는 모든 곳에서 확률 > 0이어야 함 — "질량 보존"
- **역방향 KL**: Q가 P의 모드에 집중 — 변분 추론에서 사용

### 상호 정보량

`I(X; Y) = H(X) - H(X|Y)`

Y를 알 때 X에 대해 얻는 정보. 특성 선택에 사용: I(특성; 타겟)이 높을수록 특성이 더 유용합니다.

### 퍼플렉서티

`Perplexity = 2^(H(P,Q))` (비트 사용 시) 또는 `exp(H(P,Q))` (내트 사용 시)

"모델이 각 토큰에서 효과적으로 선택하는 가지 수". GPT-4의 퍼플렉서티가 ~5라면, 매번 5개의 동등하게 가능성 있는 선택지 중에서 고르는 것과 같은 불확실성입니다.

## 빌드하기

```python
import math

def entropy(probs):
    return -sum(p * math.log2(p) for p in probs if p > 0)

def cross_entropy(probs_p, probs_q):
    return -sum(p * math.log2(q) for p, q in zip(probs_p, probs_q) if p > 0)

def kl_divergence(probs_p, probs_q):
    return sum(p * math.log2(p/q) for p, q in zip(probs_p, probs_q) if p > 0)
```
