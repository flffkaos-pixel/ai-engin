# 볼록 최적화

> 볼록 문제에는 하나의 골짜기가 있습니다. 신경망에는 수백만 개가 있습니다. 그 차이를 아는 것이 중요합니다.

**유형:** 빌드
**언어:** Python
**선수 과목:** Phase 1, Lessons 04, 08
**시간:** ~90분

## 학습 목표

- 정의, 2차 도함수, 헤시안 기준을 사용하여 함수의 볼록성 검사하기
- 뉴턴 방법 구현하고 경사하강법과의 2차 수렴 비교하기
- 라그랑주 승수를 사용하여 제약 최적화 문제 풀고 KKT 조건 해석하기
- 신경망 손실 지형이 비볼록인데도 SGD가 좋은 해를 찾는 이유 설명하기

## 문제

경사하강법, 모멘텀, Adam은 모든 표면에서 내리막길을 걷습니다. 하지만 보장이 없습니다. 비볼록 지형에서 경사하강법은 나쁜 지역 최소값에 빠지거나 안장점에 갇히거나 영원히 진동할 수 있습니다.

그러나 ML의 많은 문제는 볼록합니다: 선형 회귀, 로지스틱 회귀, SVM, LASSO, Ridge. 볼록 문제에는 정확히 하나의 골짜기가 있습니다. 내리막길을 걷는 모든 알고리즘이 전역 최소값에 도달합니다.

## 개념

### 볼록 집합

집합 S가 볼록하다: S의 임의의 두 점에 대해, 그 사이의 선분도 완전히 S에 포함됨.

볼록: 직사각형, 원, 반공간
비볼록: 도넛, 별 모양, 두 분리된 원의 합집합

### 볼록 함수

f(tx + (1-t)y) ≤ t·f(x) + (1-t)·f(y) — 그래프 위의 두 점을 잇는 선분이 그래프 위에 있음.

검사 방법:
- **1D**: f''(x) ≥ 0 모든 x에 대해
- **nD**: 헤시안 ∇²f(x)가 양의 준정부호
- **Jensen 부등식**: f(E[X]) ≤ E[f(X)]

볼록 함수 예: x², -log(x), ||x||, softmax의 로그 합

### 뉴턴 방법

경사하강법: x ← x - lr·∇f(x)
뉴턴 방법: x ← x - [∇²f(x)]⁻¹·∇f(x)

뉴턴 방법은 2차 수렴(오차가 매 단계 제곱으로 감소) vs 경사하강법의 선형 수렴. 단점: 헤시안 계산 및 역행렬 O(n³).

### 라그랑주 승수

제약 최적화: `maximize f(x) subject to g(x) = 0`

라그랑지안: L(x, λ) = f(x) - λ·g(x). 정류점에서 ∇f = λ∇g — 기울기가 평행.

KKT 조건: 부등식 제약으로 일반화. SVM, 제약 RL의 기초.

### 신경망이 비볼록인데도 작동하는 이유

- 고차원에서 대부분의 안장점은 엄격한 안장점(일부 방향은 하강)
- SGD 노이즈가 얕은 최소값에서 밀어냄
- 과매개변수화: 넓은 네트워크에서 모든 지역 최소값이 비슷하게 좋음
- 손실 지형이 실제로는 예상보다 더 볼록에 가까움(가중치 공간의 큰 영역이 연결됨)

## 주요 용어

| 용어 | 실제 의미 |
|------|----------|
| 볼록 함수 | 하나의 전역 최소값. 선분 ≥ 함수값 |
| 뉴턴 방법 | 2차 방법 — 헤시안으로 더 나은 단계. 2차 수렴 |
| 라그랑주 승수 | 제약을 목적 함수로 변환 |
| KKT 조건 | 부등식 제약 하 최적화의 필요 조건 |
| 안장점 | 기울기 0, 헤시안 부정부호 — 비볼록 지형의 주요 장애물 |
