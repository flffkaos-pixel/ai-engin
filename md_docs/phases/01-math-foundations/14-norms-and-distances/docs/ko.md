- L1, L2, 코사인, 마할라노비스, 자카드, 편집 거리 함수를 처음부터 구현하기
- 주어진 ML 작업에 적절한 거리 측정법 선택하고 대안이 실패하는 이유 설명하기

- 서로 다른 측정법에서 동일한 데이터셋이 다른 최근접 이웃을 생성함을 시연하기

## 문제

두 벡터가 있습니다 — 단어 임베딩, 사용자 프로필, 픽셀 배열. 얼마나 가까운가요?

답은 전적으로 어떤 거리 함수를 선택하느냐에 달려 있습니다. 두 데이터 포인트는 한 측정법에서는 최근접 이웃이고 다른 측정법에서는 멀리 떨어져 있을 수 있습니다. KNN 분류기, 추천 엔진, 벡터 데이터베이스, 클러스터링 알고리즘, 손실 함수 — 모두 이 선택에 의존합니다.

보편적으로 최고인 거리는 없습니다. L2는 공간 데이터. 코사인 유사도는 NLP. 자카드는 집합. 편집 거리는 문자열. 마할라노비스는 상관관계 고려.

## 개념

### L1 노름 (맨해튼 거리)

`||x||₁ = |x₁| + |x₂| + ... + |xₙ|`

도시 그리드에서 축을 따라 걷는 거리.

사용 시기: 고차원 희소 데이터, 이상치에 강건해야 할 때, 특성 선택(L1 정규화 = Lasso)

**Lasso 회귀**: `loss + λ||w||₁`. 작은 가중치를 정확히 0으로 만들어 자동 특성 선택.

### L2 노름 (유클리드 거리)

`||x||₂ = √(x₁² + x₂² + ... + xₙ²)`

직선 거리. n차원 피타고라스.

사용 시기: 공간 데이터, 이상치에 민감해도 될 때, 연속 특성.

**Ridge 회귀**: `loss + λ||w||₂²`. 모든 가중치를 0에 가깝게 축소하지만 정확히 0으로 만들지는 않음.

### 코사인 유사도

`cos(a,b) = (a·b) / (||a|| ||b||)`

벡터 간 각도 측정. 크기 불변. NLP의 표준 — 단어/문장 임베딩 비교에 사용. 코사인 거리 = 1 - 코사인 유사도.

### 마할라노비스 거리

`d(x,y) = √((x-y)ᵀ Σ⁻¹ (x-y))`

공분산 역행렬로 스케일링된 유클리드 거리. 특성 간 상관관계를 고려. 이상치 탐지에 사용.

### 자카드 유사도

`J(A,B) = |A ∩ B| / |A ∪ B|`

두 집합의 중첩 측정. 텍스트 n-gram 비교, 추천 시스템, 중복 탐지.

### 편집 거리 (Levenshtein)

한 문자열을 다른 문자열로 변환하는 최소 편집(삽입/삭제/대체) 횟수. 오타 수정, DNA 서열 정렬.

## 빌드하기

```python
import math

def l1_distance(a, b):
    return sum(abs(x - y) for x, y in zip(a, b))

def l2_distance(a, b):
    return math.sqrt(sum((x - y)**2 for x, y in zip(a, b)))

def cosine_similarity(a, b):
    dot = sum(x*y for x, y in zip(a, b))
    norm_a = math.sqrt(sum(x**2 for x in a))
    norm_b = math.sqrt(sum(y**2 for y in b))
    return dot / (norm_a * norm_b)

def jaccard_similarity(a, b):
    set_a, set_b = set(a), set(b)
    return len(set_a & set_b) / len(set_a | set_b)
```

## 주요 용어

| 용어 | 실제 의미 |
|------|----------|
| L1/맨해튼 | 절대 차이의 합 — 격자 기반 거리, 희소성 촉진 |
| L2/유클리드 | 직선 거리 — 연속 공간의 표준 |
| 코사인 | 벡터 간 각도 — 크기 불변, NLP 표준 |
| 마할라노비스 | 공분산으로 스케일링 — 상관관계 고려 |
| 자카드 | 교집합/합집합 — 집합 중첩 측정 |
| 편집 거리 | 최소 문자 편집 — 문자열 비교 |
