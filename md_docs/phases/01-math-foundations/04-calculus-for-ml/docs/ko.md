## 문제

수백만 개의 가중치가 있는 신경망이 있습니다. 각 가중치는 조절 손잡이입니다. 모델을 약간 덜 틀리게 만들기 위해 모든 손잡이를 어느 방향으로 돌려야 하는지 알아내야 합니다. 미적분이 그 방향을 알려줍니다.

## 개념

### 도함수란?

도함수는 변화율을 측정합니다. y = f(x)에서 f'(x)는: x를 아주 조금 움직이면 y가 얼마나 변하는가?

기하학적으로 도함수는 한 점에서 접선의 기울기입니다.

**f(x) = x²:**
| x | f'(x) | 의미 |
|---|-------|------|
| 0 | 0 | 평평함 (바닥!) |
| 2 | 4 | 오른쪽으로 가면 y가 4배 빠르게 증가 |

### 편도함수

실제 함수는 많은 입력을 가집니다. 편도함수는 하나를 제외한 모든 변수를 상수로 고정합니다.

```
f(x,y) = x² + 3xy + y²
∂f/∂x = 2x + 3y  (y는 상수로 취급)
∂f/∂y = 3x + 2y  (x는 상수로 취급)
```

### 기울기(Gradient)

기울기는 모든 편도함수를 하나의 벡터로 모읍니다. 가장 가파른 상승 방향을 가리킵니다. 최소화하려면 반대 방향으로 가세요.

```
경사하강법 업데이트 규칙:
w_new = w_old - 학습률 * ∂L/∂w
```

### 수치적 vs 해석적 도함수

- **해석적**: 미적분 규칙 적용. f(x)=x² → f'(x)=2x. 정확하고 빠름.
- **수치적**: 정의 사용. (f(x+h) - f(x-h)) / (2h). 느리지만 모든 함수에 작동.

신경망 프레임워크는 자동 미분이라는 세 번째 접근법을 사용합니다.

### ML에서 자주 보는 도함수

| 함수 | 도함수 | 사용처 |
|------|--------|--------|
| f(x)=x² | f'(x)=2x | 손실 함수 (MSE) |
| f(x)=wx+b | f'(w)=x | 선형 레이어 |
| f(x)=e^x | f'(x)=e^x | 소프트맥스, 어텐션 |
| f(x)=ln(x) | f'(x)=1/x | 교차 엔트로피 손실 |
| f(x)=1/(1+e^-x) | f'(x)=f(x)(1-f(x)) | 시그모이드 활성화 |

### 연쇄 법칙

합성 함수 미분: y = f(g(x)) → dy/dx = f'(g(x)) * g'(x)

신경망은 함수의 연쇄입니다: 입력 → 선형 → 활성화 → 선형 → 활성화 → 손실. 역전파는 출력에서 입력까지 연쇄 법칙을 반복 적용하는 것입니다.

### 헤시안 행렬

기울기가 기울기를 알려준다면, 헤시안은 곡률을 알려줍니다.

임계점(기울기=0)에서:

| 헤시안 | 의미 |
|--------|------|
| 양의 정부호 (모든 고윳값 > 0) | 지역 최소값 |
| 음의 정부호 (모든 고윳값 < 0) | 지역 최대값 |
| 부정부호 (혼합 고윳값) | 안장점 |

뉴턴 방법: `w_new = w_old - H^(-1) * gradient` — 곡률을 고려하므로 경사하강법보다 빠르게 수렴. 단점: N개 파라미터에 대해 N×N 헤시안 필요.

| 방법 | 사용하는 것 | 단계당 비용 | 수렴 |
|------|-----------|-----------|------|
| 경사하강법 | 1차 도함수만 | O(N) | 느림 |
| 뉴턴 방법 | 전체 헤시안 | O(N³) | 빠름 |
| Adam | 대각 헤시안 근사 | O(N) | 중간 |

실제로 Adam이 딥러닝의 기본 옵티마이저입니다.

### 테일러 급수

모든 매끄러운 함수는 국소적으로 다항식으로 근사 가능:
```
f(x+h) = f(x) + f'(x)h + (1/2)f''(x)h² + ...
```
- 1차 = 경사하강법
- 2차 = 뉴턴 방법
- 모든 기울기 기반 최적화는 손실 함수를 국소적으로 근사하고 그 근사의 최소값으로 이동하는 것입니다.

## 빌드하기

### 수치적 도함수

```python
def numerical_derivative(f, x, h=1e-7):
    return (f(x + h) - f(x - h)) / (2 * h)

def f(x): return x**2
# f'(2) ≈ 4.000000
```

### 수치적 기울기

```python
def numerical_gradient(f, point, h=1e-7):
    gradient = []
    for i in range(len(point)):
        point_plus = list(point); point_minus = list(point)
        point_plus[i] += h; point_minus[i] -= h
        partial = (f(point_plus) - f(point_minus)) / (2 * h)
        gradient.append(partial)
    return gradient
```

### 경사하강법

```python
# f(x) = x²의 최소값 찾기
x = 5.0; lr = 0.1
for step in range(20):
    grad = 2 * x
    x = x - lr * grad  # x → 0으로 수렴
```

### 2D 경사하강법

```python
def f_2d(point): x, y = point; return x**2 + y**2
point = [4.0, 3.0]; lr = 0.1
for step in range(30):
    grad = numerical_gradient(f_2d, point)
    point = [p - lr * g for p, g in zip(point, grad)]
    # (4,3) → (0,0)으로 수렴
```

## 활용하기

신경망의 모든 가중치가 기울기를 얻습니다. 기울기는 손실을 줄이기 위해 가중치를 어떻게 조정할지 알려줍니다.

순전파: 입력 → W1 → relu → W2 → softmax → 손실
역전파: ∂L/∂loss → ∂L/∂W2 → ... → ∂L/∂W1

각 가중치 업데이트: W = W - lr * ∂L/∂W. 수백만 번 반복. 이것이 딥러닝입니다.

## 주요 용어

| 용어 | 실제 의미 |
|------|----------|
| 도함수 | 변화율. 한 변수의 작은 변화가 출력에 얼마나 영향을 주는지 |
| 편도함수 | 하나의 변수만 변할 때의 변화율, 다른 변수는 고정 |
| 기울기 | 가장 가파른 상승을 가리키는 모든 편도함수의 벡터 |
| 경사하강법 | 반대 방향으로 작은 걸음 반복하여 함수 최소화 |
| 연쇄 법칙 | 합성 함수 미분 규칙 — 역전파의 전체 알고리즘 |
| 헤시안 | 2차 도함수 행렬 — 곡률 측정. 뉴턴 방법에 사용 |
| 학습률 | 각 단계의 크기 제어. 너무 크면 오버슈트, 너무 작으면 느림 |
