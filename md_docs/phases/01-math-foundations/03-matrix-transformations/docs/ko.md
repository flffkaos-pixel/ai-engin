## 개념

### 변환으로서의 행렬

2D의 모든 선형 변환은 2x2 행렬로 작성할 수 있습니다. 행렬은 기저 벡터 [1,0]과 [0,1]이 어디로 가는지 정확히 알려줍니다. 나머지는 모두 따라옵니다.

### 회전 (Rotation)

각도 θ만큼의 2D 회전:
```
R(θ) = [[cos θ, -sin θ], [sin θ, cos θ]]
```
거리와 각도를 보존합니다. 행렬식은 항상 1.

3D 회전 행렬:
- Rz(θ): z축 기준 회전 (x-y 평면이 회전, z는 유지)
- Rx(θ): x축 기준 회전
- Ry(θ): y축 기준 회전

### 크기 조정 (Scaling)

각 축을 독립적으로 늘이거나 압축합니다.
```
S = [[sx, 0], [0, sy]]
```
행렬식 = sx * sy.

### 전단 (Shearing)

한 축을 기울이고 다른 축은 고정합니다. 직사각형을 평행사변형으로 바꿉니다.
```
Shx = [[1, k], [0, 1]]  — x를 k*y만큼 이동
```

### 반사 (Reflection)

```
y축 반사: [[-1, 0], [0, 1]]
x축 반사: [[1, 0], [0, -1]]
```
행렬식 = -1 (방향 뒤집힘).

### 합성: 변환 연결하기

A 다음 B 적용 = `result = B @ A @ point`. 순서가 중요합니다. 회전 후 크기 조정 ≠ 크기 조정 후 회전. 행렬 곱셈은 교환 법칙이 성립하지 않습니다.

### 고윳값과 고유벡터

대부분의 벡터는 행렬에 의해 방향이 바뀝니다. 고유벡터는 특별합니다: 행렬이 크기만 조정하고 절대 회전시키지 않습니다.

```
A @ v = λ * v

v = 고유벡터 (살아남는 방향)
λ = 고윳값 (얼마나 늘어나는지)
```

예: A = [[2, 1], [1, 2]]
- 고유벡터 [1, 1], 고윳값 3 → 같은 방향, 3배로 조정
- 고유벡터 [1, -1], 고윳값 1 → 같은 방향, 변화 없음

### 고유분해

A = V @ D @ V^(-1). "고유벡터 좌표로 회전, 각 축을 따라 크기 조정, 다시 회전"을 의미합니다.

### 고윳값이 중요한 이유

- **PCA**: 공분산 행렬의 고유벡터가 주성분. 고윳값이 각 성분의 분산량을 알려줌
- **안정성**: |λ| > 1이면 폭발, |λ| < 1이면 소멸 — 기울기 소실/폭발 문제
- **스펙트럼 방법**: 그래프 신경망은 인접 행렬의 고윳값 사용

### 행렬식: 부피 조정 계수

```
det = 1: 면적 보존 (회전)
det = 2: 면적 2배
det = 0: 공간이 낮은 차원으로 소멸 (특이 행렬)
det = -1: 면적 보존, 방향 뒤집힘 (반사)
```

## 빌드하기

### 변환 행렬 함수

```python
import math

def rotation_2d(theta):
    c, s = math.cos(theta), math.sin(theta)
    return [[c, -s], [s, c]]

def scaling_2d(sx, sy):
    return [[sx, 0], [0, sy]]

def shearing_2d(kx, ky):
    return [[1, kx], [ky, 1]]

def mat_vec_mul(matrix, vector):
    return [sum(matrix[i][j] * vector[j] for j in range(len(vector)))
            for i in range(len(matrix))]
```

### 고윳값 계산 (2x2)

특성 방정식: `λ² - (a+d)λ + (ad-bc) = 0`

```python
def eigenvalues_2x2(matrix):
    a, b = matrix[0]; c, d = matrix[1]
    trace = a + d; det = a * d - b * c
    discriminant = trace**2 - 4 * det
    sqrt_disc = discriminant ** 0.5
    return ((trace + sqrt_disc)/2, (trace - sqrt_disc)/2)
```

## 활용하기 (NumPy)

```python
import numpy as np

theta = np.pi / 4
R = np.array([[np.cos(theta), -np.sin(theta)],
              [np.sin(theta),  np.cos(theta)]])
point = np.array([1.0, 0.0])
print(f"45도 회전: {R @ point}")

A = np.array([[2, 1], [1, 2]], dtype=float)
eigenvalues, eigenvectors = np.linalg.eig(A)
print(f"고윳값: {eigenvalues}")
print(f"고유벡터:\n{eigenvectors}")

# 고유분해: A = V @ D @ V^(-1)
D = np.diag(eigenvalues)
reconstructed = eigenvectors @ D @ np.linalg.inv(eigenvectors)
```

## 주요 용어

| 용어 | 실제 의미 |
|------|----------|
| 회전 행렬 | 점을 원호를 따라 이동, 거리와 각도 보존. 행렬식 = 1 |
| 크기 조정 행렬 | 각 축을 독립적으로 늘이거나 압축. 행렬식 = 조정 계수의 곱 |
| 전단 행렬 | 한 좌표를 다른 좌표에 비례하여 이동, 직사각형 → 평행사변형 |
| 합성 | 변환 행렬 곱셈으로 연산 연결. 순서 중요: B @ A = A 먼저, B 다음 |
| 고유벡터 | 행렬이 크기만 조정하고 회전시키지 않는 방향 |
| 고윳값 | 행렬이 고유벡터를 조정하는 스칼라 계수 |
| 행렬식 | 변환이 면적/부피를 조정하는 계수. 0이면 비가역적 |
