## 문제

샘플당 784개의 특성이 있는 데이터셋. 시각화할 수도, 그래프를 그릴 수도, 생각조차 할 수 없습니다. 하지만 그 784개 특성의 대부분은 중복됩니다. 실제 정보는 훨씬 작은 표면에 존재합니다. 손글씨 "7"을 설명하는 데 784개의 독립적인 숫자가 필요하지 않습니다.

차원 축소는 그 더 작은 표면을 찾습니다. 784차원 데이터를 2, 10, 50차원으로 압축하면서 중요한 구조를 유지합니다.

## 개념

### 차원의 저주

- **거리가 무의미해짐**: 고차원에서는 임의의 두 점 간 거리가 같은 값으로 수렴
- **부피가 모서리에 집중**: d차원 단위 하이퍼큐브는 2^d개의 모서리. 100차원에서는 거의 모든 부피가 모서리에
- **기하급수적으로 더 많은 데이터 필요**: 2D→20D로 가려면 10^18배 더 많은 데이터 필요

### PCA: 중요한 방향 찾기

```
1. 데이터 중심화        (각 특성에서 평균 빼기)
2. 공분산 계산          (특성이 어떻게 함께 움직이는지)
3. 고유분해            (주요 방향 찾기)
4. 고윳값으로 정렬      (가장 큰 분산 먼저)
5. 사영               (상위 k개 고유벡터 유지, 나머지 삭제)
```

공분산 행렬은 대칭이고 양의 준정부호입니다. 고유벡터는 특성 공간의 직교 방향입니다. 고윳값은 각 방향이 포착하는 분산량을 알려줍니다.

### 설명된 분산 비율

```python
import numpy as np

# 중심화
X_centered = X - X.mean(axis=0)

# 공분산 행렬
cov = (X_centered.T @ X_centered) / (len(X) - 1)

# 고유분해
eigenvalues, eigenvectors = np.linalg.eigh(cov)

# 내림차순 정렬
idx = np.argsort(eigenvalues)[::-1]
eigenvalues = eigenvalues[idx]
eigenvectors = eigenvectors[:, idx]

# 설명된 분산 비율
explained_var_ratio = eigenvalues / eigenvalues.sum()
cumulative = np.cumsum(explained_var_ratio)

# k개 성분으로 사영
k = 2
X_pca = X_centered @ eigenvectors[:, :k]
```

### PCA vs t-SNE vs UMAP

| 방법 | 전역 구조 | 지역 구조 | 속도 | 용도 |
|------|----------|----------|------|------|
| PCA | 보존 | 보존 | 빠름 | 전처리, 노이즈 제거 |
| t-SNE | 손실 | 보존 | 느림 | 시각화 |
| UMAP | 부분 보존 | 보존 | 중간 | 시각화 + 특징 |
