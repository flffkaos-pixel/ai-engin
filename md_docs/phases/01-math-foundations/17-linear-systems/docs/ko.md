# 선형 시스템

> Ax = b를 푸는 것은 여전히 당신의 신경망을 실행하는 수학에서 가장 오래된 문제입니다.

**유형:** 빌드
**언어:** Python
**선수 과목:** Phase 1, Lessons 01-03
**시간:** ~120분

## 학습 목표

- 부분 피벗팅과 역대입을 사용한 가우스 소거법으로 Ax = b 풀기
- LU, QR, 콜레스키 분해로 행렬 분해하고 각각이 적절한 시기 설명하기
- 최소제곱을 위한 정규방정식 유도하고 선형 및 Ridge 회귀와 연결하기
- 조건수를 사용하여 불량 조건 시스템 진단하고 정규화로 안정화하기

## 문제

선형 회귀를 훈련할 때마다, 최소제곱 적합을 계산할 때마다 선형 시스템을 풉니다. 신경망 레이어가 `y = Wx + b`를 계산할 때마다 선형 시스템의 한쪽을 평가하는 것입니다. 방정식 Ax = b는 어디에나 있습니다. 선형 회귀에서 A는 데이터 행렬, b는 목표 벡터, x는 가중치 벡터입니다.

## 개념

### Ax = b의 기하학적 의미

각 방정식은 초평면을 정의합니다. 해는 모든 초평면이 교차하는 점입니다.

```
2x + y = 5    →  두 직선. x=2, y=1에서 교차.
x - y  = 1
```

세 가지 가능성:
- **하나의 해**: A가 가역적
- **해 없음**: 시스템이 불일치 → 최소제곱 필요
- **무한한 해**: A가 영공간을 가짐

### 열 그림 vs 행 그림

- **행 그림**: 각 방정식 = 하나의 초평면. 교차점 = 해
- **열 그림**: b = A 열들의 선형 결합. "x는 A의 열 공간에서 b를 생성하는 계수"

### 해결 방법

**가우스 소거법**: 행 연산으로 상삼각 형태로 변환 후 역대입. O(n³). 부분 피벗팅이 수치적 안정성 향상.

**LU 분해**: A = LU (L=하삼각, U=상삼각). 한 번 분해하면 여러 b에 대해 재사용 가능.

**QR 분해**: A = QR (Q=직교, R=상삼각). 최소제곱에 수치적으로 더 안정적.

**콜레스키 분해**: A = LLᵀ. 대칭 양의 정부호 행렬에만 해당. LU보다 2배 빠름.

### 최소제곱

과결정 시스템(Ax = b, 방정식 > 미지수)의 경우: `minimize ||Ax - b||²`

정규방정식: `AᵀA x̂ = Aᵀb`

Ridge 회귀: `(AᵀA + λI) x̂ = Aᵀb` — 대각선에 λ 추가로 정규화.

### 조건수

κ(A) = σ_max / σ_min. κ가 크면 시스템이 불량 조건 — 입력의 작은 변화가 출력의 큰 변화 유발. 정규화로 개선.

## 빌드하기

```python
def gaussian_elimination(A, b):
    n = len(A)
    # 전진 소거 (부분 피벗팅 포함)
    for col in range(n):
        pivot = max(range(col, n), key=lambda r: abs(A[r][col]))
        A[col], A[pivot] = A[pivot], A[col]
        b[col], b[pivot] = b[pivot], b[col]
        for row in range(col + 1, n):
            factor = A[row][col] / A[col][col]
            for j in range(col, n):
                A[row][j] -= factor * A[col][j]
            b[row] -= factor * b[col]
    # 역대입
    x = [0.0] * n
    for i in range(n - 1, -1, -1):
        x[i] = (b[i] - sum(A[i][j] * x[j] for j in range(i + 1, n))) / A[i][i]
    return x
```

## 주요 용어

| 용어 | 실제 의미 |
|------|----------|
| 가우스 소거법 | 행 연산 → 상삼각 → 역대입 |
| LU 분해 | L과 U로 분해 — 여러 b에 재사용 |
| 정규방정식 | AᵀA x̂ = Aᵀb — 최소제곱 해 |
| 조건수 | σ_max/σ_min — 해의 민감도 측정 |
| 불량 조건 | 큰 조건수 → 작은 입력 오차가 큰 출력 오차로 |
