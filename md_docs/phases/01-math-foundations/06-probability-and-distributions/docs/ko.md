## 개념

### 사건, 표본 공간, 확률

표본 공간 S는 모든 가능한 결과의 집합입니다. 사건은 표본 공간의 부분집합입니다.

```
동전 던지기: S = {앞, 뒤}, P(앞) = 0.5
주사위 굴리기: S = {1,2,3,4,5,6}, P(짝수) = 3/6 = 0.5
```

확률의 세 가지 공리:
1. P(A) >= 0
2. P(S) = 1
3. P(A 또는 B) = P(A) + P(B) (A와 B가 동시에 발생할 수 없을 때)

### 조건부 확률

P(A|B) = P(A와 B) / P(B). B가 발생했을 때 A의 확률.

카드 덱에서: P(King | Face) = 4/12 = 1/3

### PMF vs PDF

- **PMF**(확률 질량 함수): 이산 확률 변수용. 각 결과에 특정 확률이 있음
- **PDF**(확률 밀도 함수): 연속 확률 변수용. 단일 점의 밀도는 확률이 아님. 구간에 대한 적분이 확률

### 주요 분포

| 분포 | 용도 | 예시 |
|------|------|------|
| 베르누이 | 이진 분류 | P(스팸)=p, P(정상)=1-p |
| 범주형 | 다중 클래스 분류 | P(고양이)=0.7, P(개)=0.2 |
| 균등 | 랜덤 초기화 | 모든 결과 동일 확률 |
| 정규(가우시안) | 자연 현상, 노이즈 모델링 | 중심극한정리로 설명됨 |

### 기댓값과 분산

- **기댓값 E[X]**: 무게 중심. 무한 번 시행했을 때의 평균
- **분산 Var[X]**: 퍼짐 정도. E[(X - E[X])²]
- **중심극한정리**: 독립적인 랜덤 변수의 합(또는 평균)은 원래 분포와 관계없이 정규분포에 접근

## 빌드하기

### 소프트맥스 (수치적 안정성 포함)

```python
import math

def softmax(logits):
    max_logit = max(logits)  # 오버플로 방지
    exp_vals = [math.exp(x - max_logit) for x in logits]
    total = sum(exp_vals)
    return [v / total for v in exp_vals]

def log_softmax(logits):
    max_logit = max(logits)
    exp_sum = sum(math.exp(x - max_logit) for x in logits)
    return [x - max_logit - math.log(exp_sum) for x in logits]
```

### 교차 엔트로피 손실

```python
def cross_entropy_loss(logits, target_class):
    log_probs = log_softmax(logits)
    return -log_probs[target_class]  # NLL: negative log-likelihood
```

## 주요 용어

| 용어 | 실제 의미 |
|------|----------|
| 확률 질량 함수 (PMF) | 이산 변수: P(X=k) |
| 확률 밀도 함수 (PDF) | 연속 변수: 구간 적분이 확률 |
| 기댓값 | 무게 중심, 무한 시행 평균 |
| 중심극한정리 | 합/평균이 정규분포에 접근 — AI에서 정규분포가 어디에나 있는 이유 |
| 소프트맥스 | 로짓을 확률 분포로 변환 (합 = 1) |
| 교차 엔트로피 | 두 분포 간 차이 측정 — 분류의 표준 손실 함수 |
