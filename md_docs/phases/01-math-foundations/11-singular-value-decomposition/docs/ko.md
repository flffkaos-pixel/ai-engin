## 개념

### SVD의 기하학적 의미

모든 행렬은 세 가지 연산을 순서대로 수행합니다: 회전, 크기 조정, 회전.

```
A = U * Σ * V^T

A: m×n 행렬
U: m×m 직교 행렬 (왼쪽 특이벡터, 출력 공간으로 회전)
Σ: m×n 대각 행렬 (특이값, 각 축 따라 크기 조정)
V: n×n 직교 행렬 (오른쪽 특이벡터, 입력 공간에서 회전)
```

"SVD에게 행렬을 주면 이렇게 말합니다: '이 행렬은 입력 구를 먼저 V^T로 회전시키고, Σ로 타원체로 늘인 다음, U로 타원체를 회전시킵니다.' 특이값은 타원체 축의 길이입니다."

### 세 가지 구성 요소

- **V의 열 (오른쪽 특이벡터)**: 입력 공간(R^n)의 정규직교 기저. 행렬이 출력 공간의 직교 방향으로 매핑하는 방향
- **Σ의 대각선 (특이값)**: 크기 조정 계수. σ_i는 i번째 오른쪽 특이벡터를 따라 행렬이 얼마나 늘어나는지. 0이면 방향 소멸
- **U의 열 (왼쪽 특이벡터)**: 출력 공간(R^m)의 정규직교 기저. i번째 오른쪽 특이벡터가 (크기 조정 후) 도착하는 방향

### 절단 SVD

상위 k개의 특이값과 해당 특이벡터만 유지: `A_k = U_k * Σ_k * V_k^T`

이것은 랭크 k에서 A의 최적 근사(Eckart-Young 정리). 이미지 압축, 노이즈 제거, 잠재 의미 분석에 사용됩니다.

### SVD의 응용

- **PCA**: X^T X의 고유분해 대신 X의 SVD 계산. 더 빠르고 수치적으로 안정적
- **추천 시스템**: 사용자-아이템 행렬의 SVD → 잠재 요인(예: "액션 선호도", "로맨스 선호도")
- **잠재 의미 분석(LSA)**: 문서-단어 행렬의 SVD → 잠재 토픽
- **유사역행렬**: A^+ = V * Σ^+ * U^T — 과결정 시스템의 최소제곱 해

## 빌드하기

### 거듭제곱 반복으로 SVD

```python
import numpy as np

def power_iteration(A, n_iter=100):
    """가장 큰 특이값과 해당 특이벡터 찾기"""
    v = np.random.randn(A.shape[1])
    v = v / np.linalg.norm(v)
    for _ in range(n_iter):
        v_new = A.T @ (A @ v)
        v_new = v_new / np.linalg.norm(v_new)
        if np.abs(v @ v_new) > 0.9999:
            v = v_new
            break
        v = v_new
    sigma = np.linalg.norm(A @ v)
    u = (A @ v) / sigma
    return u, sigma, v

def svd_power(A, k):
    """거듭제곱 반복 + 디플레이션으로 상위 k개 특이값/벡터 계산"""
    A = A.astype(float)
    U, S, Vt = [], [], []
    for _ in range(k):
        u, sigma, v = power_iteration(A)
        U.append(u); S.append(sigma); Vt.append(v)
        A = A - sigma * np.outer(u, v)  # 디플레이션
    return np.column_stack(U), np.array(S), np.row_stack(Vt)
```

### 이미지 압축 예시

```python
# 이미지의 SVD 계산
U, S, Vt = svd_power(image_matrix, k=50)

# 절단 SVD로 재구성
compressed = U[:, :k] @ np.diag(S[:k]) @ Vt[:k, :]

# 압축률: 원본 mn vs 저장 mn+kn+km
compression_ratio = m*n / (k*(m + n + 1))
```
