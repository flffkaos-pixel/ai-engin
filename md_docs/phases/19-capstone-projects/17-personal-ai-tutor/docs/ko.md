# 캡스톤 17 — 개인 AI 튜터 (적응형, 멀티모달, 메모리 포함)

> Khan Academy의 Khanmigo, Duolingo Max, Google LearnLM / Gemini for Education, Quizlet Q-Chat, Synthesis Tutor는 모두 2026년에 적응형 멀티모달 튜터링을 대규모로 출시했습니다. 공통된 형태는 소크라테스식 정책(절대 답을 그냥 알려주지 않음), 모든 상호작용 후 업데이트되는 학습자 모델(베이지안 지식 추적 스타일), 음성 + 텍스트 + 사진-수학 입력, 커리큘럼 그래프 검색, 간격 반복 스케줄링, 연령에 적합한 콘텐츠를 위한 강력한 안전 필터입니다. 이 캡스톤은 특정 과목 튜터(K-12 대수학 또는 입문 Python)를 출시하고, 10명의 학습자로 2주 효능 연구를 실행하며, 콘텐츠 안전 감사를 통과하는 것입니다.

**Type:** Capstone
**Languages:** Python (백엔드, 학습자 모델), TypeScript (웹 앱), SQL (Postgres + Neo4j를 통한 커리큘럼 그래프)
**Prerequisites:** Phase 5 (NLP), Phase 6 (음성), Phase 11 (LLM 엔지니어링), Phase 12 (멀티모달), Phase 14 (에이전트), Phase 17 (인프라), Phase 18 (안전)
**Phases exercised:** P5 · P6 · P11 · P12 · P14 · P17 · P18
**Time:** 30시간

## 문제

적응형 튜터링은 한때 교육 기술 연구 틈새였습니다. 2026년에는 소비자 제품이 되었습니다. Khanmigo는 대부분의 미국 학군에 배포되었습니다. Duolingo Max는 수천만 MAU에 도달했습니다. Google의 LearnLM / Gemini for Education은 Google Classroom에서 튜터링을 구동합니다. Quizlet Q-Chat은 플래시카드와 함께 사용됩니다. Synthesis Tutor는 호기심 많은 아이들을 위한 튜터로 입소문을 탔습니다. 공통 요소: 멀티모달 입력(타이핑, 말하기, 수학 문제 사진 찍기), 소크라테스식 교수법(먼저 질문하고 나중에 설명), 각 상호작용 후 업데이트되는 학습자 모델, 엄격한 연령 적합 안전입니다.

특정 학습자 그룹을 위한 튜터를 구축합니다. 측정 기준은 실제 효능 연구입니다: 10명의 학습자와 2주 동안 사전 테스트 및 사후 테스트 점수. 음성 루프는 자연스러워야 하고(캡스톤 03 하위 스택), 메모리는 프라이버시를 존중해야 하며, 안전 필터는 K-12용 COPPA 인식 레드팀을 통과해야 합니다.

## 개념

네 가지 구성 요소. **튜터 정책**은 소크라테스식 루프입니다: 학습자가 답을 요청하면 정책이 유도 질문을 하고, 정답을 맞추면 다음 개념으로 이동하며, 막히면 발판 힌트를 제공합니다. **학습자 모델**은 각 상호작용 후 커리큘럼 노드별 숙달 확률을 업데이트하는 베이지안 지식 추적(또는 간단한 변형)입니다. **커리큘럼 그래프**는 선수 조건 엣지가 있는 Neo4j 개념입니다; 정책은 그래프를 탐색하여 다음 개념을 선택합니다. **메모리**는 과거 상호작용, 실수, 선호도를 저장하는 에피소드 + 의미 저장소(agentmemory 스타일)입니다.

UX는 멀티모달입니다. 입력: 타이핑된 답변용 텍스트, LiveKit + Whisper를 통한 음성 입력(캡스톤 03 재사용), dots.ocr 또는 PaliGemma 2를 통한 수학 문제 사진 입력. 출력: Cartesia Sonic-2를 통한 음성 출력. 안전: Llama Guard 4와 연령 적합 필터(성인 콘텐츠, 폭력, 자해 차단) 및 COPPA 인식 메모리 보존 정책.

효능 연구가 결과물입니다. 10명의 학습자, 사전 및 사후 테스트, 2주. 학습 향상 델타와 신뢰 구간을 보고합니다. 비적응형 기준선(튜터 정책 없이 선형적으로 동일한 콘텐츠 제공)과 비교합니다.

## 아키텍처

```
학습자 디바이스
  |
  +-- 텍스트         -> 웹 앱
  +-- 음성           -> LiveKit Agents (ASR + TTS)
  +-- 사진 수학      -> dots.ocr / PaliGemma 2
       |
       v
  튜터 정책 (LangGraph)
       - 소크라테스식 결정 헤드
       - 다음 개념 선택기 (커리큘럼 그래프 탐색)
       - 힌트 발판기
       - 숙달 업데이트
       |
       v
  학습자 모델 (BKT / 문항 반응 이론)
       - 개념별 숙달 확률
       - 간격 반복 스케줄러 (SM-2 또는 FSRS)
       |
       v
  메모리 (agentmemory 스타일)
       - 에피소드: 모든 상호작용
       - 의미: 학습된 실수, 선호도
       - 보존 정책: COPPA / GDPR 인식
       |
       v
  커리큘럼 그래프 (Neo4j)
       - 선수 조건 엣지
       - OER 콘텐츠 첨부
       |
       v
  안전:
    Llama Guard 4 + 연령 적합 필터
    학습자 ID 범위로 보호된 메모리 액세스
```

## 스택

- 과목 선택: K-12 대수학 또는 입문 Python (깊이를 위해 하나 선택)
- 튜터 정책: LangGraph + Claude Sonnet 4.7 (프롬프트 캐싱 포함)
- 학습자 모델: 베이지안 지식 추적 (클래식) 또는 간격을 위한 FSRS
- 커리큘럼 그래프: Neo4j 개념 + 선수 조건 엣지 + OER 콘텐츠
- 메모리: agentmemory 스타일의 지속적 벡터 + 에피소드 + 의미 저장소
- 음성: LiveKit Agents 1.0 + Cartesia Sonic-2 (캡스톤 03 하위 스택 재사용)
- 사진 수학: dots.ocr 또는 PaliGemma 2 (수식 인식)
- 안전: Llama Guard 4 + 사용자 정의 연령 적합 필터
- 평가: Bloom 수준 질문 생성, 사전/사후 테스트 하네스, 효능 연구 도구

## 구축하기

1. **커리큘럼 그래프.** 선수 조건 엣지가 있는 50~150개 개념 노드(예: "수직선"에서 "이차 공식"까지 K-12 대수학)의 Neo4j를 구축합니다. 노드별 OER 콘텐츠(Open Textbook, OpenStax)를 첨부합니다.

2. **학습자 모델.** 사전 확률(추측, 실수, 학습률)로 베이지안 지식 추적을 초기화합니다. 각 상호작용 후 개념별 숙달을 업데이트합니다. 학습자별로 유지합니다.

3. **튜터 정책.** LangGraph 노드: `read_signal` (학습자의 답변이 정답 / 부분 정답 / 막힘?), `select_concept` (커리큘럼 그래프를 탐색하여 최우선 개념 선택), `scaffold` (소크라테스식 프롬프트), `update_mastery`.

4. **메모리.** 모든 상호작용이 에피소드 저장소에 기록됩니다. 실수와 선호도는 의미 메모리로 승격됩니다. COPPA 인식 보존 정책: 1년 후 자동 삭제, 학부모 접근 가능.

5. **음성 경로.** 튜터 정책에 연결된 LiveKit Agents 워커. ASR: Whisper-v3-turbo. TTS: Cartesia Sonic-2. Barge-in 지원 (캡스톤 03 메커니즘 재사용).

6. **사진-수학 경로.** 이미지 업로드 또는 캡처; dots.ocr 또는 PaliGemma 2를 실행하여 수식 인식; 구조화된 입력으로 튜터에 전달.

7. **안전.** 모든 모델 출력은 Llama Guard 4 + 연령 적합 필터(자해, 성인 콘텐츠, 폭력 차단)를 통과합니다. 메모리 액세스는 학습자 ID로 범위 지정; 삭제를 위한 학부모 액세스 표면.

8. **효능 연구.** 10명의 학습자, 사전 테스트(표준화된 30문항 기준선), 2주 튜터 상호작용(주 3회), 사후 테스트. 동일한 콘텐츠의 비적응형 기준선 코호트 10명과 비교합니다.

9. **주간 진행 보고서.** 학습자별로 탐색된 주제, 숙달 궤적, 권장 다음 단계의 PDF 요약을 자동 생성합니다.

## 사용하기

```
학습자: "3x + 6 = 12가 x = 2인 이유를 모르겠어요"
[signal]   막힘
[concept]  '변수 분리하기' (선수조건: 덧셈-뺄셈-등식)
[scaffold] "시작하려면 양변에서 어떤 숫자를 빼야 할까요?"
학습자: "6"
[signal]   정답
[mastery]  덧셈-뺄셈-등식: 0.62 -> 0.77
[concept]  '변수 분리하기' 계속
[scaffold] "좋아요. 그럼 3x / 3은 무엇과 같나요?"
```

## 실습

1. 적응형 학습자 모델 유무에 따라 효능 연구를 실행합니다(무작위 개념 순서). 델타를 보고합니다. 적응형이 이길 것으로 예상되지만, 그 크기가 흥미로운 숫자입니다.

2. 멀티모달 프로브를 추가합니다: 동일한 개념 질문을 텍스트, 음성, 사진으로 전달합니다. 학습자가 선호하는 양식으로 더 빠르게 수렴하는지 측정합니다.

3. 학부모 대시보드를 구축합니다: 연습한 주제, 숙달 궤적, upcoming concepts, 안전 이벤트(가드레일 적중). COPPA 정렬.

4. 언어 전환 모드를 추가합니다: 튜터가 스페인어 입력을 받아들이고 스페인어로 가르칩니다. X-Guard 커버리지를 측정합니다.

5. 메모리 프라이버시를 테스트합니다: 학습자 A가 음성 클립 재수집 공격을 통해서도 학습자 B의 데이터를 볼 수 없는지 확인합니다. 시도된 접근을 기록하고 알림을 보냅니다.

## 주요 용어

| 용어 | 일반적인 사용법 | 정확한 의미 |
|------|----------------|-------------|
| 소크라테스식 정책 | "질문하라, 덤프하지 마라" | 튜터가 답을 주는 대신 유도 질문을 함 |
| 베이지안 지식 추적 | "BKT" | 개념별 숙달 확률을 위한 고전 학습자 모델 방정식 |
| FSRS | "Free Spaced Repetition Scheduler" | 2024년 간격 반복 스케줄러, SM-2보다 우수 |
| 커리큘럼 그래프 | "개념 DAG" | 선수 조건 엣지가 있는 Neo4j 개념 |
| 에피소드 메모리 | "상호작용별 로그" | 나중 검색을 위해 저장된 모든 상호작용 |
| 의미 메모리 | "학습된 패턴 저장소" | 에피소드에서 승격된 압축된 실수 및 선호도 |
| COPPA | "어린이 프라이버시 법" | 13세 미만 아동의 데이터 수집을 제한하는 미국 법률 |
