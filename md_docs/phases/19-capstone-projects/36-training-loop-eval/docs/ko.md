# 학습 루프와 평가

> 측정하지 않는 루프는 거짓말하는 루프입니다. 이 수업은 GPT 모델을 구동하는 학습 루프를 구축합니다: 가중치 감쇠 분할이 있는 AdamW, 워밍업 + 코사인 학습률 스케줄, calc_loss_batch 헬퍼, 보류 데이터에 대한 evaluate_model 패스, K단계마다 generate_and_print_sample 정성적 프로브, 그리고 이후에 플롯할 수 있는 손실의 JSONL 로그. 동일한 골격이 여러분이 구축할 모든 디코더 LLM을 학습시킵니다.

**Type:** Build
**Languages:** Python
**Prerequisites:** Phase 19 수업 30~35
**Time:** 약 90분

## 학습 목표

- 다음 토큰 예측을 위한 올바른 입력 및 타겟 정렬로 교차 엔트로피 손실을 계산하는 학습 루프를 구축합니다.
- LayerNorm 또는 바이어스 텐서가 아닌 가중치 텐서에 적용되는 가중치 감쇠로 AdamW를 구성합니다.
- 선형 워밍업과 코사인 감쇠가 있는 학습률 스케줄을 구현하고 시간에 따른 결과 LR을 읽습니다.
- evaluate_model로 보류 분할에서 평가하여 eval 손실이 실행 간에 비교 가능하도록 합니다.
- 손실 곡선이 발산을 잡기 전에 catch하기 위해 K단계마다 generate_and_print_sample로 정성적 샘플을 생성합니다.
- 단계별 손실을 JSONL에 저장하여 학습 로그를 결과물로 재로드, 플롯, 제공할 수 있게 합니다.
