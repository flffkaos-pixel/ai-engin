# 시각적 자기 회귀 모델링 (VAR): 다음-스케일 예측

> 확산 모델은 시간적으로 반복적으로 샘플링합니다(노이즈 제거 단계). VAR은 스케일로 반복적으로 샘플링합니다 — 1x1 토큰을 예측한 다음 2x2, 그 다음 4x4, 최종 해상도까지, 각 스케일이 이전 조건으로 조건화됩니다. 2024년 논문은 VAR이 이미지 생성을 위해 GPT 스타일 스케일링 법칙과 일치하고 동일한 컴퓨트 예산에서 DiT를 능가한다는 것을 보여주었습니다. 이 레슨은 핵심 메커니즘을 구축합니다.

**유형:** 실습
**언어:** Python (PyTorch 포함)
**선수 과목:** Phase 7 Lesson 03 (Multi-Head Attention), Phase 8 Lesson 06 (DDPM)
**소요 시간:** ~90분

## 문제

자기 회귀 생성은 예측 가능하게 확장되기 때문에 언어 모델링을 지배했습니다: 더 많은 컴퓨트, 더 많은 파라미터, 더 낮은 퍼플렉서티, 더 나은 출력. 이미지 생성에는 2024년 이전에 두 가지 주요 AR 시도がありました: PixelRNN/PixelCNN(픽셀별) 및 DALL-E 1 / Parti / MuseGAN(VQ-VAE 코드에서 토큰별).

둘 다 생성 순서 문제로 어려움을 겪었습니다. 픽셀과 토큰은 2D 그리드에 배열되어 있지만, AR 모델은它们을 1D 래스터 순서로 방문해야 합니다. 초기 코너 픽셀은 이미지가 결국 무엇이 될지 알지 못합니다. 생성 품질은 GPT-on-text보다 더 나쁘게 확장되었으며 일치하는 컴퓨트에서 확산 모델 품질에 도달하지 못했습니다.

VAR은 생성되는 내용을 변경하여 생성 순서 문제를 수정합니다. 공간에서 이미지 토큰을 하나씩 예측하는 대신, VAR은 증가하는 해상도로 전체 이미지를 예측합니다. 단계 1: 1x1 토큰 예측(전체 이미지 "요약"). 단계 2: 2x2 토큰 그리드 예측(더 거친 특성). 단계 3: 4x4 그리드 예측. 단계 K: 최종 (H/8)x(W/8) 그리드 예측.

각 스케일은 모든 이전 스케일에 attend하고(스케일 순서에서 causal), 자신의 스케일 내에서는並列입니다. 순서 문제가 사라집니다: 스케일 k의 전체 이미지는 하나의 트랜스포머 패스로 생성됩니다.

## 개념

### VQ-VAE 다중 스케일 토크나이저

VAR은 **다중 스케일 이산 토크나이저**가 필요합니다. 이미지 x에 대해, 점진적으로 더 높은 해상도의 토큰 그리드 시퀀스를 생성합니다:

```
x -> encoder -> latent f
f -> 1x1에서 토큰화: 형태 (1, 1)의 토큰 그리드 z_1
f -> 2x2에서 토큰화: 형태 (2, 2)의 토큰 그리드 z_2
...
f -> (H/p)x(W/p)에서 토큰화: 형태 (H/p, W/p)의 토큰 그리드 z_K
```

각 z_k는 동일한 코드북(일반적인 크기 4096-16384)을 사용합니다. 각 스케일에서의 토큰化은 독립적이지 않습니다 — scales 1..k-1가 놓친 것을 캡처하도록 학습됩니다:

```
f ≈ upsample(embed(z_1), target_size) + ... + upsample(embed(z_K), target_size)
```

이것이 **잔차 VQ** 변형입니다. 스케일 k는 scales 1..k-1가 놓친 잔차를 캡처합니다. 디코더는 모든 스케일 임베딩의 합을 취하여 이미지를 생성합니다.

다중 스케일 VQ 토크나이저는 한 번 학습된 후( VQGAN처럼) 동결됩니다. 모든 생성 작업은 위의 자기 회귀 모델이 수행합니다.

### 다음-스케일 예측

생성 모델은 모든 이전 스케일의 토큰을 보고 다음 스케일의 토큰을 예측하는 트랜스포머입니다.

입력 시퀀스 구조:
```
[START, z_1 토큰, z_2 토큰, z_3 토큰, ..., z_K 토큰]
```

위치 임베딩은 스케일 인덱스와 스케일 내 공간 위치를 모두 인코딩합니다. 어텐션은 스케일 순서에서 causal입니다: 스케일 k, 위치 (i, j)의 토큰은 scales 1..k의 모든 토큰과 스케일 k 자체의 이전 토큰(사용되는 스케일 내 순서)에 attend할 수 있습니다(VAR은 스케일 내 인과관계 없이 고정 위치 어텐션을 사용합니다 — 스케일 내 모든 위치가並列로 예측됩니다).

학습 손실: 각 스케일 k에서 모든 이전 스케일 토큰이 주어지면 z_k를 예측합니다. 이산 VQ 코드의 교차 엔트로피 손실. 구조는 GPT와 동일합니다 "시퀀스"가 이제 스케일 구조를 가집니다.

### 생성

추론 시:
```
z_1 생성 = p(z_1)에서 샘플링                    # 1 토큰
z_2 생성 = p(z_2 | z_1)에서 샘플링              # 4 토큰並列
z_3 생성 = p(z_3 | z_1, z_2)에서 샘플링         # 16 토큰並列
...
디코딩: f = 스케일 1..K의 embed-and-upsample의 합
이미지 = VAE_decoder(f)
```

K = 10 스케일의 경우, 생성은 10개의 트랜스포머 순방향 패스입니다. 각 패스는 전체 스케일을並列로 생성합니다 — 스케일 내 토큰별 자기 회귀 없음. 256x256 이미지의 경우 이것은 약 10 패스 vs DiT의 28-50입니다.

### 다음-토큰 대 다음-스케일이 승리하는 이유

세 가지 구조적 승리:
1. ** coarse-to-fine는 자연스러운 이미지 통계와 정렬됩니다.** 인간 시각 지각과 이미지 데이터셋은 모두 스케일 종속적 규칙성을 나타냅니다: 저주파 구조는 안정적이고 예측 가능합니다; 고주파 디테일은 저주파 내용에 조건부입니다. 다음-스케일 예측은 이것을 활용합니다.
2. **스케일 내並列 생성.** GPT 스타일 토큰 AR과 달리, VAR은 하나의 단계에서 스케일의 모든 토큰을 생성합니다. 유효 생성 길이가 선형 대신 로그 스케일입니다.
3. **생성 순서 편향 없음.** 스케일 k의 토큰은 스케일 k-1의 전체를 봅니다; 초기 토큰이 나중 컨텍스트를 사용할 수 있게強制する前にcommit하는 "left-of" 또는 "above" 편향이 없습니다.

### 스케일링 법칙

Tian et al.은 VAR이 ImageNet에서 FID에 대한 멱법칙 스케일링 곡선을 따른다는 것을demonstrated했습니다 — GPT가 퍼플렉서티에 대해 하는 것처럼요. 파라미터나 컴퓨트를 두 배로 늘리면 오류가 reliably 절반이 됩니다. 이것은 언어 모델만큼 깨끗하게 이 종류의 스케일링 동작을 나타내는 첫 번째 이미지 생성 모델이었습니다. 결과는 VAR-스케일 예측이 아키텍처당 경험적 추측이 아니라 컴퓨트에서 예측 가능해졌다는 것입니다.

### 확산과의 관계

VAR과 확산은 동일한 데이터 압축 이야기를 공유합니다: 둘 다 생성 문제를 더 쉬운 하위 문제의 시퀀스로 나눕니다.

- 확산: 점진적으로 노이즈를 추가하고, 한 단계를 되돌리는 것을 학습합니다.
- VAR: 점진적으로 해상도를 추가하고, 다음 스케일을 예측하는 것을 학습합니다.

그들은 문제에 대한 다른 축입니다. 둘 다 다루기 쉬운 조건부 분포를 산출합니다. 경험적으로 VAR은 추론에서 더 빠릅니다(더 적은 패스, 스케일 내 모두並列). class-conditional ImageNet에서 DiT와 일치하거나 능가합니다. 텍스트 조건 VAR (VARclip, HART)는 활동적인 연구 방향입니다.

## 실습

`code/main.py`에서 다음을 수행합니다:
1. 합성 "이미지" 데이터(2D 가우시안 링)에서 tiny **다중 스케일 VQ 토크나이저**를 구축합니다.
2. 다음-스케일-예측하도록 **VAR 스타일 트랜스포머**를 학습시킵니다.
3. 트랜스포머를 4번 호출(4 스케일)하고 디코딩하여 샘플링합니다.
4. 스케일 순서 학습이 스케일 내 생성이並列인지 확인합니다.

이것은 toy 구현입니다. 포인트는 스케일 구조 어텐션 마스크와 스케일 내並列 생성이 실제로 작동하는 것을 보는 것입니다.

## 연습 문제

1. **스케일 수 절제.** 4, 6, 8, 10 스케일로 VAR을 학습시킵니다. 재구성 품질 vs 자기 회귀 패스 수를 측정합니다. 더 많은 스케일 = 더 나은 품질이지만 더 많은 패스를 의미하는 더 나은 품질입니다.

2. **코드북 크기.** 코드북 크기 512, 4096, 16384로 토크나이저를 학습시킵니다. 더 큰 코드북은 더 나은 재구성이지만 더 어려운 예측을 제공합니다. 노이를 찾으세요.

3. **스케일 내並列 확인.** 학습된 VAR에 대해 어텐션 패턴을 명시적으로 측정합니다. 스케일 k 내에서 모델은 스케일 간 위치에 attend하지만 스케일 내에는 하지 않습니까? 마스크 구현을 확인하세요.

4. **VAR vs DiT 스케일링.** 동일한 ImageNet 클래스 조건 작업에 대해, 일치된 파라미터 예산(예: 33M, 130M, 458M)에서 VAR과 DiT를 학습시킵니다. FID vs 컴퓨트를 플롯합니다. VAR은 각 크기에서 DiT를 능가해야 합니다 — 작은 규모에서 논문의 결과를 재현하세요.

5. **텍스트 조건.** adaLN을 통해 텍스트 임베딩(CLIP pooled)을 추가 조건 입력으로 VAR을 확장합니다. 이것이 HART 레시피입니다. 텍스트 정렬 샘플링에서 FID가 얼마나 개선되나요?

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|-------------------|----------|
| VAR | "Visual AutoRegressive" | VQ 토큰 그리드의 피라미드에서 다음-스케일 예측による 이미지 생성 |
| 다음-스케일 예측 | "먼저 더粗く, 그 다음 더 미세하게" | 증가하는 해상도 스케일에서 토큰을 예측하고, 모든 이전 스케일을 조건으로 합니다 |
| 다중 스케일 VQ 토크나이저 | "잔차 VQ" | 증가하는 해상도의 K개 토큰 그리드를 생성하고, 디코더가 모든 스케일을 합산하는 VQ-VAE |
| 스케일 k | "피라미드 레벨 k" | k=1에서 1x1부터 k=K에서 (H/p)x(W/p)까지의 K개 해상도 레벨 중 하나 |
| 스케일 내並列 | "스케일당 하나向前" | 스케일 k의 모든 토큰이 하나의 트랜스포머 패스로 예측되며, 자기 회귀적이지 않습니다 |
| 스케일 간 인과 | "스케일 순서 어텐션" | 스케일 k의 토큰은 scales 1..k에는 attend할 수 있지만 scales k+1..K에는 할 수 없습니다 |
| 잔차 VQ | "가산적 토큰化" | 각 스케일의 토큰이 더 낮은 스케일에서 남긴 잔차를 인코딩합니다; 디코더가 모든 스케일 임베딩을 합산합니다 |
| VAR 스케일링 법칙 | "이미지 GPT 스케일링" | FID가 언어 모델의 퍼플렉서티처럼 컴퓨트에서 예측 가능한 멱법칙을 따릅니다 |
| HART | "하이브리드 VAR + 텍스트" | MaskGIT 스타일 반복적 디코딩과 VAR의 스케일 구조를 결합한 텍스트 조건 VAR 변형 |
| 스케일 위치 임베딩 | "(스케일, 행, 열) 트리플" | 위치 인코딩은 스케일 인덱스와 스케일 내 공간 좌표를 모두携带합니다 |
