# Show-o와 이산-확산 통합 모델

> Transfusion은 연속과 이산 표현을 혼합합니다. Show-o(Xie et al., 2024년 8월)는 반대 방향으로 갑니다: 텍스트 토큰은 인과적 다음-토큰 예측을 사용하고, 이미지 토큰은 MaskGIT의 정신에 따라 마스크된 이산 확산을 사용합니다. 둘 다 하이브리드 어텐션 마스크를 가진 하나의 트랜스포머 안에 위치합니다. 그 결과는 하나의 백본, 모달리티당 하나의 토크나이저, 하나의 손실 공식(다음-토큰을 마스크된 예측으로 확장)으로 VQA, 텍스트-이미지, 인페인팅 및 혼합-모달리티 생성을 통합합니다. 이 레슨은 Show-o 설계 — 마스크된 이산 확산이 왜 병렬적이고 소수-단계 이미지 생성기인지 — 를 살펴보고 Transfusion 및 Emu3와 대조합니다.

**Type:** Learn
**Languages:** Python (stdlib, masked-discrete-diffusion sampler)
**Prerequisites:** Phase 12 · 13 (Transfusion)
**Time:** ~120 minutes

## 학습 목표

- 마스크된 이산 확산을 설명한다: 토큰을 균일하게 마스킹한 다음 트랜스포머가 이를 복구하도록 요청하는 스케줄.
- 병렬 이미지 디코딩(Show-o, MaskGIT)과 자기회귀 이미지 디코딩(Chameleon, Emu3)을 속도와 품질 측면에서 비교한다.
- Show-o가 하나의 체크포인트에서 처리하는 세 가지 작업(T2I, VQA, 이미지 인페인팅)을 나열한다.
- 마스킹 스케줄(코사인, 선형, 절단)을 선택하고 샘플 품질에 미치는 영향에 대해 추론한다.

## 문제

Transfusion의 두-손실 학습은 작동하지만 더 까다로운 역학을 가집니다 — 연속 확산 손실은 이산 NTP 손실과 다른 수치적 스케일에 존재합니다. 손실 가중치 균형 맞추기는 하이퍼파라미터 탐색입니다. 아키텍처는 효과적이지만 복잡합니다.

Show-o의 답변: 두 모달리티를 모두 이산적으로 유지하되(Chameleon처럼), 이미지를 순차적이 아닌 마스크된 이산 확산을 통해 병렬로 생성합니다. 학습 목적 함수는 다음-토큰-예측을 자연스럽게 일반화하는 단일 마스크된-토큰-예측이 됩니다.

## 개념

### 마스크된 이산 확산 (MaskGIT)

원래 Chang et al. (2022)의 MaskGIT 기법은 우아합니다. 완전히 마스크된 이미지(모든 토큰이 특별한 `<MASK>` id)에서 시작합니다. 각 단계에서 모든 마스크된 토큰을 병렬로 예측한 다음, 가장 자신 있는 상위-K 예측을 유지하고 나머지를 다시 마스킹합니다. 약 8-16회 반복 후 모든 토큰이 채워집니다. 단계당 마스크 해제할 토큰 수의 스케줄은 조정됩니다 — 코사인 스케줄이 잘 작동합니다.

학습은 간단합니다: [0, 1]에서 마스킹 비율을 균일하게 샘플링하고, 이를 이미지의 VQ 토큰에 적용하며, 트랜스포머가 마스크된 토큰을 복구하도록 학습합니다. 정확히 BERT가 텍스트에 대해 했던 일을 이미지 생성으로 확장한 것입니다.

### Show-o: 하나의 트랜스포머, 하이브리드 마스크

Show-o는 MaskGIT을 인과적-언어-모델 트랜스포머 안에 넣습니다. 어텐션 마스크는 다음과 같습니다:

- 텍스트 토큰: 인과적 (표준 LLM).
- 이미지 토큰: 이미지 블록 내에서 완전 양방향 (마스크된 토큰이 예측 중에 다른 모든 이미지 토큰을 볼 수 있도록).
- 텍스트-이미지: 텍스트는 이전 이미지에 어텐션, 이미지는 이전 텍스트에 어텐션.

학습은 다음을 번갈아 수행합니다:
1. 텍스트 시퀀스에 대한 표준 NTP.
2. T2I 샘플: 텍스트 → 이미지, 마스크된 이미지 토큰, 마스크된-토큰-예측 손실.
3. VQA 샘플: 이미지 → 텍스트, 마스크된 텍스트 토큰(사실상 NTP).

통합 손실은 `<MASK>` 토큰에 대한 교차 엔트로피로, 텍스트 NTP(마지막 토큰만 "마스크됨")와 이미지 마스크된-확산(무작위 부분집합이 마스크됨)을 모두 포함합니다.

### 병렬 샘플링

Show-o는 ~16단계로 이미지를 생성합니다(토큰당 자기회귀 ~1000단계나 확산 ~20단계 대신). 각 단계에서 모든 마스크된 토큰을 병렬로 예측합니다; 가장 자신 있는 상위-K를 확정하고 반복합니다.

비교:
- Chameleon / Emu3 (토큰에 대한 자기회귀): N_tokens 순전파, 일반적으로 이미지당 1024-4096회.
- Transfusion (연속 확산): ~20단계, 각각 전체 트랜스포머 순전파.
- Show-o (마스크된 이산 확산): ~16단계, 각각 전체 트랜스포머 순전파.

Show-o는 유사한 규모의 모델에서 Chameleon보다 빠르며, 단계 수는 Transfusion과 대략 일치하면서 단계당 비용이 더 낮습니다(연속 MSE 손실 대신 이산 어휘 로짓).

### 하나의 체크포인트에서의 작업

Show-o는 프롬프트 형식에 의해 선택되는 네 가지 작업을 추론 시 지원합니다:

- 텍스트 생성: 표준 자기회귀 텍스트 출력.
- VQA: 이미지 입력, 텍스트 출력.
- T2I: 텍스트 입력, 마스크된 이산 확산을 통한 이미지 출력.
- 인페인팅: 일부 토큰이 마스크된 이미지, 채워 넣기.

인페인팅 기능은 마스크된-예측 학습에서 무료로 제공됩니다. VQ-토큰 그리드의 영역을 마스킹하고, 나머지와 텍스트 프롬프트를 입력으로 제공하며, 마스크된 토큰을 예측합니다.

### 마스킹 스케줄

단계당 마스크 해제할 토큰 수의 스케줄이 품질을 결정합니다. Show-o는 코사인을 권장합니다:

```
mask_ratio(t) = cos(pi * t / (2 * T))   # t = 0..T
```

단계 0에서는 모든 토큰이 마스크됨(비율 1.0). 단계 T에서는 마스크 없음. 코사인은 예측이 가장 유용한 중간 비율에 질량을 집중합니다. 선형 스케줄도 작동하지만 더 빨리 정체됩니다.

### Show-o2

Show-o2(2025 후속, arXiv 2506.15564)는 Show-o를 확장합니다: 더 큰 LLM 베이스, 더 나은 토크나이저, 개선된 마스크 스케줄. 동일한 아키텍처 패턴.

### Show-o의 위치

2026년 분류에서:

- 이산 토큰 + NTP: Chameleon, Emu3. 간단하지만 추론이 느림.
- 이산 토큰 + 마스크된 확산: Show-o, MaskGIT, LlamaGen, Muse. 병렬 샘플링, 여전히 토크나이저에 의한 손실 있음.
- 연속 + 확산: Transfusion, MMDiT, DiT. 최고 품질, 더 복잡한 학습.
- VLM에서 연속 + 플로우 매칭: JanusFlow, InternVL-U. 최신.

작업에 따라 선택: 하나의 공개 모델에서 T2I + 인페인팅 + VQA를 합리적인 속도로 원할 때 Show-o; 품질이 가장 중요하고 두-손실 배관을 감당할 수 있을 때 Transfusion.

## 사용하기

`code/main.py`는 Show-o 샘플링을 시뮬레이션합니다:

- 16개 VQ 토큰의 장난감 그리드.
- 프롬프트와 현재 마스크 해제된 토큰을 기반으로 로짓을 예측하는 모의 "트랜스포머".
- 코사인 스케줄로 8단계에 걸친 병렬 마스크된 샘플링.
- 중간 상태(마스크 패턴 진화)와 최종 토큰을 출력합니다.

실행하고, 마스크가 단계별로 사라지는 것을 지켜보세요.

## 연습 문제

1. 마스크된 이산 확산은 ~16단계로 샘플링합니다. 왜 1단계가 아닐까요? 단계 0에서 모든 것을 마스크 해제하면 무엇이 깨질까요?

2. 인페인팅은 마스크된 확산으로 무료로 제공됩니다. Show-o의 인페인팅이 전문 모델을 능가하는 제품 사용 사례(실제 또는 가상)를 제안하세요.

3. 코사인 스케줄 vs 선형 스케줄: T=8에 대한 단계당 마스크 해제된 토큰 수를 추적하세요. 어느 쪽이 더 균형 잡혀 있나요?

4. 512x512 Show-o 이미지는 1024개 토큰입니다. 어휘 K=16384에서, 모델은 1024 * log2(16384) = 14,336비트(~1.75 KiB)의 데이터를 출력합니다. Stable Diffusion은 512*512*24비트 = 6,291,456비트(~768 KiB)의 원시 픽셀을 출력합니다. 압축 비율은 얼마이며, 어떤 품질을 얻을 수 있나요?

5. LlamaGen(arXiv:2406.06525)을 읽으세요. LlamaGen의 클래스-조건부 자기회귀 이미지 모델은 Show-o의 마스크된 접근 방식과 어떻게 다른가요?

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|-------------------|----------|
| Masked discrete diffusion | "MaskGIT 스타일" | 마스크된 토큰을 예측하도록 학습; 추론 시 가장 자신 있는 예측을 반복적으로 마스크 해제 |
| Cosine schedule | "마스크 해제 스케줄" | 추론 단계에 따른 마스크 비율의 감소; 중간 범위에서 신뢰도 성장 집중 |
| Parallel decoding | "모든 토큰을 한 번에" | 각 단계가 한 번의 순전파로 마스크된 토큰의 전체 시퀀스를 예측한 후 상위-K 확정 |
| Hybrid attention | "인과적 + 양방향" | 텍스트 토큰에 대해서는 인과적이고 이미지 블록 내에서는 양방향인 마스크 |
| Inpainting | "채우기 생성" | 일부 토큰이 마스크된 이미지를 조건으로, 누락된 부분을 예측; 학습 목적 함수에서 무료로 제공 |
| Commitment rate | "단계별 상위-K" | 반복당 "완료"로 선언되는 토큰 수; 추론과 품질 간의 트레이드오프 제어 |
