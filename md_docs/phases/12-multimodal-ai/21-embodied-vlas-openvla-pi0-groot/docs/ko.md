# 체화된 VLA: RT-2, OpenVLA, π0, GR00T

> 모델이 웹사이트에서 레시피를 읽고 주방 로봇에서 실행한 첫 번째 사례는 RT-2(Google DeepMind, 2023년 7월)였습니다. RT-2는 행동을 텍스트 토큰으로 이산화하고, 웹 데이터와 로봇-행동 데이터에 대해 VLM을 공동 미세 조정했으며, 웹 규모의 비전-언어 지식이 로봇 제어로 전이됨을 증명했습니다. OpenVLA(2024년 6월)는 오픈 7B 참조를 제공했습니다. Physical Intelligence의 π0 시리즈(2024-2025)는 플로우 매칭 행동 전문가를 추가했습니다. NVIDIA의 GR00T N1(2025년 3월)은 인간형 로봇을 위한 이중 시스템(System 1 / System 2) 제어를 대규모로 제공했습니다. VLA 프리미티브 — 비전-언어-행동, 보고, 읽고, 행동하는 단일 모델 — 은 이 단계의 이해 모델과 Phase 15의 자율 시스템 사이의 다리입니다.

**Type:** Learn
**Languages:** Python (stdlib, action tokenizer + VLA inference skeleton)
**Prerequisites:** Phase 12 · 05 (LLaVA), Phase 15 (Autonomous Systems, 참조)
**Time:** ~180 minutes

## 학습 목표

- 행동 토큰화를 설명한다: 이산 빈 인코딩(RT-2), FAST 효율적 행동 토큰, 연속 플로우 매칭 행동(π0).
- 웹 + 로봇 데이터에 대한 공동 미세 조정이 새로운 작업으로의 일반-지식 전이를 보존하는 이유를 설명한다.
- 동일한 로봇 작업에서 OpenVLA(오픈 7B Llama+VLM), π0(플로우-매칭), GR00T N1(이중-시스템)을 비교한다.
- Open X-Embodiment 데이터셋과 RT-X 학습 코퍼스로서의 역할을 나열한다.

## 문제

자연어 명령으로 집안일을 하는 로봇은 1970년대부터 연구 목표였습니다. 2020년대의 답변: 비전-언어-행동(VLA) 모델. VQA에 사용되는 것과 동일한 VLM 아키텍처이지만, 출력은 텍스트 대신 행동(관절 토크, 엔드-이펙터 포즈, 이산 명령)입니다.

VLA에 특화된 과제:

1. 행동 공간은 연속적(관절 각도, 힘)이고 고차원적(7-DOF 암 + 3-DOF 그리퍼 = 10차원, 30 Hz).
2. 로봇 특화 학습 데이터는 부족. Open X-Embodiment는 ~1M 궤적; 웹 텍스트-이미지는 5B+.
3. 제어 주파수 중요. 30 Hz 제어 루프는 행동당 33ms 예산 의미.
4. 안전. 잘못된 행동은 하드웨어, 사람 또는 재산 손상.

## 개념

### 행동 토큰화 (RT-2)

RT-2의 기법: 각 관절 목표를 양자화된 텍스트 토큰으로 표현. 정규화된 [-1, 1] 범위를 256개 빈으로 이산화하고, 각 빈을 어휘 ID에 매핑. 10-DOF 행동은 각 제어 단계에서 10개 토큰이 됩니다.

PaLM-X VLM을 혼합 데이터로 공동 미세 조정:

- 웹 이미지-텍스트 쌍(캡셔닝, VQA).
- 로봇 시연, 행동을 토큰으로.

모델은 "빨간 큐브를 집어"(언어) → 이미지(비전) → 10-토큰 행동 시퀀스(이산화된 관절 목표)를 봅니다. 웹 사전 학습은 일반-지식 전이를 보존: RT-2는 "빠르게 움직이는 물체 쪽으로 이동"을 따를 수 있는데, "빠르게 움직이는"이 학습 데이터에 없더라도 가능합니다.

RT-2 논문에서 추론은 3-5 Hz로, VLM 자기회귀 디코드에 의해 제한됨.

### OpenVLA — 오픈 7B 참조

OpenVLA(Kim et al., 2024년 6월)는 오픈-가중치 RT-2 등가물입니다. 7B Llama 백본, DINOv2 + SigLIP 이중 비전 인코더, 256개 빈에 대한 행동 토큰화.

Open X-Embodiment(22개 로봇에 걸친 970k 궤적)로 학습. 새로운 로봇에 적응하기 위한 LoRA 미세 조정 지원 제공.

추론: 양자화로 A100에서 4-5 Hz. 느린 조작에는 충분히 빠르지만, 고주파 제어에는 부적합.

### FAST 토크나이저 — 더 빠른 행동 디코드

Pertsch et al. (2024)은 이산-빈 토큰화가 비효율적임을 보여주었습니다 — 대부분의 행동이 빈-공간의 작은 영역에 모입니다. FAST(Frequency-domain Action Sequence Tokenizer)는 DCT를 통해 행동 시퀀스를 압축하고 계수를 양자화합니다.

30-단계 행동 궤적은 300개의 이산-빈 토큰 대신 ~10개의 FAST 토큰이 됩니다. 품질 손실 없이 추론이 3-5배 빨라집니다.

### π0와 플로우 매칭 행동

Physical Intelligence의 π0(Black et al., 2024년 10월)는 이산 행동 토큰을 플로우 매칭 행동 전문가로 대체합니다:

- 소형 행동 트랜스포머가 VLM의 히든 상태를 읽고 교정된 플로우를 통해 연속 50-단계 행동 시퀀스를 출력.
- 행동 헤드는 플로우-매칭 손실로 학습; VLM 사전 학습은 변경되지 않음.
- 추론: ~5회 잡음 제거 단계에서 전체 행동 시퀀스 방출, 효과적으로 50 Hz 제어.

π0의 주장: 광범위한 조작 작업에서 OpenVLA와 Octo를 능가. 연속-행동 공식은 이산화가 파괴하는 평활성을 보존.

π0.5와 π0-FAST는 점진적 업그레이드. π0-FAST는 FAST 토큰화와 플로우 매칭을 결합.

### GR00T N1 — 인간형을 위한 이중 시스템

NVIDIA의 GR00T N1(2025년 3월)은 인간형 로봇(>30 DOF, 전신)을 위해 구축:

- System 2: 장면 + 명령을 읽는 대형 VLM, ~1 Hz로 고수준 하위 목표 생성.
- System 1: 하위 목표를 조건으로 저수준 50-100 Hz 관절 명령을 생성하는 소형 행동-헤드 트랜스포머.

분할은 Kahneman의 빠른-느린 사고에 매핑: System 2가 계획, System 1이 실행. 이점: 느린 VLM-크기의 계획이 빠른 제어를 차단하지 않음; System 1이 지연 시간을 위해 작게 유지.

GR00T N1.7(2025년 후반)은 데이터 스케일링 개선. GR00T는 Omniverse의 sim-to-real 데이터로 미세 조정.

### Open X-Embodiment

학습 데이터. RT-X(2023년 10월)는 22개 로봇에 걸친 1M 궤적을 포함하는 22개 데이터셋을 모았습니다. Open X-Embodiment는 모든 사람이 사용하는 코퍼스:

- ALOHA / Bridge V2 / Droid / RT-2 Kitchen / Language Table.
- 각 샘플: (로봇 상태, 카메라 뷰, 명령, 행동 시퀀스).
- 학습 위생: 행동 공간 통일, 관절 범위 정규화, 카메라 크기 조정.

OpenVLA와 π0는 Open X-Embodiment에서 학습. 특정 로봇에 대한 도메인 격차는 100-1000개의 작업-특화 데모에 대한 LoRA 미세 조정으로 해소.

### 공동 미세 조정 vs 로봇 전용

공동 미세 조정은 웹 VQA 데이터와 로봇 궤적을 혼합. 비율이 중요: VQA가 너무 많으면 모델이 행동을 잊음; 로봇 데이터가 너무 많으면 모델이 일반 지식을 잃음.

RT-2의 비율: ~1:1. OpenVLA: ~0.5:1 웹-대-로봇. π0: 유사. 정확한 비율은 데이터셋 크기별로 조정할 하이퍼파라미터.

로봇 전용 학습은 분포 외 명령에서 실패하는 작업-특화 모델을 생성. 공동 미세 조정은 "빨간 큐브를 집어(데모에 있음)"와 "왼쪽에서 세 번째로 큰 물체를 집어(새로운 표현)"의 차이.

### 안전 및 행동 제한

모든 프로덕션 VLA는 다음을 탑재:

- 하드 관절 제한(사양 이상의 토크 불가).
- 속도 제한(소프트 클리핑).
- 작업공간 경계(엔드-이펙터가 테이블을 벗어날 수 없음).
- 새로운 작업에 대한 인간-인-더-루프 승인.

이것들은 제어-계층 검사로 VLA 외부에 위치. VLA의 출력은 제안이지 명령이 아닙니다.

## 사용하기

`code/main.py`:

- 256-빈 행동 토큰화 및 디토큰화 구현.
- DCT + 양자화 기반 FAST 토크나이저 스케치.
- (이산-빈, FAST, 연속-플로우) 간 행동 단계당 토큰 수 비교.
- RT-2 → OpenVLA → π0 → GR00T 계보 요약 출력.

## 결과물

이 레슨은 `outputs/skill-vla-action-format-picker.md`를 생성합니다. 로봇 작업(조작, 내비게이션, 인간형 전신)이 주어지면, 이산-빈 + RT-2, FAST + OpenVLA, 플로우-매칭 + π0, 또는 이중-시스템 + GR00T 중에서 선택.

## 연습 문제

1. 30 Hz 제어 속도의 10-DOF 암. 256개 빈의 이산-빈 토큰화는 초당 몇 개의 토큰을 방출하나요? 7B VLM이 따라잡을 수 있나요?

2. FAST 토큰화는 30-단계 궤적을 ~10개 토큰으로 압축. 궤적에 고주파 움직임(예: 드럼 치기)이 있으면 사용자는 무엇을 잃나요?

3. π0의 플로우-매칭 헤드는 ~5단계로 잡음 제거. 4-5 Hz의 OpenVLA 자기회귀 디코드와 처리량을 비교하세요.

4. GR00T의 System 1 / System 2 분할은 Kahneman에 매핑. 이족 보행에 도움이 될 수 있는 다른 분할(System 3?)을 제안하세요.

5. Open X-Embodiment 섹션 4(데이터셋 큐레이션)를 읽으세요. 도메인 누출을 방지하는 세 가지 큐레이션 규칙을 나열하세요.

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|-------------------|----------|
| VLA | "비전-언어-행동" | 이미지 + 명령을 받아 행동 명령을 출력하는 모델 |
| Action tokenization | "이산 빈" | 연속 관절 목표를 차원당 256개 빈으로 양자화, 각각 어휘 ID |
| FAST tokenizer | "주파수 행동 토큰" | DCT + 양자화로 30-단계 궤적을 ~10개 토큰으로 압축 |
| Co-fine-tune | "웹 + 로봇 혼합" | 일반 지식 보존을 위해 로봇 데모와 함께 웹 VQA 데이터 학습 |
| Flow-matching action head | "π0 연속 출력" | 교정된 플로우를 통해 50-단계 행동 시퀀스를 출력하는 소형 트랜스포머 |
| System 1 / System 2 | "이중-시스템 제어" | 대형 VLM이 천천히 계획, 소형 행동 헤드가 빠르게 실행; GR00T 패턴 |
| Open X-Embodiment | "RT-X 데이터셋" | 1M-궤적 교차-로봇 데이터셋; 학습 코퍼스 |
