# CLIP에서 BLIP-2까지 — Q-Former를 모달리티 브릿지로

> CLIP는 이미지와 텍스트를 정렬하지만 캡션을 생성하거나 질문에 답하거나 대화를 유지할 수 없다. BLIP-2(Salesforce, 2023)는 작은 훈련 가능한 브릿지로 이를 해결했다: 32개의 학습 가능한 쿼리 벡터가 교차 어텐션을 통해 동결 ViT의 피처에 attend한 다음 동결 LLM의 입력 스트림에 직접 슬롯된다. 188M 파라미터의 브릿지가 11B LLM을 ViT-g/14에 연결했다. 2026년까지 모든 어댑터 기반 VLM — MiniGPT-4, InstructBLIP, LLaVA의 사촌들 —은 후손이다. 이 레슨은 Q-Former의 아키텍처를 읽고 2단계 훈련을 설명하며, 시각 토큰을 동결 텍스트 디코더에 공급하는 토이 버전을 구축한다.

**유형:** 실습
**언어:** Python (stdlib, 교차 어텐션 + 학습 가능한 쿼리 데모)
**선수 과목:** Phase 12 · 02 (CLIP), Phase 7 (트랜스포머)
**소요 시간:** ~180분

## 학습 목표

- 동결 비전 인코더와 동결 LLM 사이의 훈련 가능한 병목이 엔드투엔드 미세조정보다 비용과 안정성에서 뛰어난 이유를 설명한다.
- 고정된 학습 가능한 쿼리 세트가 외부 이미지 피처에 교차 어텐션하는 교차 어텐션 블록을 구현한다.
- BLIP-2의 2단계 사전훈련을 따라간다: 표현(ITC + ITM + ITG) then 생성(LM 손실과 동결 디코더).
- Q-Former를 LLaVA에서 사용되는 더 간단한 MLP 투영기와 비교하고 각 선택이 언제 이기는지議論한다.

## 문제

당신은 이미지당 256개의 패치 토큰(차원 1408)을 생성하는 동결 ViT를 가지고 있다. 차원 4096의 토큰 임베딩을 기대하는 동결 7B LLM을 가지고 있다. 명백한 브릿지 — 1408에서 4096으로의 선형 레이어 — 작동하지만, 모든 256개의 패치 토큰을 LLM의 컨텍스트에 공급하면 이미지당 256개의 추가 토큰이 든다. 32개 이미지의 배치에서それは 8192개의 토큰이 비주얼 모달리티에만 소비된다.

BLIP-2 질문: 256-토큰 이미지 표현을 (말하여 32개)로 훨씬 적은 토큰으로 압축하면서 LLM이 이미지를 캡션하고 질문에 답하고 추론할 수 있는 충분한 정보를 보존할 수 있는가? 그리고 동결 백본을 건드리지 않고 브릿지만 훈련할 수 있는가, 훈련 비용은 브릿지의 파라미터만으로 유지?

답변: Q-Former. 32개의 학습 가능한 "쿼리" 벡터가 ViT의 패치 토큰에 교차 어텐션하여 LLM이 소비하는 32-토큰 시각 요약을 생성한다. 총 188M 파라미터. LLM을 건드리기 전에 대비적, 매칭, 생성 목표와 함께 훈련되었다.

## 개념

### 학습 가능한 쿼리

Q-Former의 핵심 트릭: LLM의 텍스트 토큰이 이미지 패치에 attend하도록 허용하는 대신, 새로운 32개의 학습 가능한 쿼리 벡터 `Q`를 도입하고 *它ら*가 이미지 패치에 attend하도록 한다. 쿼리는 모델의 파라미터다 — 훈련 중 학습되며 모든 이미지에 대해 동일한 32개의 쿼리가 사용된다.

교차 어텐션 후, 각 쿼리는 이미지의 압축된 요약은 "메인 객체를 설명하라", "배경을 설명하라", "객체를 카운트하라" 등을 담고 있다. 쿼리가 Literally 시맨틱 레이블에 전문화되지 않는다; 그들은 다운스트림 손실이 감소하는 인코딩을 학습한다.

### 아키텍처

Q-Former는 두 가지 경로가 있는 작은 트랜스포머(12 레이어, ~100M 파라미터)다:

1. 쿼리 경로: 32개 쿼리 벡터가.self-attention(彼此之间)을 통해 흐른 다음 동결 ViT의 패치 토큰에 교차 어텐션, 그 다음 FFN.
2. 텍스트 경로: BERT 유사 텍스트 인코더가 쿼리 경로와 self-attention 및 FFN 가중치를 공유한다. 교차 어텐션은 텍스트 경로에 대해 비활성화된다.

훈련 시 두 경로 모두 실행된다. 쿼리와 텍스트는 공유 self-attention을 통해相互作用하므로 쿼리는(ITM, ITG가 필요한 태스크에 대해) 텍스트에 조건을 할 수 있다. VLM 핸드오프를 위한 추론 시에는 쿼리만 흐르고, 32개의 시각 토큰을 산출한다.

### 2단계 훈련

BLIP-2는 두 단계로 사전훈련한다:

1단계: 표현 학습 (LLM 없음). 세 가지 손실:
- ITC (이미지-텍스트 대비): 풀링된 쿼리 토큰과 텍스트 CLS 토큰 사이의 CLIP 스타일 대비.
- ITM (이미지-텍스트 매칭): 이진 분류기 — 이 이미지-텍스트 페어가 일치하는가? 하드 네거티브 마이닝됨.
- ITG (이미지 기반 텍스트 생성): 쿼리에 조건화된 텍스트의 인과적 LM 헤드. 쿼리가 텍스트 생성 가능한 콘텐츠를 인코딩하도록 강제한다.

Q-Former만 훈련한다. ViT는 동결된다. LLM은 관여하지 않는다.

2단계: 생성 학습. 동결 LLM(OPT-2.7B 또는 Flan-T5-XL 등)을 연결한다. 32개 쿼리 출력을 LLM의 임베딩 차원으로 작은 선형 레이어를 통해 투영한다. 텍스트 프롬프트 앞에 붙인다. 연결된 프롬프트 + 이미지 + 캡션 시퀀스에 대한 LM 손실에 대해 선형 투영과 Q-Former만 훈련한다.

2단계 후, Q-Former + 투영이 전체 비주얼 어댑터다. 추론 시: 이미지 → ViT → Q-Former → 선형 proj → 텍스트 앞에 붙임 → 동결 LLM이 출력.

### 파라미터 경제학

ViT-g/14 (1.1B, 동결) + OPT-6.7B (6.7B, 동결) + Q-Former (188M, 훈련) = 8B 총계, 188M 훈련. Q-Former 단독은 전체 스택 파라미터의 약 2.4%다. 훈련 비용이 이를 반영한다: 몇 개의 A100에서 며칠 vs 엔드투엔드의 몇 주.

품질: BLIP-2는 제로샷 VQA에서 Flamingo-80B와 일치하거나 능가하면서 50배 작다. 브릿지가 작동한다.

### InstructBLIP와 지시 인식을하는 Q-Former

InstructBLIP(2023)는 추가 입력을 통해 Q-Former를 확장한다: 지시 텍스트 자체. 교차 어텐션 시점에 쿼리는 이제 이미지 패치와 지시 모두에 접근한다. 쿼리는 ("차량을 카운트", "분위기를 묘사") 지시별로 전문화할 수 있으며 고정된 요약이 아니다. 보유된 태스크에서 벤치마크 향상.

### MiniGPT-4와 투영기 전용 접근법

MiniGPT-4는 Q-Former를 유지했지만 다른 모든 것을 동결하면서 출력 선형 투영만 훈련했다. 저렴하지만 품질 비용 — 쿼리는 BLIP-2의 것이지 yours가 아니다. 빠른 반복에는 좋지만 최상의 아키텍처는 아니다.

### LLaVA가 더 단순해진 이유

LLaVA(2023, 레슨 12.05)는 Q-Former를 모든 ViT 패치 토큰을 LLM 공간으로 투영하는 평범한 2-layer MLP로 교체했다 — 이미지에 대해 576 토큰(24x24 그리드의 경우). 더 나쁜 압축이지만 LLM이 원시 패치에 attend하도록 허용한다. 당시 이것은 논쟁의 여지가 있었다; 2023년 후반까지 지배적이었다因为视觉指令数据(LLaVA-Instruct-150k)가 MLP가 충분한 신호를 보존하도록 훈련될 수 있음을 증명했기 때문이다. 트레이드오프: LLM의 컨텍스트가 더 빠르게 채워지지만, 멀티이미지와 비디오로 자연스럽게 확장된다.

2026년까지 이 분야는 분열되었다: 토큰 예산이 중요한 곳에서는 Q-Former가 생존한다(긴 비디오, 많은 이미지); 토큰당 품질 우선인 곳에서는 MLP 투영기가 지배한다.

### 게이트된 교차 어텐션: Flamingo, 조상

Flamingo(레슨 12.04)는 BLIP-2보다 앞서 있었고 모든 동결 LLM 레이어에서 동일한 교차 어텐션 아이디어를 사용했지만 단일 브릿지로가 아닌. BLIP-2는 입력 레이어에만 압축해도 작동함을 보여주었다. Gemini와 Idefics2는 둘 다 결합한다: 인터리브된 입력 토큰 plus 선택적 게이트된 교차 어텐션 for 인컨텍스트 few-shot.

### 2026년 후손

- Q-Former: BLIP-2, InstructBLIP, MiniGPT-4, 대부분의 비디오-언어 모델(토큰 예산 이유).
- Perceiver 리샘플러: Flamingo 변형(레슨 12.04); Idefics 패밀리, Eagle, OmniMAE.
- MLP 투영기: LLaVA, LLaVA-NeXT, LLaVA-OneVision, Cambrian-1.
- 어텐션 풀: VILA, PaliGemma.

네 가지 모두 유효하다. 결정 질문은 토큰 예산이나 토큰당 품질 중 어느 것이 제약인지이다.

## 활용

`code/main.py`는 stdlib Q-Former 스타일 교차 어텐션을 구축한다:

1. 256개 이미지 패치 토큰(차원 128) 시뮬레이션.
2. 32개의 학습 가능한 쿼리(차원 128) 인스턴스화.
3. 스케일된 도트 프로덕트 교차 어텐션 실행(Q from queries, K/V from patches).
4. 선형 레이어를 통해 LLM 차원(512)으로 투영.
5. 32개의 LLM 준비 시각 토큰 출력.

모든 수학이 순수 Python(벡터에 대한 중첩 루프). 토이이지만 올바른 형태. 어텐션 가중치 행렬이 인쇄되어 각 쿼리가 어떤 패치에서 가져왔는지 볼 수 있다.

## 결과물

이 레슨은 `outputs/skill-modality-bridge-picker.md`를 생성한다. 대상 VLM 구성(비전 인코더 토큰 수, LLM 컨텍스트 예산, 배포 제약, 품질 목표)이 주어지면 Q-Former 대 MLP 대 Perceiver 리샘플러를 권장하며 짧은 근거와 각 브릿지의 파라미터 수 추정을 제공한다.

## 연습 문제

1. PyTorch에서 교차 어텐션 블록을 구현한다. 32개의 쿼리와 256개의 키/값으로 어텐션 가중치 행렬이 32 x 256이고 각 행이 softmax 후 1의 합계를 갖는지 확인한다.

2. BLIP-2 1단계에서 Q-Former는 세 가지 손실(ITC, ITM, ITG)을 동시에 실행한다. 각 항목의 정방향 사인을 의사코드로 작성한다. 어떤 항목이 텍스트 인코더 경로가 활성 상태여야 하는가?

3. 파라미터 수 비교: Q-Former (12 레이어, 768 히든) 대 2-layer MLP 투영기 (1408 → 4096, 두 레이어). 어떤 LLM 규모에서 188M Q-Former 비용이 훈련 효율성에서 상환되는가?

4. Q-Former가 어떻게 초기화되는지 대한 BLIP-2 논문(arXiv:2301.12597) 섹션 3.2를 읽는다. BERT-base에서 무작위가 아닌 것으로 초기화하면 수렴이加速되는 이유를 설명한다.

5. 1 FPS로 샘플링된 10분 비디오의 경우, (Q-Former → 32 토큰/프레임) 대 (MLP 투영기 → 576 토큰/프레임)에서 프레임당 토큰 비용을 계산한다. 128k 토큰 LLM 컨텍스트 창에 맞는가?

| 교차 어텐션 | "Q는 여기서, K/V는 저기서" | 쿼리, 키, 값이 다른 소스에서 오는 어텐션; 쿼리가 ViT 패치에서 가져오는 방식 |
| ITC | "이미지-텍스트 대비" | 풀링된 Q-Former 쿼리와 텍스트 CLS에 적용되는 CLIP 스타일 손실 |
| ITM | "이미지-텍스트 매칭" | 하드 네거티브 마이닝된 페어에 대한 이진 분류기; 쿼리가 세밀한 불일치를 구별하도록 강제 |
| ITG | "이미지 기반 텍스트 생성" | 쿼리에 조건화된 텍스트 생성에서의 인과적 LM 손실; 쿼리가 텍스트 디코딩 가능한 콘텐츠를 인코딩하도록 강제 |
| 2단계 사전훈련 | "표현 then 생성" | 1단계는 Q-Former만 훈련(ITC/ITM/ITG); 2단계는 동결 LLM을 연결하고 투영 + Q-Former만 훈련 |
| 동결 백본 | "미세조정 안함" | 비전 인코더와 LLM 가중치는 고정됨; 브릿지만 훈련 |
| 투영 헤드 | "LLM 차원으로 선형" | Q-Former 출력을 LLM의 임베딩 차원으로 매핑하는 최종 선형 레이어 |
