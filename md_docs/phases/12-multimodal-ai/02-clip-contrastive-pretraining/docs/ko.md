# CLIP와 대조적 비전-언어 사전훈련

> OpenAI의 CLIP(2021)은 다음 5년을 이끌기에 충분한 하나의 아이디어를 증명했다: 노이즈가 많은 웹 이미지-캡션 페어와 대조적 손실만 사용하여 이미지 인코더와 텍스트 인코더를 같은 벡터 공간에 정렬한다. 제로 감독 레이블. 400M 페어. 결과적인 임베딩 공간은 제로샷 분류, 이미지-텍스트 검색을 수행하고 모든 2026 VLM에 비전 타워로 연결된다. SigLIP 2(2025)는 softmax를 시그모이드로 대체하고更低 비용으로 CLIP를 능가했다. 이 레슨은 InfoNCE에서 시그모이드 페어별 손실까지 수학을 설명하고 stdlib Python으로 훈련 단계를 구축한다.

**유형:** 실습
**언어:** Python (stdlib, InfoNCE + 시그모이드 손실 구현)
**선수 과목:** Phase 12 · 01 (ViT 패치), Phase 7 (트랜스포머)
**소요 시간:** ~180분

## 학습 목표

- 상호 정보로부터 InfoNCE 손실을 유도하고 수치적으로 안정적인 벡터화 버전을 구현한다.
- 시그모이드 페어별 손실(SigLIP)이 일괄 처리 32768+로 확장되는 이유를 설명한다 — softmax가 요구하는 all-gather 오버헤드 없이.
- 텍스트 템플릿(`a photo of a {class}`)을 구성하고 코사인 유사도에서 argmax를 취하여 제로샷 ImageNet 분류를 실행한다.
- CLIP / SigLIP 사전훈련이 제공하는 네 가지 레버 назвать: 배치 크기, 온도, 프롬프트 템플릿, 데이터 품질.

## 문제

CLIP 이전 비전은 감독되었다. 레이블이 있는 데이터셋(ImageNet: 1.2M 이미지, 1000 클래스)을 수집하고, CNN을 훈련하고, 출시한다. 레이블은 비싸고, 레이블은 레이블러가 동의할 수 있는 것에 편향되며, 레이블은 미세조정 없이는 새 태스크로 이전되지 않는다.

이미지-캡션 웹에는 무료의 느슨하게 레이블된 10억 개 이상의 페어가 있다. "my dog Max in the park"라는 alt 텍스트가 있는 골든 리트리버 사진은 감독 신호를 담고 있다 — 텍스트가 이미지를 설명한다. 질문: 이것을 유용한 훈련으로 전환할 수 있는가?

CLIP의 대답: 이미지-캡션 페어를 매칭 태스크로 취급한다. N개의 이미지와 N개의 캡션 배치가 주어지면, 각 이미지를 N-1개의 분산 요소에 대해 자체 캡션과 일치하도록 학습한다. 감독은 "이 두 가지는 함께 속한다; 이 N-1은 아니다." 클래스 레이블 없음. 인간 주석 없음. 대조적 손실만.

결과적인 임베딩 공간은 CLIP가 훈련된 것 이상의 일을 한다. "a photo of a cat"가 명시적으로 고양이로 레이블되지 않은 고양이 사진 근처에 임베딩되기 때문에 ImageNet 제로샷이 작동한다. 이것이 모든 2026 VLM을 생성한 베팅이다.

## 개념

### 이중 인코더

CLIP는 두 개의 타워를 가지고 있다:

- 이미지 인코더 `f`: ViT 또는 ResNet, 이미지당 D차원 벡터 출력.
- 텍스트 인코더 `g`: 작은 트랜스포머, 캡션당 D차원 벡터 출력.

두 타워 모두 출력을 단위 길이로 정규화한다. 유사도는 `cos(f(x), g(y)) = f(x)^T g(y)` — 둘 다 단위 노름이기 때문이다.

N개의 (이미지, 캡션) 페어 배치가 주어지면, shape `(N, N)`의 유사도 행렬 `S`를 구축한다:

```
S[i, j] = cos(f(x_i), g(y_j)) / tau
```

`tau`는 학습된 온도(CLIP는 0.07로 초기화; 로그 공간에서 학습).

### InfoNCE 손실

CLIP는 행과 열에 대해 대칭적인 교차 엔트로피를 사용한다:

```
loss_i2t = CE(S, labels=identity)     # 각 이미지의 양성은 자체 캡션
loss_t2i = CE(S^T, labels=identity)   # 각 캡션의 양성은 자체 이미지
loss = (loss_i2t + loss_t2i) / 2
```

이것이 InfoNCE다. CE의 softmax는 각 이미지가 배치의 모든 다른 캡션보다 자체 캡션과 더 잘 일치하도록强迫한다. "네거티브"는 모든 다른 배치 항목이다. 더 큰 배치 = 더 많은 네거티브 = 더 강한 신호. CLIP는 배치 32k에서 훈련했다; 규모가 중요하다.

### 온도

`tau`는 softmax의 날카로움을 控制한다. 낮은 tau → 날카로운 분포, 하드 네거티브 마이닝 효과. 높은 tau → 부드럽고, 모든 샘플이 기여한다. CLIP는 log(1/tau)를 학습하고,崩溃를 방지하기 위해 클리핑한다. SigLIP 2는 초기 tau를 고정하고 학습된 바이어스를 대신 사용한다.

### 시그모이드가 더 잘 확장하는 이유 (SigLIP)

Softmax는 전체 유사도 행렬과 동기화가 필요하다. 분산 훈련에서 모든 레플리카에 모든 임베딩을 수집한 다음 softmax를 수행해야 한다. 이것은 통신에서 세계 크기에 대해 2차적이다.

SigLIP는 요소별 시그모이드로 softmax를 대체한다: 각 페어 `(i, j)`에 대해 "이 매칭 페어인가?"의 이진 분류, positive 클래스 레이블은 대각선, 나머지는 모두 네거티브. 손실은:

```
L = -1/N sum over (i, j) [ y_ij log sigmoid(S[i,j]) + (1-y_ij) log sigmoid(-S[i,j]) ]
```

`y_ij = 1` if `i == j`, else 0. 각 페어의 손실은 독립적이다. All-gather 필요 없음. 각 GPU는 로컬 블록을 계산하고 합산한다. SigLIP 2는 CLIP가 비례해서 더 많은 통신이 필요한 곳에서 배치 32k-512k로 저렴하게 확장된다.

### 제로샷 분류

N개의 클래스 이름이 주어지면, 각 클래스에 대해 텍스트 템플릿을 구축한다:

```
"a photo of a {class}"
```

텍스트 인코더로 각 템플릿을 임베딩한다. 이미지 인코더로 이미지를 임베딩한다. 코사인 유사도 argmax = 예측된 클래스. 대상 클래스에서 훈련 없음.

프롬프트 템플릿이 중요하다. CLIP의 원본 논문은 클래스당 80개의 템플릿(plain, artistic, photo, painting 등)을 사용하고 임베딩을 평균화했다. +3 ImageNet 포인트. 현대 사용법은 전형적으로 하나 또는 두 개의 템플릿을 선택한다.

### 선형 프로브와 미세조정

제로샷은 기준선이다. 선형 프로브(대상 클래스에 대해 동결된 CLIP 피처 위에 하나의 선형 레이어 훈련)는 도메인 내 태스크에서 제로샷을 능가한다. 전체 미세조정은 도메인 내에서 선형 프로브를 능가하지만 제로샷 이전을 해칠 수 있다. 세 가지 체제, 세 가지 트레이드오프.

### SigLIP 2: NaFlex와 밀집 피처

SigLIP 2(2025)는 다음을 추가한다:
- NaFlex: 단일 모델이 가변 종횡비와 해상도를 처리한다.
- VLM에서 동결 백본을 겨냥한 세그멘테이션과 깊이 추정을 위한 더 나은 밀집 피처.
- 다국어: CLIP가 영어만だった 곳에서 100개 이상의 언어로 훈련됨.
- CLIP가 400M에서 최고였던 1B 파라미터 규모.

2026년 오픈 VLM에서 SigLIP 2 SO400m/14는 기본 비전 타워다. CLIP는 특정 LAION-2B 훈련 분포가 쿼리 패턴과 일치하는 순수 이미지-텍스트 검색의 기본값으로 remains.

### ALIGN, BASIC, OpenCLIP, EVA-CLIP

ALIGN (Google, 2021): CLIP와 동일한 아이디어, 1.8B 페어 규모, 90% 노이즈. 노이즈 데이터가 확장됨을 증명함. OpenCLIP (LAION): LAION-400M / 2B에서 CLIP의 오픈 재생, 여러 규모, goto 오픈 체크포인트. EVA-CLIP: 마스킹된 이미지 모델링에서 초기화; VLM용 강력한 백본. BASIC: Google's CLIP+ALIGN hybrid. 모두 같은 계열, 다른 데이터와 튜닝.

### 제로샷 천장

CLIP 클래스 모델은 약 76% ImageNet 제로샷(CLIP-G, OpenCLIP-G)에서 정점에達한다. 그 이상은 훨씬 더 큰 데이터(SigLIP 2가 80%+ 달성) 또는 아키텍처 변경(감독 헤드, 더 많은 파라미터)을 요구한다. 벤치마크가 포화되고 있다; 실제 가치는 다운스트림 VLM이 소비하는 임베딩 공간이다.

## 활용

`code/main.py` 구현:

1. 토이 이중 인코더(해시 기반 이미지 피처, 텍스트 문자 피처) — numpy 없이 InfoNCE 형태를 볼 수 있음.
2. 순수 Python의 InfoNCE 손실(log-sum-expによる数値安定性).
3. 비교를 위한 시그모이드 페어별 손실.
4. 제로샷 분류 루틴: 텍스트 프롬프트 세트에 대한 코사인 유사도 계산, argmax로 예측.

실행하고 손실 곡선을 관찰한다. 절대 숫자는 토이이지만 모양이 실제 CLIP 트레이너가 출력하는 것과 일치한다.

## 결과물

이 레슨은 `outputs/skill-clip-zero-shot.md`를 생성한다. 이미지 경로와 대상 클래스 목록이 주어지면 CLIP 템플릿으로 텍스트 프롬프트를 构建하고, 명시된 체크포인트(예: `openai/clip-vit-large-patch14`)로 양쪽을 임베딩하고, 유사도 점수로 top-1 / top-5 예측을 반환한다. 스킬은 프롬프트 목록에 없는 클래스에 대한 주장을 거부한다.

## 연습 문제

1. 4개 페어 배치에 대해 InfoNCE를手計算으로 구현한다. 4x4 유사도 행렬을 구성하고, softmax를 실행하고, 대각선을 선택하고, 교차 엔트로피를 계산한다. Python 구현이 이手計算과 일치함을 확인한다.

2. SigLIP는 배치에 큰 클래스 불균형이 있을 때 추가적인 바이어스 파라미터 `b`를 사용한다: `S'[i,j] = S[i,j]/tau + b`. 행당 양수보다 네거티브가 훨씬 많은 경우 `b`가 어떤 역할을 하는가? SigLIP 섹션 3(arXiv:2303.15343)을 읽는다.

3. 고양이 vs 개에 대한 제로샷 분류기를 구축한다. 두 가지 프롬프트 템플릿을 시도: `a photo of a {class}`와 `a picture of a {class}`. 100개의 테스트 이미지에서 정확도를 측정한다. 템플릿 앙상블이 단일보다 나은가?

4. 배치 32k에서 512-GPU 실행에 대한 softmax InfoNCE 대 시그모이드 페어별의 통신 비용을 계산한다. 어떤 것이 O(N)으로 확장되고 어떤 것이 O(N^2)인가? SigLIP 섹션 4를 인용한다.

5. OpenCLIP 확장 법칙 논문(arXiv:2212.07143, Cherti 등)을 읽는다. 그림에서 고정 모델 크기에서 ImageNet 제로샷 정확도와 훈련 데이터 크기 사이의 로그-선형 관계에 대한他们的 결론을再現한다.
