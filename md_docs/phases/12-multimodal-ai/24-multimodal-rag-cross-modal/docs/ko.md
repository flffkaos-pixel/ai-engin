# 멀티모달 RAG와 교차-모달 검색

> 비전-네이티브 문서 RAG는 한 조각입니다. 프로덕션 멀티모달 RAG는 더 넓게 갑니다 — 여행 계획("조용한 비건 브런치를 자연광이 있는 곳에서 찾아줘"), 의료 분류("이 사진 + 이 메모와 일치하는 부상은 무엇인가"), 전자상거래("이 셀카와 비슷한 내 사이즈의 옷차림"), 현장 서비스("이 엔진 소리와 부품 사진을 진단해줘")와 같은 워크플로우를 위해 텍스트, 이미지, 오디오, 비디오 전반에서 검색합니다. 2025년의 세 가지 설문 조사 — Abootorabi et al., Mei et al., Zhao et al. — 은 하위 문제를 체계화했습니다: 교차-모달 검색, 검색 융합, 생성 그라운딩, 멀티모달 평가. 이 레슨은 설문 조사를 읽고 프로덕션 파이프라인을 설계합니다.

**Type:** Build
**Languages:** Python (stdlib, cross-modal retriever with fusion + grounded generator)
**Prerequisites:** Phase 12 · 23 (ColPali), Phase 11 (RAG basics)
**Time:** ~180 minutes

## 학습 목표

- 교차-모달 검색을 설계한다: 텍스트 → 이미지, 이미지 → 텍스트, 오디오 → 비디오 등.
- 세 가지 융합 전략을 비교한다: 점수 융합, 어텐션 기반 융합, MoE 융합.
- 생성 그라운딩을 설명한다: 출처가 다양한 모달리티의 혼합일 때 "출처를 인용하세요"가 의미하는 바.
- 2025년의 세 가지 표준 멀티모달 RAG 설문 조사와 그 하위 문제 분류를 나열한다.

## 문제

단일-모달리티 RAG는 해결된 패턴입니다: 쿼리 임베딩, 청크 임베딩, 검색, LLM에 주입. 멀티모달 RAG는 다음을 필요로 합니다:

1. 여러 검색 헤드(각 모달리티는 호환 가능한 공간의 임베딩 필요).
2. 모달리티 간 검색 결과의 융합.
3. 모달리티 간 출처를 인용하는 생성 그라운딩.
4. 교차-모달 신호를 다루는 평가 메트릭.

2025년 설문 조사는 모두 동일한 분류에 도달합니다.

## 개념

### 교차-모달 검색

모달리티 A의 쿼리가 주어졌을 때 모달리티 B의 문서 검색. 세 가지 패턴:

1. 공유 임베딩 공간. CLIP과 CLAP는 공유 공간에서 텍스트 + 이미지 / 텍스트 + 오디오 임베딩을 생성. 모달리티 간 코사인 유사도가 직접 작동. CLIP-학습 쌍으로 제한.
2. 모달리티별 인코더 + 변환. 텍스트 인코더 + 이미지 인코더 + 공간 간 매핑을 위한 작은 변환기 모듈. Gupta et al.의 Sen2Sen 및 기타 2024 설계. 유연하지만 복잡성 추가.
3. VLM을 인코더로 사용. VLM의 히든 상태를 검색 표현으로 사용. VLM이 지원하는 모든 모달리티가 작동. 더 높은 품질, 더 비쌈.

선택: 텍스트+이미지용 CLIP / SigLIP 2; 텍스트+오디오용 CLAP; 최첨단 품질의 교차-모달용 VLM-히든-상태.

### 융합 전략

10개의 결과를 검색했습니다: 5개 이미지, 3개 텍스트 구절, 2개 오디오 클립. 어떻게 병합하나요?

점수 융합(가장 저렴). 각 모달리티는 자체 검색기를 가지며, 각각 점수를 반환. 모달리티 내에서 점수를 정규화한 다음 합산. 간단, 종종 작동.

어텐션 기반 융합. 모든 검색 항목을 연결하고, 작은 어텐션 네트워크가 가중치 부여. 학습 필요.

MoE 융합. 게이팅 네트워크가 모달리티별 전문가로 라우팅. 다른 쿼리 유형은 다르게 라우팅 — 시각적 질문은 이미지를 더 높게 가중치.

프로덕션 기본값: 쿼리의 지배적 모달리티에 약간의 편향이 있는 점수 융합. A/B 테스트가 도메인에서 명확한 승리를 보여주면 MoE로 업그레이드.

### 생성 그라운딩

LLM은 각 주장이 어떤 검색 항목에서 나왔는지 인용해야 합니다. 멀티-모달의 경우:

- 텍스트 출처: 표준 인용 `[1]`.
- 이미지 출처: `[img 3]`과 짧은 캡션.
- 오디오: `[audio 2 at 0:34]`.

그라운딩-인지 데이터로 생성기 학습: 학습 대상의 각 주장은 출처 인덱스로 태그. 추론 시 모델이 자연스럽게 인용을 방출.

### 2025년 설문 조사

Abootorabi et al. (arXiv:2502.08826, "Ask in Any Modality"): 멀티모달 RAG에 대한 분류. 검색, 융합, 생성 포함. 가장 광범위한 범위.

Mei et al. (arXiv:2504.08748, "A Survey of Multimodal RAG"): 하위 작업 벤치마크 및 실패 모드에 초점. 평가 설계에 유용.

Zhao et al. (arXiv:2503.18016): 비전 중심 설문 조사. ColPali-계열 작업에 강함.

세 가지를 모두 읽으면 2025년 봄 기준 최신 기술을 얻을 수 있습니다. 대부분의 하위 문제는 여전히 열려 있습니다.

### MuRAG — 기초 논문

MuRAG(Chen et al., 2022)는 최초의 멀티모달 RAG였습니다. 멀티모달 KB에서 이미지 + 텍스트를 검색하고, 답변을 생성했습니다. VLM 물결 이전에 타당성을 보여줌. 현대 시스템(REACT, VisRAG, M3DocRAG)이 이를 기반으로 구축.

### 프로덕션 여행-플래너 예제

쿼리: "조용한 비건 브런치를 자연광이 있는 곳에서 찾아줘."

파이프라인:

1. 쿼리 분해. "조용한" → 오디오/리뷰 키워드; "비건 브런치" → 메뉴 항목; "자연광" → 이미지 특징.
2. 모달리티별 검색:
   - 리뷰에 대한 텍스트 검색: "비건 브런치, 조용한 분위기."
   - 레스토랑 사진에 대한 이미지 검색: "자연광, 통풍이 잘 되는."
   - 주변-소리 클립에 대한 오디오 검색: "낮은 데시벨, 음악 없음."
3. 점수 융합. 각 레스토랑은 복합 점수를 가짐.
4. 상위-k 레스토랑 → 모든 증거가 있는 VLM 생성기 → 인용과 함께 답변.

이것은 텍스트-RAG를 훨씬 넘어섭니다. 각 모달리티는 텍스트만으로는 놓치는 신호를 추가합니다.

### 에이전트 멀티모달 RAG

다중-홉: 첫 번째 검색이 높은 신뢰도의 답변을 반환하지 않으면, LLM이 재구성하고 다시 검색. Phase 14의 에이전틱 RAG 패턴이 여기에 적용. 예:

- 초기 상위-10 검색 → LLM "너무 시끄럽다, <40 dB로 필터링" → 재검색.
- 이미지 검색 → LLM이 하나에 메뉴가 있음을 확인 → 메뉴 텍스트 검색 → 답변.

복잡성을 추가하지만 단일-샷 검색이 처리할 수 없는 쿼리를 처리.

### 평가

교차-모달 평가는 아직 성숙하지 않음. 일반적인 프록시:

- 모달리티별 Recall@k.
- 융합된 상위-k 정확도.
- 인간-판단 종단간 만족도.
- 작업별(완료된 예약, 구매).

모든 모달리티를 포괄하는 표준 벤치마크는 없음. 대부분 논문은 도메인별 작업에서 평가.

## 사용하기

`code/main.py`:

- 레스토랑의 공유 코퍼스에서 작동하는 세 개의 모의 검색기(텍스트, 이미지, 오디오).
- 구성 가능한 가중치로 모달리티 점수를 결합하는 점수 융합.
- 인용과 함께 최종 답변을 방출하는 생성기 스텁.
- 신뢰도가 낮으면 쿼리를 재구성하는 간단한 에이전트 루프.

## 결과물

이 레슨은 `outputs/skill-multimodal-rag-designer.md`를 생성합니다. 멀티모달 쿼리 흐름이 있는 제품 사양이 주어지면, 검색기, 융합, 생성기 및 평가를 설계.

## 연습 문제

1. 의료-분류 멀티모달 RAG를 제안하세요: 쿼리 = 부상 사진 + 텍스트 증상. 어떤 모달리티가 어떤 KB에서 검색하나요?

2. 점수 융합은 간단한 가중 합계입니다. MoE 융합이 피하는 어떤 실패 모드가 있나요?

3. Abootorabi et al.의 분류(섹션 3)를 읽으세요. 세 가지 표준 하위 문제는 무엇이며 선택한 제품에 어떻게 매핑되나요?

4. 여행-플래너 멀티모달 RAG에 대한 평가 사양을 설계하세요. 어떤 메트릭이 이미지 재현율, 오디오 재현율 및 복합 정확도를 다루나요?

5. 에이전트 다중-홉 RAG는 왕복당 지연 시간 비용이 있습니다. 어떤 쿼리 난이도에서 정확도 향상이 지연 시간을 정당화하나요?

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|-------------------|----------|
| Cross-modal retrieval | "하나의 모달리티로 쿼리, 다른 모달리티 검색" | 텍스트 쿼리가 이미지 검색; 이미지 쿼리가 텍스트 검색; 공유 공간 또는 변환기 필요 |
| Score fusion | "점수 결합" | 모달리티별 검색 점수의 가중 합계; 가장 간단한 융합 |
| MoE fusion | "모달리티-라우팅 전문가" | 게이팅 네트워크가 쿼리별로 어느 모달리티의 점수를 신뢰할지 선택 |
| Grounded generation | "출처 인용" | 답변의 각 주장이 출처 인덱스로 태그됨 |
| MuRAG | "최초의 멀티모달 RAG" | 2022년 멀티모달 RAG 패턴을 확립한 논문 |
| Agentic multi-hop | "재구성 및 재시도" | 1차 패스 신뢰도가 낮을 때 LLM이 검색기를 재쿼리 |
