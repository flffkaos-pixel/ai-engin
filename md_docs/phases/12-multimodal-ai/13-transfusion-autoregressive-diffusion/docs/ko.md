# Transfusion: 하나의 트랜스포머에서 자기회귀 텍스트 + 확산 이미지

> Chameleon과 Emu3는 모든 것을 이산 토큰에 걸었습니다. 작동은 하지만, 양자화 병목이 눈에 띕니다 — 이미지 품질이 연속 공간 확산 모델 아래에서 정체됩니다. Transfusion(Meta, Zhou et al., 2024년 8월)은 반대의 선택을 합니다: 이미지를 연속적으로 유지하고, VQ-VAE를 완전히 제거하며, 하나의 트랜스포머를 두 개의 손실로 학습합니다. 텍스트 토큰은 다음-토큰-예측을 수행합니다. 이미지 패치는 플로우 매칭/확산 손실을 받습니다. 두 목적 함수는 동일한 가중치를 최적화합니다. Stable Diffusion 3(MMDiT)의 기반 아키텍처는 가까운 사촌입니다. 이 레슨은 Transfusion 논문을 읽고, 장난감 수준의 두-손실 학습기를 구축하며, 하나의 트랜스포머가 두 가지 작업을 수행할 수 있게 하는 어텐션 마스크를 추적합니다.

**Type:** Build
**Languages:** Python (stdlib, MNIST-scale 장난감에서의 two-loss trainer)
**Prerequisites:** Phase 12 · 11 (Chameleon), Phase 8 (Generative AI)
**Time:** ~180 minutes

## 학습 목표

- 하나의 백본에서 두 가지 손실(텍스트 토큰에 대한 NTP, 이미지 패치에 대한 확산 MSE)을 실행하는 트랜스포머를 구성한다.
- 이미지 패치에 대한 양방향 어텐션과 텍스트 토큰에 대한 인과적 어텐션이 올바른 마스크 선택인 이유를 설명한다.
- Transfusion 스타일(연속 이미지, 확산 손실)과 Chameleon 스타일(이산 이미지, NTP)을 계산, 품질, 코드 복잡성 측면에서 비교한다.
- MMDiT의 기여를 설명한다: 각 블록에서의 모달리티별 가중치, 잔차 스트림에서의 공동 어텐션.

## 문제

이산 vs 연속 이미지 토큰에 대한 논쟁은 LLM보다 오래되었습니다. 연속 표현(원본 픽셀, VAE 잠재 변수)은 세부 정보를 보존합니다. 이산 토큰(VQ 인덱스)은 트랜스포머의 네이티브 어휘에 맞지만 양자화 단계에서 세부 정보를 잃습니다.

Chameleon / Emu3는 이산 방식을 선택했습니다: 하나의 손실, 하나의 아키텍처, 하지만 이미지 충실도는 토크나이저 품질에 의해 제한됩니다.

확산 모델은 연속 방식을 선택했습니다: 탁월한 이미지 품질, 하지만 LLM과는 별도의 모델, 복잡한 노이즈 스케줄 엔지니어링, 텍스트 생성과의 깔끔한 통합 불가.

Transfusion이 묻습니다: 둘 다 가질 수 있을까? 이미지는 연속적으로 유지하고, 여전히 하나의 모델을 학습하며, 하나의 그래디언트 단계에 두 개의 손실을 결합합니다.

## 개념

### 두-손실 아키텍처

단일 디코더-전용 트랜스포머가 다음을 포함하는 시퀀스를 처리합니다:

- 텍스트 토큰(이산, BPE 어휘에서 가져옴).
- 이미지 패치(연속, 16x16 픽셀 블록을 선형 임베딩을 통해 히든 차원으로 투영 — ViT 인코더의 입력과 동일).
- 연속 패치가 위치하는 곳을 표시하는 `<image>` 및 `</image>` 태그.

순전파는 한 번 실행됩니다. 손실은 토큰당 두 개의 헤드 중 하나를 선택합니다:

- 텍스트 토큰의 경우: 어휘-로짓 헤드에 대한 표준 교차 엔트로피.
- 이미지 패치의 경우: 연속 패치에 대한 확산 손실 — 각 패치에 추가된 노이즈를 예측합니다.

그래디언트는 공유 트랜스포머 본체를 통해 흐릅니다. 두 손실이 공유 가중치를 동시에 개선합니다.

### 어텐션 마스크: 인과적 텍스트 + 양방향 이미지

텍스트 토큰은 인과적이어야 합니다 — 텍스트 토큰이 미래 텍스트에 어텐션할 수 없게 해야 합니다, 그렇지 않으면 teacher forcing이 깨집니다. 그러나 이미지 패치는 하나의 스냅샷을 나타내므로, 동일한 이미지 블록 내에서 서로 양방향으로 어텐션해야 합니다.

마스크:

```
M[i, j] = 1 if:
  (i가 텍스트이고 j가 텍스트이고 j <= i)   # 텍스트에 대한 인과적
  OR (i가 이미지이고 j가 이미지이고 same_image_block(i, j))   # 이미지 내 양방향
  OR (i가 텍스트이고 j가 이미지이고 j < i_image_end)   # 텍스트는 이전 이미지에 어텐션
  OR (i가 이미지이고 j가 텍스트이고 j < i_image_start)   # 이미지는 선행 텍스트에 어텐션
```

학습 및 추론 시 블록-삼각 마스크로 구현됩니다.

### 트랜스포머 내부의 확산 손실

확산 손실은 표준적입니다: 이미지 패치에 노이즈를 추가하고, 모델이 노이즈(또는 동등하게 깨끗한 패치)를 예측하도록 합니다. Transfusion의 버전은 플로우 매칭을 사용합니다 — 노이즈가 있는 상태에서 깨끗한 상태로의 속도장을 예측합니다.

학습 중:
1. 각 이미지 패치 x0에 대해, 무작위 타임스텝 t를 샘플링합니다.
2. 노이즈 ε을 샘플링하고, xt = (1-t) * x0 + t * ε (플로우 매칭을 위한 선형 보간)을 계산합니다.
3. 트랜스포머가 v_theta(xt, t)를 예측합니다; 손실 = MSE(v_theta(xt, t), ε - x0).
4. 동일한 시퀀스의 텍스트 NTP 손실과 함께 역전파합니다.

추론 시 생성은 다음과 같습니다:
- 텍스트 토큰: 표준 자기회귀 샘플링.
- 이미지 패치: 이전 텍스트 토큰을 조건으로 하는 확산 샘플링 루프(일반적으로 10-30 단계).

### MMDiT: Stable Diffusion 3의 변형

Stable Diffusion 3(Esser et al., 2024년 3월)는 Transfusion과 비슷한 시기에 MMDiT(Multimodal Diffusion Transformer)를 출시했습니다. 아키텍처는 가까운 사촌입니다.

MMDiT의 주요 차이점:

- 블록별 모달리티별 가중치. 각 트랜스포머 블록은 텍스트 토큰과 이미지 패치에 대해 별도의 Q, K, V 및 MLP 가중치를 가집니다. 어텐션은 공동(교차-모달리티)입니다; 나머지는 모두 모달리티별입니다.
- 교정된 플로우 학습. DDPM보다 간단한 수학으로 알려진 샘플링 방식을 가진 특정 플로우 매칭 변형.
- 스케일. MMDiT는 SD3(2B 및 8B 매개변수 변형)의 백본입니다. Transfusion 논문은 7B까지 확장됩니다.

둘 다 동일한 핵심 아이디어로 수렴합니다: 하나의 트랜스포머가 텍스트에 대해 NTP를, 연속 이미지 표현에 대해 확산을 실행합니다.

### 이것이 Chameleon 스타일을 능가하는 이유

이미지 생성에서 연속-확산과 이산-NTP 간의 품질 격차는 측정 가능합니다. Transfusion 논문은 보고합니다:

- 7B 매개변수에서, 동일한 크기의 Chameleon-스타일 모델을 FID에서 3-5포인트 능가합니다.
- 토크나이저 학습이 필요 없음 — 이미지 인코더가 더 간단합니다(히든에 대한 선형 투영, ViT의 입력 레이어와 동일).
- 추론 시 이미지 패치 잡음 제거를 병렬화할 수 있어, 자기회귀 이미지 토큰과 다릅니다.

단점: Transfusion은 이중-손실 모델이므로 학습 역학이 더 까다롭습니다. 손실 가중치 조정이 필요합니다. NTP와 확산 간의 스케줄 불일치로 인해 하나의 헤드가 지배적이 될 수 있습니다.

### 이후의 방향

Janus-Pro(레슨 12.15)는 Transfusion의 아이디어를 개선하여 이해와 생성을 위한 비전 인코더를 분리합니다 — 하나는 SigLIP, 다른 하나는 VQ — 트랜스포머 본체는 공유합니다. Show-o(레슨 12.14)는 확산을 이산-확산(마스크된 예측)으로 대체합니다. 통합 생성 제품군은 Transfusion 이후 빠르게 분기됩니다.

이미지를 출력하는 2026년 프로덕션 VLM — Gemini 3 Pro, GPT-5, Claude Opus 4.7의 이미지 생성 경로 — 거의 확실히 이 제품군의 후손을 사용합니다. 세부 사항은 독점적입니다.

## 사용하기

`code/main.py`는 작은 MNIST-유사 문제에 대한 장난감 Transfusion을 구축합니다:

- 텍스트 캡션은 숫자(0-9)를 설명하는 짧은 정수 시퀀스입니다.
- 이미지는 바이트의 4x4 그리드입니다.
- 공유 가중치 선형 투영 쌍이 트랜스포머 대용으로 작동합니다; 텍스트에 대한 NTP 손실, 노이즈가 있는 패치에 대한 MSE 손실.
- 학습 루프는 두 손실을 번갈아 가며, 어텐션 마스크는 명시적입니다.
- 생성은 한 번의 순전파로 텍스트 캡션과 4x4 이미지를 생성합니다.

트랜스포머는 장난감 수준입니다. 두-손실 배관, 어텐션 마스크 구성 및 추론 루프가 실제 산출물입니다.

## 결과물

이 레슨은 `outputs/skill-two-loss-trainer-designer.md`를 생성합니다. 새로운 멀티모달 학습 작업(텍스트 + 이미지, 텍스트 + 오디오, 텍스트 + 비디오)이 주어지면, 두-손실 스케줄(손실 가중치, 마스크 형태, 공유 vs 모달리티별 블록)을 설계하고 구현 위험을 식별합니다.

## 연습 문제

1. Transfusion-스타일 모델이 70% 텍스트 토큰과 30% 이미지 패치로 학습합니다. 이미지 확산 손실은 텍스트 NTP 손실보다 크기가 약 10배입니다. 어떤 손실 가중치가 이들을 균형있게 할까요?

2. 시퀀스에 대한 블록-삼각 마스크를 구현하세요: `[T, T, <image>, P, P, P, P, </image>, T]`. 각 항목을 0 또는 1로 표시하세요.

3. MMDiT는 모달리티별 QKV 가중치를 가집니다. 이는 Transfusion의 완전 공유 트랜스포머 대비 어떤 매개변수 수 오버헤드를 추가하나요? 7B 매개변수에서, 그만한 가치가 있을까요?

4. 생성: 텍스트 프롬프트가 주어지면, 모델은 50개 토큰에 대해 NTP를 실행하고, `<image>`에 도달한 후 20개의 잡음 제거 단계에 걸쳐 256개 패치에 대해 확산을 실행합니다. 총 몇 번의 순전파가 필요할까요?

5. SD3 논문 섹션 3을 읽으세요. 교정된 플로우(rectified flow)를 설명하고 DDPM보다 적은 추론 단계로 수렴하는 이유를 설명하세요.

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|-------------------|----------|
| Two-loss training | "NTP + 확산" | 단일 트랜스포머가 동일한 그래디언트 단계에서 텍스트 토큰에 대한 교차 엔트로피와 연속 이미지 패치에 대한 MSE를 모두 최적화함 |
| Flow matching | "교정된 플로우" | 노이즈에서 깨끗한 데이터까지의 속도장을 예측하는 확산 변형; DDPM보다 간단한 수학 |
| MMDiT | "멀티모달 DiT" | Stable Diffusion 3의 아키텍처: 공동 어텐션, 모달리티별 MLP 및 정규화 |
| Block-triangular mask | "인과적 텍스트 + 양방향 이미지" | 텍스트 전반에서는 인과적이지만 이미지 영역 내에서는 양방향인 어텐션 마스크 |
| Continuous image representation | "VQ 없음" | 정수 코드북 인덱스가 아닌 실수값 벡터로서의 이미지 패치 |
| Velocity prediction | "v-parameterization" | 네트워크 출력이 노이즈 자체가 아닌 노이즈와 데이터 사이의 속도장임 |
