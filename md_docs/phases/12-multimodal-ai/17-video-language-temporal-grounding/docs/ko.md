# 비디오-언어 모델: 시간 토큰과 그라운딩

> 비디오는 사진 더미가 아닙니다. 5초 클립에는 이미지 모델이 표현할 수 없는 인과적 순서, 동작 동사, 이벤트 타이밍이 있습니다. Video-LLaMA(Zhang et al., 2023년 6월)는 시청각 그라운딩을 갖춘 최초의 오픈 비디오-LLM을 출시했습니다. VideoChat과 Video-LLaVA는 이 패턴을 확장했습니다. 2025년까지 Qwen2.5-VL의 TMRoPE는 최첨단 독점 모델과의 격차를 좁혔습니다. 각 시스템은 시간 토큰을 다르게 해결했습니다 — 클립당 Q-former, 프레임당 concat-pool, 토큰당 TMRoPE. 이 레슨은 패턴을 읽고, 균일 vs 동적 프레임 샘플러를 구축하며, 시간 그라운딩 작업에서 평가합니다.

**Type:** Build
**Languages:** Python (stdlib, frame sampler + temporal-grounding evaluator)
**Prerequisites:** Phase 12 · 08 (LLaVA-OneVision)
**Time:** ~180 minutes

## 학습 목표

- 시간적 위치 인코딩이 비전 인코더와 독립적으로 비디오 VLM 성능을 변경하는 이유를 설명한다.
- 균일, 동적-FPS, 이벤트 기반 프레임 샘플링을 초당 토큰 수 대 그라운딩 정확도 측면에서 비교한다.
- 클립당 Q-former(Video-LLaMA) vs 프레임당 풀링(Video-LLaVA) vs 토큰당 M-RoPE(Qwen2.5-VL) 설계를 설명한다.
- 네 가지 비디오 벤치마크를 나열한다: VideoMME, TempCompass, EgoSchema, Video-MMMU.

## 문제

30 FPS의 1분 비디오는 1800프레임입니다. 프레임당 196개의 시각적 토큰(ViT-B, 224에서)은 352k 토큰입니다 — 2024년 LLM 컨텍스트보다 큽니다.

세 가지 축소 전략이 존재합니다:

1. 프레임 서브샘플링(콘텐츠에 따라 1-8 FPS).
2. 각 프레임의 패치 토큰을 적극적으로 풀링(3x3 또는 4x4 쌍선형 풀).
3. 16프레임 클립을 가져와 64개 토큰을 출력하는 Q-former를 통해 압축.

각 트레이드오프가 다릅니다. 서브샘플링은 시간적 세부 정보를 잃습니다. 풀링은 공간적 세부 정보를 잃습니다. Q-former는 둘 다 약간 잃지만 토큰을 절약합니다.

시간적 위치 인코딩은 다른 축입니다: 모델이 프레임 5가 프레임 6보다 앞에 있다는 것을 어떻게 알까요? 옵션에는 단순 1D 시간적 RoPE(Video-LLaMA), 학습된 시간적 임베딩(Video-LLaVA), TMRoPE(Qwen2.5-VL, 완전 3D)가 포함됩니다.

## 개념

### Video-LLaMA: 클립당 Q-former + 오디오 브랜치

Video-LLaMA(2023)는 최초의 오픈 비디오-LLM이었습니다. 아키텍처:

- 2 FPS에서 16-프레임 클립(따라서 8초).
- 프레임별 ViT 특징 -> 모든 16개 프레임에 대해 교차 어텐션하는 Video Q-former -> 32개 학습된 쿼리 -> LLM.
- 병렬 오디오 브랜치: 파형 -> ImageBind 오디오 인코더 -> Audio Q-former -> 32개 쿼리 -> LLM.

강점: 시청각 공동 추론. 약점: 고정된 클립 길이, 임의 시간 그라운딩 불가.

### VideoChat과 Video-LLaVA

VideoChat은 Video-LLaMA 아이디어를 유지했지만 오디오를 제거하고 단순화했습니다. Video-LLaVA(Lin et al., 2023)는 이미지와 비디오 프레임 모두에 대해 단일 시각적 인코더를 학습시켜("프로젝션 전 정렬") 통합 표현을 제공했습니다. 둘 다 frozen-CLIP-encoder + MLP + LLM입니다.

둘 다 긴 비디오를 처리하지 못합니다. 둘 다 8-16 프레임 시스템입니다.

### Qwen2.5-VL과 TMRoPE

Qwen2.5-VL은 TMRoPE — Temporal-Modality Rotary Position Embedding을 도입했습니다. 각 패치 토큰은 (t, h, w) 위치를 가지며, 여기서 t는 실제 타임스탬프(프레임 인덱스가 아님)입니다.

단순 시간적 임베딩과의 주요 차이점:

- 인덱스가 아닌 절대 시간. 모델은 "프레임 15에서"가 아닌 "4.2초에서"를 봅니다.
- 클립별이 아닌 토큰별 회전. 각 시각적 토큰은 타임스탬프에 의해 독립적으로 회전합니다.
- 동적 FPS와 호환 가능. 여기서 2 FPS, 저기서 4 FPS로 샘플링하면 TMRoPE가 불균등한 간격을 네이티브로 처리합니다.

TMRoPE는 "고양이가 몇 초에 점프하나요?"와 같은 쿼리를 가능하게 합니다. 모델은 "4.2초에"라고 출력할 수 있습니다. Video-LLaMA는 "클립 초반에"라고만 말할 수 있었습니다.

### 프레임 샘플링 전략

균일: 지속 시간에 걸쳐 N개 프레임을 균등하게 샘플링. 간단, 모션 피크를 놓침.

동적 FPS: 모션 강도에 따라 적응적으로 샘플링. 광학 흐름 또는 프레임 차분이 높은 모션 세그먼트를 선택하여 더 조밀하게 샘플링. Qwen2.5-VL이 이 방식으로 학습.

이벤트 기반: 경량 감지기를 실행하고, 액션이 발생하는 곳에서 더 많이 샘플링. VideoAgent에서 사용.

키프레임 + 컨텍스트: 샷 경계 + 몇 개의 인접 프레임에서 샘플링. 영화 콘텐츠에 사용.

### 프레임당 풀링

1 FPS 및 프레임당 576개 토큰에서 5분 클립은 172,800개 토큰입니다. Qwen2.5-VL-72B의 128k 컨텍스트로 가능하지만 비용이 많이 듭니다.

3x3 쌍선형 풀은 프레임당 64개 토큰으로 줄입니다 -> 5분 동안 19,200개 토큰. 대부분의 작업에 최적점입니다.

공간적 세부 정보가 덜 중요한 에이전트 워크플로우에서는 더 적극적으로 풀링합니다(6x6 -> 프레임당 16개 토큰).

### 네 가지 비디오 벤치마크

- VideoMME: 포괄적인 비디오 이해, 짧은 + 중간 + 긴.
- TempCompass: 세분화된 시간적 추론, "이전"/"이후" 질문.
- EgoSchema: 장시간 1인칭 비디오.
- Video-MMMU: 멀티모달 다분야 비디오 질문.

완전한 비디오-VLM 평가는 네 가지 모두를 다룹니다. 이들은 다른 축을 강조합니다 — TempCompass는 모두 순서에 관한 것이고, EgoSchema는 3분 이상 추론에 관한 것이며, VideoMME는 지속 시간을 포괄합니다.

### 그라운딩 출력 형식

시간적 그라운딩을 위한 출력 형식:

- 자유 텍스트: "고양이가 4초 부근에서 점프합니다." 파싱은 쉽지만 부정확.
- 구조화된 JSON: `{"event": "jump", "start": 4.1, "end": 4.3}`. Qwen2.5-VL이 이 형식으로 학습.
- 토큰 기반: 답변과 인터리브된 특수 `<time>4.1</time>` 토큰. Qwen2.5-VL의 내부 형식.

토큰 기반이 다운스트림 사용에 가장 정확합니다. Qwen2.5-VL의 JSON 출력 형식은 직접 파싱됩니다.

### 2026년 모범 사례

2026년 비디오 VLM의 경우:

- 인코더: M-RoPE 또는 TMRoPE가 있는 SigLIP 2(Qwen2.5-VL).
- 프레임 샘플링: 최대 프레임 제한이 있는 동적 FPS(모션에 따라 1-4).
- 프레임당 풀링: 3x3 쌍선형.
- 출력: 시간 + 이벤트 필드가 있는 구조화된 JSON.
- 벤치마크: 일반용 VideoMME + TempCompass; 장시간용 EgoSchema.

## 사용하기

`code/main.py`는 다음을 포함합니다:

- 균일 및 동적-FPS 프레임 샘플러.
- 장난감 시간적-그라운딩 평가기: 시간 T에서의 "실측" 이벤트와 모델 출력이 주어지면 허용 오차로 정확도 점수 매기기.
- Video-LLaMA(16프레임, Q-former), Video-LLaVA(8프레임, MLP), Qwen2.5-VL(동적 FPS + TMRoPE) 비교.

## 결과물

이 레슨은 `outputs/skill-video-vlm-frame-planner.md`를 생성합니다. 비디오 작업(모니터링, 동작 인식, 시간적 그라운딩, 요약)이 주어지면, 프레임 샘플러, 풀링 팩터, 출력 형식 및 예상 정확도 수준을 선택합니다.

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|-------------------|----------|
| Temporal grounding | "시간-지역화된 답변" | VLM이 이벤트 발생 시간에 대한 특정 타임스탬프 범위를 출력함 |
| TMRoPE | "Time-Multimodal RoPE" | Qwen2.5-VL이 사용하는 절대 타임스탬프를 가진 3D 회전 위치 |
| Dynamic FPS | "모션 인식 샘플링" | 높은 모션 세그먼트에서 더 많은 프레임을, 정적인 곳에서 더 적게 샘플링 |
| Frame pooling | "프레임당 공간 압축" | LLM 이전에 쌍선형 보간으로 프레임당 패치 수를 줄임 |
| Video Q-former | "클립 압축기" | N개 프레임을 K개 학습된 쿼리에 매핑하는 교차 어텐션 병목 |
| VideoMME | "비디오 벤치" | 포괄적인 짧은/중간/긴 비디오 벤치마크, 2500+ 샘플 |
