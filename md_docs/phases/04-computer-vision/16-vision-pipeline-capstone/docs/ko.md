# 비전 파이프라인 캡스톤

> 데이터 수집부터 배포까지 전체 비전 시스템 구축.

**유형:** 빌드  
**언어:** Python  
**시간:** ~150분

## 개념

종합 프로젝트:
1. 데이터 수집/정제
2. 모델 선택 (분류/탐지/분할)
3. 훈련 파이프라인 (증강, 스케줄링)
4. 평가 및 오류 분석
5. ONNX/TensorRT 최적화
6. 추론 서버 배포

## 체크리스트

- [ ] 데이터 버전 관리 (DVC)
- [ ] 실험 추적 (W&B)
- [ ] 모델 레지스트리
- [ ] A/B 테스트 프레임워크
- [ ] 모니터링 (데이터 드리프트)

## 주요 용어

| 용어 | 의미 |
|------|------|
| DVC | 데이터 버전 관리 — Git + 스토리지 |
| 모델 레지스트리 | 버전 있는 모델 아티팩트 저장소 |
| 데이터 드리프트 | 프로덕션 데이터 분포 변화 |
