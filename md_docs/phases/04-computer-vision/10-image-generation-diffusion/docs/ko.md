# 이미지 생성 — 확산 모델

> 노이즈를 천천히 제거하세요. 각 단계는 작은 정제입니다.

**유형:** 빌드  
**언어:** Python  
**시간:** ~90분

## 개념

- **순방향 과정**: 이미지에 점진적으로 노이즈 추가 (고정)
- **역방향 과정**: 노이즈를 단계적으로 제거하도록 U-Net 학습
- **DDPM**: 각 단계에서 노이즈 예측 → 제거
- **DDIM**: 더 적은 단계로 더 빠른 샘플링

## vs GAN

| 특성 | GAN | 확산 |
|------|-----|------|
| 품질 | 높음 | 더 높음 |
| 다양성 | 모드 붕괴 위험 | 더 다양함 |
| 속도 | 빠름 (1회 순전파) | 느림 (다단계) |
| 안정성 | 불안정 | 안정적 |

## 빌드하기

```python
# 노이즈 추가 (순방향)
def add_noise(x_0, t, betas):
    alpha_bar = cumprod(1 - betas)[t]
    noise = torch.randn_like(x_0)
    return sqrt(alpha_bar)*x_0 + sqrt(1-alpha_bar)*noise, noise

# 손실: 예측 노이즈와 실제 노이즈의 MSE
loss = mse(model(x_t, t), noise)
```
