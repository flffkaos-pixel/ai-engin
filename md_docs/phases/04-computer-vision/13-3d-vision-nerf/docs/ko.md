# 3D 비전 — NeRF

> 몇 장의 2D 사진으로 3D 장면을 재구성합니다. 신경망이 빛과 밀도를 학습합니다.

**유형:** 빌드  
**언어:** Python  
**시간:** ~90분

## 개념

- **NeRF**: 3D 좌표 + 방향 → 색상 + 밀도를 매핑하는 MLP
- **볼륨 렌더링**: 광선을 따라 밀도와 색상 누적 → 픽셀 생성
- **위치 인코딩**: 고주파 함수로 좌표 변환 → 미세 디테일 포착

## 빌드하기

```python
class NeRF(nn.Module):
    def __init__(self):
        super().__init__()
        self.mlp = nn.Sequential(
            nn.Linear(60, 256), nn.ReLU(),  # 위치 인코딩
            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, 4)  # RGB + 밀도
        )
```

## 주요 용어

| 용어 | 의미 |
|------|------|
| 볼륨 렌더링 | 광선 상의 점들을 누적 → 픽셀 |
| 위치 인코딩 | 고주파 변환 → 미세 구조 포착 |
