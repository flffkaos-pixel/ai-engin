# 합성 데이터 — 생성, 평가, 적용

> 2024-2026년 합성 데이터 연구는 세 방향으로 발전했다. 합성 데이터 생성: Liu et al. 2024(Stanford)는 합성 데이터가 합성-실제 격차를 좁히기 위해 모델의 특성을 명시적으로 modeling해야 함을 보여준다; Ye et al. 2024는 합성 수학 증명 데이터를 사용하여 수학적 추론에서 o1-preview를 능가하는 모델을 훈련시킨다. 합성 데이터 평가: Barik et al. 2025는 합성 코퍼스가 기존 벤치마크에 대한 성능을 예측하지 못함을 보여준다; Liu et al. 2024는 합성 텍스트에서 모델崩壊의 경험적signature를 식별한다. 합성 데이터 적용: Hu et al. 2025는 합성 EHR 데이터로 임상 모델을 사전 훈련시켜 실제 데이터 privacy 비용을 절감하고 performance를 유지한다; Peste et al. 2024는 합성 이미지로视觉模型を事前訓練하는 것이 도메인 데이터饥饿을缓解함을 보여준다.

## 학습 목표

- 합성 데이터 생성의 세 가지 접근 방식(재현, 조건부 합성, 속성 modeling)을 설명한다.
- 합성-실제 격차와 그것이 합성 데이터 적용을限制하는 방식을 설명한다.
- 합성 데이터 평가의 세 가지 메트릭을 설명한다.
- 합성 EHR과 합성 이미지의 실제 적용 사례를 분석한다.

## 문제

실제 데이터는 비용, privacy, 가용성이 제한적이다. 합성 데이터는 이러한 제약 없이 대규모 학습 데이터를 생성할 수 있다. 그러나 합성 데이터는 실제 데이터와 동일하지 않다. 합성-실제 격차를 이해하고 管理하는 것이 핵심 문제이다.

## 개념

### 세 가지 합성 데이터 생성

- **재현 합성.** 실제 데이터 분포에서 샘플링. 원본 데이터와 동일한 분포를 가진다 — 그러나 실제로는 원본만큼 좋다.
- **조건부 합성.** 특정 조건 하에서 합성 — 클래스 균형, 도메인 커버리지, 특정 시나리오. 데이터 증강 형태로 기능.
- **속성 modeling.** 모델의 특성을 명시적으로 modeling하는 합성. Liu et al. 2024: 모델이 실수할 곳을 알고 있으면那里에 더 많은 합성 데이터를 생성. 이것은 합성-실제 격차를 좁힌다.

### 합성-실제 격차

합성 데이터로 훈련된 모델이 실제 데이터 분포에서 성능 저하를 보인다. 원인:
- 합성 데이터가 실제 분포의 끝极端을포함하지 않음.
- 합성 데이터가 모델 훈련에서 사용된 실제 데이터와 겹치지 않음.
- 합성 생성기가 실제 데이터의 노이즈를포함하지 않음.

Ye et al. 2024의 성공은 속성 modeling 접근 — 모델의 수학적 weakness를 분석하고那里에 합성 데이터를 집중 — 을 사용했기 때문에 가능하다.

### 합성 데이터 평가 메트릭

Barik et al. 2025가 제안하는 세 가지 메트릭:
- **커버리지.** 합성 코퍼스가 실제 분포의 얼마나 많은 variance를 포착하는가.
- **고보전.** 합성 코퍼스가 실제 데이터의低频率 패턴을 포함하는가.
- **분류자-의존성.** 합성 데이터가 분류자에 의해 학습된 기능에 의존하는 정도.

핵심 발견: 커버리지가 높并不意味着 downstream 성능이 예측된다. 분류자-의존성이 낮아야 한다 — 합성 데이터가 특정 분류자에 과적합되지 않은 일반화된 표현을 학습해야 한다.

### 모델 Collapse

Liu et al. 2024는 모델 collapse 현상을 경험적으로 특징짓는다: 합성 데이터로 반복 훈련하면 이후 세대의 성능이 저하된다. 초기 세대에서珍しい 패턴이 이후 세대에서 사라진다. 이것은 합성 데이터가 낮은 빈도 피처를drop하는 경향이 있기 때문이다.

방지: 실제 데이터의 최소 비율 유지; 다양한 합성 생성기 사용; 빈도 加權 재샘플링.

### 실제 적용

- **합성 EHR (Hu et al. 2025).** 실제 환자 데이터 대신 합성 EHR로 임상 모델 사전 훈련. Privacy 비용 제거. 특정 작업(질병 진행 예측)에서 실제 데이터로 사전 훈련한 모델과 동등한 성능. 합성 EHR은 실제 데이터의 통계적 특성을 유지하도록 훈련된 생성기를 통해 생성.
- **합성 이미지 (Peste et al. 2024).** 컴퓨터 비전 모델의 사전 훈련에서 도메인 데이터 부족問題 해결. 합성 이미지에서 사전 훈련된 모델이 레이블이 지정된 실제 데이터가 부족한 도메인에서 더 나은 전이 학습을 보여준다.

## 활용

`code/main.py`는 합성 텍스트 코퍼스를 생성하고 합성-실제 격차를 평가한다. 실제 분포와 합성 분포에서 훈련된 분류자의 성능을 비교한다. 속성 modeling이 합성-실제 격차를 어떻게 줄이는지 demonstrat한다.

## 결과물

이 수업은 `outputs/skill-synthetic-data-proposal.md`를 생성한다. 실제 데이터 가용성 또는 privacy 제약이 주어지면 합성 데이터 접근 방식, 합성 생성기 선택, 평가 메트릭을 제안하고 합성-실제 격차를 管理하는 전략을 설명한다.

## 연습 문제

1. `code/main.py`를 실행한다. 합성-실제 격차의 크기를 보고한다. 속성 modeling 접근을 적용하고 격차 감소를 측정한다.

2. Ye et al. 2024의 합성 수학 증명 합성 전략을 설명한다. 이것이 일반적으로 적용될 수 있는 이유와 그렇지 않은 이유를 分析한다.

3. Barik et al. 2025의 세 가지 평가 메트릭을 이름 짓는다. 각 메트릭이 합성 코퍼스의 한계를 포착하는 방식을 설명한다.

4. 모델 collapse 현상의 원인을 분석한다. 합성 데이터로 반복 훈련할 때 이를 방지하는 세 가지 전략을 제안한다.

5. Hu et al. 2025의 합성 EHR 접근을 의료 AI 회사에 적용하도록 적응시킨다. 합성 EHR의 privacy 이점과 성능 보장의 trade-off를 分析한다.
