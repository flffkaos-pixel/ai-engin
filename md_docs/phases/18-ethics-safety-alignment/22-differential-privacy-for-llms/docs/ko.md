# LLM을 위한 차등 프라이버시

> DP-SGD는 여전히 표준이다 — 노이즈가 주입된 그래디언트 업데이트는 공식적인 (epsilon, delta) 보장을 제공한다. 연산, 메모리, 유틸리티 측면의 오버헤드는 상당하며; 파라미터 효율적 DP 미세조정(LoRA + DP-SGD)이 2025년의 일반적인 구성이다(ACM 2025). 상충되는 두 증거 체계: 카나리 기반 멤버십 추론(Duan et al., 2024)은 언어 모델에 대한 제한된 성공을 보고하는 반면; 훈련 데이터 추출(Carlini et al., 2021; Nasr et al., 2025)은 상당한 축어적 기억을 복구한다. 해결(arXiv:2503.06808, 2025년 3월): 측정 대상의 차이 — 삽입된 카나리 대 "가장 추출 가능한" 데이터. 새로운 카나리 설계는 섀도우 모델 없이 손실 기반 MIA를 가능하게 하며, 실제 데이터로 훈련되고 현실적인 DP 보장을 갖는 LLM에 대한 최초의 의미 있는 DP 감사를 제공한다. 대안: PMixED(arXiv:2403.15638) — 다음 토큰 분포에 대한 전문가 혼합을 통한 추론 시점의 비공개 예측; DP 합성 데이터 생성(Google Research 2024). 새로운 공격: LLM 피드백을 통한 차등 프라이버시 역전 — 신뢰도 점수 유출.

## 학습 목표

- (epsilon, delta)-차등 프라이버시를 정의하고 DP-SGD 레시피를 설명한다.
- 2024-2025년의 긴장 관계를 설명한다: 카나리 MIA vs 훈련 데이터 추출이 다른 그림을 보여준다.
- PMixED와 추론 시점 비공개 예측이 DP 훈련의 대안이 되는 이유를 설명한다.
- LLM 피드백을 통한 차등 프라이버시 역전 공격을 설명한다.

## 문제

LLM은 기억한다. Carlini et al. 2021은 프로덕션 언어 모델이 요청 시 축어적 훈련 텍스트를 재생산함을 보여주었다. DP는 공식적인 방어책이다: 출력이 어떤 단일 훈련 예제에도 증명 가능하게 둔감하도록 훈련한다. 2024-2025년 증거는 DP-SGD가 필수적이지만, 배포된 ε 값이 위협 모델과 일치하지 않을 수 있음을 보여준다.

## 개념

### (ε, δ)-차등 프라이버시

무작위 알고리즘 M은 하나의 예제에서 차이가 나는 두 데이터셋과 어떤 사건 S에 대해 다음이 성립하면 (ε, δ)-DP이다:
P(M(D) in S) <= e^ε * P(M(D') in S) + δ.

해석: 출력 분포는 (ε으로 매개변수화된) 충분히 가까워서 어떤 개인의 기여도 δ의 확률을 제외하고는 신뢰성 있게 추론될 수 없다.

### DP-SGD

Abadi et al. 2016. 표준 레시피:
1. 미니배치를 샘플링한다.
2. 예제별 그래디언트를 계산한다.
3. 각 예제별 그래디언트를 임계값 C로 클리핑한다.
4. 클리핑된 그래디언트를 합산하고 표준편차 σ * C의 가우시안 노이즈를 추가한다.
5. 노이즈가 추가된 합으로 파라미터를 업데이트한다.

프라이버시 비용은 회계사(Moments Accountant, Rényi DP 회계사)에 의해 추적된다. LLM 문헌에서 보고된 ε 값은 위협 모델, 데이터 민감도, 유틸리티 목표에 따라 크게 다양하며, 보편적으로 "안전한" 기본 ε 값은 존재하지 않는다. 게시된 예시는 일부 LLM 훈련 환경에서 대략 ε ≈ 1–10 범위에 걸쳐 있지만, 이는 예시일 뿐 — 권장되는 기본값은 아니다. 낮은 ε은 일반적으로 더 많은 노이즈를 필요로 하며 유틸리티 손실을 증가시킬 수 있다.

### LoRA + DP-SGD

프론티어 모델의 전체 DP-SGD는 엄두도 못 낼 정도이다. LoRA(Hu et al. 2022)는 그래디언트 업데이트를 작은 어댑터로 제한하여 예제별 그래디언트 저장소를 줄인다. LoRA + DP-SGD는 2025년의 일반적인 구성이다. DP 보장은 어댑터에 적용되며, 기본 모델은 고정된다.

### 2024-2025년 긴장 관계

두 증거 체계:

- **카나리 MIA (Duan et al. 2024).** 고유한 카나리를 훈련 데이터에 삽입하고, 멤버십 추론 공격자가 이를 식별할 수 있는지 측정한다. 언어 모델에 대한 제한된 성공을 보고한다. MIA가 어렵다는 것을 시사한다.
- **훈련 데이터 추출 (Carlini 2021, Nasr et al. 2025).** 모델에 프리픽스를 프롬프트로 제공하고, 훈련 데이터의 축어적 텍스트를 복구하는지 측정한다. 상당한 기억을 보고한다. 관련된 의미에서 MIA가 쉽다는 것을 시사한다.

2025년 3월 해결(arXiv:2503.06808): 두 가지는 서로 다른 것을 측정한다. MIA는 삽입된 카나리에 대해 "예제 e가 D에 있는가?"를 묻는다. 추출은 "D에서 무엇을 복구할 수 있는가?"를 묻는다. "가장 추출 가능한" 예제가 프라이버시에 중요하다; 카나리는 추출 가능하도록 최적화되지 않았기 때문에 이를 과소보고한다.

새로운 카나리 설계. 섀도우 모델 없는 손실 기반 MIA. 실제 데이터와 현실적인 DP 보장을 가진 LLM에 대한 최초의 의미 있는 DP 감사.

### DP 훈련의 대안

- **PMixED (arXiv:2403.15638).** 추론 시점의 비공개 예측. 다음 토큰 분포에 대한 전문가 혼합; 각 전문가는 훈련 데이터의 샤드를 본다; 집계는 DP를 위해 노이즈를 추가한다. DP 훈련을 완전히 회피한다.
- **DP 합성 데이터 생성 (Google Research 2024).** DP-SGD로 LoRA 미세조정, 합성 데이터 샘플링, 합성 데이터에 대해 다운스트림 분류기를 훈련한다.

둘 다 다른 위협 모델을 대가로 전체 DP 훈련의 유틸리티 비용을 회피한다.

### LLM 피드백을 통한 차등 프라이버시 역전

2025년 새로운 공격. DP로 훈련된 모델의 신뢰도 점수를 오라클로 사용하여 개인을 재식별한다. 출력이 유출되지 않더라도 신뢰도 분포는 유출될 수 있다.

방어책: 신뢰도를 노출하지 않거나, 노출 전에 자르거나 양자화한다. 이는 (ε, δ)-DP 훈련 이상의 추가 요구사항이다.

## 사용하기

`code/main.py`는 장난감 이진 분류 데이터셋에서 DP-SGD를 시뮬레이션한다. 노이즈 승수 σ와 클리핑 노름 C를 변경하고 (ε, δ) 예산과 정확도 비용을 추적할 수 있다. "카나리 공격"은 고유한 훈련 예제를 삽입하고 로그 손실 테스트가 DP 전후에 이를 감지할 수 있는지 측정한다.

## 결과물

이 레슨은 `outputs/skill-dp-audit.md`를 생성한다. 언어 모델 배포에 대한 DP 주장이 주어지면 (ε, δ) 값, 사용된 회계사, MIA 평가 프로토콜, 신뢰도 노출 벡터가 평가되었는지 감사한다.

## 실습

1. `code/main.py`를 실행한다. σ를 {0.5, 1.0, 2.0}에서 변경하고 (ε, δ)-정확도 트레이드오프를 보고한다. 유틸리티가 붕괴되는 지점을 식별한다.

2. 카나리 삽입과 로그 손실 테스트를 구현한다. σ = 1.0에서 DP-SGD 전후의 탐지율을 측정한다.

3. Nasr et al. 2025의 훈련 데이터 추출에 관한 논문을 읽는다. 왜 추출 성공이 중간 정도의 ε에서 붕괴되지 않는가? 이것이 평가로서의 MIA에 대해 무엇을 시사하는가?

4. PMixED(arXiv:2403.15638)를 사용하여 전적으로 추론 시점에 작동하는 배포를 설계한다. PMixED가 DP-SGD가 다루지 못하는 위협 모델은 무엇인가?

5. LLM 피드백을 통한 DP 역전 공격을 개략적으로 설명한다. 신뢰도 점수 유출을 제한하는 대응책을 설계하고 배포 비용을 추정한다.
