# 다중 에이전트 RL

> 단일 에이전트 RL은 환경이 고정되어 있다고 가정한다. 같은 세계에 두 개의 학습 에이전트를 넣으면 그 가정이 무너진다: 각 에이전트는 다른 에이전트의 환경 일부이며, 둘 다 변하고 있다. 다중 에이전트 RL은 마르코프 가정이 더 이상 성립하지 않을 때 학습을 수렴하게 만드는 트릭의 집합이다.

**Type:** 구축
**Languages:** Python
**Prerequisites:** Phase 9 · 04 (Q-학습), Phase 9 · 06 (REINFORCE), Phase 9 · 07 (액터-크리틱)
**Time:** ~45분

## 문제

방을 탐색하는 로봇은 단일 에이전트 RL 문제이다. 축구 팀은 아니다. AlphaStar 대 StarCraft 상대는 아니다. 입찰 에이전트의 시장은 아니다. 4방향 정지 신호를 협상하는 두 대의 자동차는 아니다. 다대다 실제 문제는 아니다.

모든 다중 에이전트 설정에서, 어느 한 에이전트의 관점에서 다른 에이전트들은 환경의 *일부*이다. 그들이 학습하고 행동을 변경함에 따라 환경은 비정상(non-stationary)이 된다. 마르코프 속성 — "다음 상태는 현재 상태와 내 행동에만 의존한다" — 은 위반되는데, 다음 상태가 *다른* 에이전트가 선택한 것에도 의존하고, 그들의 정책은 움직이는 목표이기 때문이다.

이는 테이블 기반 수렴 증명(Q-학습의 보장은 고정 환경을 가정)을 깨뜨린다. 또한 순진한 딥 RL도 깨뜨린다: 에이전트들이 서로를 루프로 쫓으며 안정적인 정책으로 수렴하지 않는다. 다중 에이전트-특화 기술이 필요하다: 중앙 집중식 훈련 / 분산식 실행, 반사실적 기준선, 리그 플레이, 자기-대결(self-play).

2026년 응용 분야: 로봇 떼, 교통 라우팅, 자율 주행 차량 군단, 시장 시뮬레이터, 다중 에이전트 LLM 시스템(Phase 16), 그리고 하나 이상의 지능적 플레이어가 있는 모든 게임.

## 개념

![네 가지 MARL 체제: 독립, 중앙 집중식 크리틱, 자기-대결, 리그](../assets/marl.svg)

**형식주의: 마르코프 게임.** MDP의 일반화: 상태 `S`, 결합 행동 `a = (a_1, …, a_n)`, 전이 `P(s' | s, a)`, 에이전트별 보상 `R_i(s, a, s')`. 각 에이전트 `i`는 자신의 정책 `π_i` 하에서 자신의 반환값을 최대화한다. 보상이 동일하면 **완전 협력적**이다. 제로-섬이면 **적대적**이다. 혼합이면 **일반-합(general-sum)** 이다.

**핵심 도전 과제:**

- **비정상성.** 에이전트 `i`의 관점에서 `P(s' | s, a_i)`는 `π_{-i}`에 의존하며, 이는 변하고 있다.
- **신용 할당.** 공유된 보상으로, 어떤 에이전트가 이를 유발했는가?
- **탐색 조정.** 에이전트는 중복되게 같은 상태를 탐색하지 않고, 보완적인 전략을 탐색해야 한다.
- **확장성.** 결합 행동 공간은 `n`에 따라 지수적으로 증가한다.
- **부분 관측 가능성.** 각 에이전트는 자신의 관찰만 본다; 전역 상태는 숨겨져 있다.

**네 가지 지배적 체제:**

**1. 독립 Q-학습 / 독립 PPO (IQL, IPPO).** 각 에이전트는 자신의 Q 또는 정책을 학습하며, 다른 에이전트를 환경의 일부로 취급한다. 간단하며, 때로는 작동한다(특히 경험 재생이 에이전트-모델링 평활화 역할을 할 때). 이론적 수렴: 없음. 실제로: 느슨하게 결합된 작업에는 괜찮고, 밀접하게 결합된 작업에는 나쁘다.

**2. 중앙 집중식 훈련, 분산식 실행 (CTDE).** 가장 흔한 현대 패러다임. 각 에이전트는 로컬 관찰 `o_i`에 조건화된 자신의 *정책* `π_i`를 가진다 — 배포 시 표준 분산식 실행. *훈련* 중에는 중앙 집중식 크리틱 `Q(s, a_1, …, a_n)`이 전체 전역 상태와 결합 행동에 조건화된다. 예시:
- **MADDPG** (Lowe et al. 2017): 에이전트당 중앙 집중식 크리틱을 가진 DDPG.
- **COMA** (Foerster et al. 2017): 반사실적 기준선 — "다른 행동 `a'`를 취했다면 내 보상이 어땠을까?"를 물어 내 기여도를 분리.
- **MAPPO** / **IPPO** with shared critic (Yu et al. 2022): 중앙 집중식 가치 함수를 가진 PPO. 2026년 협력적 MARL에서 지배적.
- **QMIX** (Rashid et al. 2018): 가치 분해 — 단조 혼합으로 `Q_tot(s, a) = f(Q_1(s, a_1), …, Q_n(s, a_n))`.

**3. 자기-대결 (Self-play).** 동일한 에이전트의 두 복사본이 서로 대결한다. 상대의 정책은 과거 스냅샷의 내 정책이다. AlphaGo / AlphaZero / MuZero. OpenAI Five. 제로-섬 게임에 가장 잘 작동; 훈련 신호가 대칭적이다.

**4. 리그 플레이 (League play).** 일반-합 / 적대적 환경으로 자기-대결을 확장: 과거 및 현재 정책의 모집단을 유지하고, 리그에서 상대를 샘플링하여 그에 대해 훈련한다. 익스플로이터(현재 최고를 이기기 특화)와 메인 익스플로이터(익스플로이터를 이기기 특화)를 추가한다. AlphaStar(StarCraft II). 게임이 "가위-바위-보" 전략 사이클을 인정할 때 필요하다.

**통신.** 에이전트가 학습된 메시지 `m_i`를 서로 보낼 수 있게 한다. 협력 설정에서 작동한다. Foerster et al. (2016)은 미분 가능한 에이전트 간 통신이 종단간 훈련될 수 있음을 보였다. 오늘날의 LLM 기반 다중 에이전트 시스템(Phase 16)은 본질적으로 자연어로 통신한다.

## 직접 구현하기

이 레슨은 두 개의 협력 에이전트가 있는 6×6 GridWorld를 사용한다. 그들은 반대쪽 모서리에서 시작하여 공유된 목표에 도달해야 한다. 공유 보상: 한 에이전트가 아직 움직이는 동안 단계당 `-1`, 둘 다 도착하면 `+10`. `code/main.py` 참조.

### 단계 1: 다중 에이전트 환경

```python
class CoopGridWorld:
    def __init__(self):
        self.size = 6
        self.goal = (5, 5)

    def reset(self):
        return ((0, 0), (5, 0))  # 두 에이전트

    def step(self, state, actions):
        a1, a2 = state
        new1 = move(a1, actions[0])
        new2 = move(a2, actions[1])
        done = (new1 == self.goal) and (new2 == self.goal)
        reward = 10.0 if done else -1.0
        return (new1, new2), reward, done
```

*결합* 행동 공간은 `|A|² = 16`이다. 전역 상태는 두 위치이다.

### 단계 2: 독립 Q-학습

각 에이전트는 결합 상태로 키가 지정된 자신의 Q-테이블을 실행한다. 각 단계에서: 둘 다 ε-탐욕적 행동을 선택하고, 결합 전이를 수집하며, 각각 공유 보상으로 자신의 Q를 업데이트한다.

```python
def independent_q(env, episodes, alpha, gamma, epsilon):
    Q1, Q2 = defaultdict(default_q), defaultdict(default_q)
    for _ in range(episodes):
        s = env.reset()
        while not done:
            a1 = epsilon_greedy(Q1, s, epsilon)
            a2 = epsilon_greedy(Q2, s, epsilon)
            s_next, r, done = env.step(s, (a1, a2))
            target1 = r + gamma * max(Q1[s_next].values())
            target2 = r + gamma * max(Q2[s_next].values())
            Q1[s][a1] += alpha * (target1 - Q1[s][a1])
            Q2[s][a2] += alpha * (target2 - Q2[s][a2])
            s = s_next
```

보상이 조밀하고 정렬되어 있기 때문에 이 작업에서 작동한다. 밀접하게 결합된 작업(예: 한 에이전트가 다른 에이전트를 *기다려야* 하는 경우)에서는 실패한다.

### 단계 3: 분해된 가치 업데이트를 통한 중앙 집중식 Q

결합 행동에 대해 하나의 Q 사용 `Q(s, a_1, a_2)`. 공유 보상으로 업데이트. 실행 시 주변화하여 분산: `π_i(s) = argmax_{a_i} max_{a_{-i}} Q(s, a_1, a_2)`. 지수적 결합 행동 공간을 *올바른* 전역 관점과 교환한다.

### 단계 4: 간단한 자기-대결 (적대적 2-에이전트)

동일한 에이전트, 두 역할. 에이전트 A를 에이전트 B에 대해 훈련; `K` 에피소드 후, A의 가중치를 B에 복사. 대칭적 훈련, 일관된 진행. AlphaZero 레시피의 축소판.

## 함정

- **비정상 재현.** 독립 에이전트를 사용한 경험 재현은 단일 에이전트보다 나쁘다. 해결: 재레이블링 또는 최신성에 따른 가중치 부여.
- **신용 할당 모호성.** 긴 에피소드 후 공유 보상; 어떤 에이전트가 기여했는지 명확한 방법 없음. 해결: 반사실적 기준선(COMA), 또는 에이전트당 보상 형태 지정.
- **정책 드리프트 / 추적.** 각 에이전트의 최상의 응답은 다른 에이전트의 업데이트와 함께 변한다. 해결: 중앙 집중식 크리틱, 느린 학습률, 또는 한 번에 하나씩 동결.
- **조정을 통한 보상 해킹.** 에이전트가 설계자가 예상하지 못한 협력적 익스플로잇을 찾는다. 경매 에이전트가 0에 입찰하도록 수렴. 해결: 신중한 보상 설계, 행동 제약.
- **탐색 중복.** 두 에이전트 모두 동일한 상태-행동 쌍을 탐색. 해결: 에이전트당 엔트로피 보너스, 또는 역할 조건화.
- **리그 사이클.** 순수 자기-대결은 지배 사이클에 갇힐 수 있다. 해결: 다양한 상대를 가진 리그 플레이.
- **샘플 폭발.** `n` 에이전트 × 상태 공간 × 결합 행동. 함수 근사로 근사; 분해된 행동 공간(에이전트당 하나의 정책 출력 헤드).

## 연습문제

1. **쉬움.** 2-에이전트 협력적 GridWorld에서 독립 Q-학습을 훈련하라. 평균 반환값이 > 0이 될 때까지 몇 에피소드가 필요한가? 결합 학습 곡선을 플롯하라.
2. **중간.** "조정" 작업 추가: 두 에이전트가 동시에 목표에 도달해야만 목표에 도달한 것으로 간주. 독립 Q가 여전히 수렴하는가? 무엇이 깨지는가?
3. **어려움.** MAPPO-스타일 훈련을 위한 중앙 집중식 크리틱을 구현하고 조정 작업에서 독립 PPO와 수렴 속도를 비교하라.

## 주요 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|-----------------|-----------------------|
| 마르코프 게임 | "다중 에이전트 MDP" | `(S, A_1, …, A_n, P, R_1, …, R_n)`; 각 에이전트는 자신의 보상을 가짐. |
| CTDE | "중앙 집중식 훈련, 분산식 실행" | 훈련 시간에 결합 크리틱; 각 에이전트의 정책은 로컬 관찰만 사용. |
| IPPO | "독립 PPO" | 각 에이전트가 PPO를 별도로 실행. 간단한 기준선; 종종 과소평가됨. |
| MAPPO | "다중 에이전트 PPO" | 전역 상태에 조건화된 중앙 집중식 가치 함수를 가진 PPO. |
| QMIX | "단조 가치 분해" | `Q_tot = f_monotone(Q_1, …, Q_n)`으로 분산 argmax 가능. |
| COMA | "반사실적 다중 에이전트" | 이점 = 내 Q에서 내 행동을 주변화한 예상 Q를 뺀 값. |
| 자기-대결 | "에이전트 vs 과거 자기" | 단일 에이전트, 두 역할; 제로-섬 게임의 표준. |
| 리그 플레이 | "모집단 훈련" | 과거 정책 캐싱, 풀에서 상대 샘플링; 전략 사이클 처리. |

## 추가 자료

- [Lowe et al. (2017). Multi-Agent Actor-Critic for Mixed Cooperative-Competitive Environments (MADDPG)](https://arxiv.org/abs/1706.02275) — 중앙 집중식 크리틱을 가진 CTDE.
- [Foerster et al. (2017). Counterfactual Multi-Agent Policy Gradients (COMA)](https://arxiv.org/abs/1705.08926) — 신용 할당을 위한 반사실적 기준선.

- [Yu et al. (2022). The Surprising Effectiveness of PPO in Cooperative Multi-Agent Games (MAPPO)](https://arxiv.org/abs/2103.01955) — PPO는 MARL에 놀라울 정도로 강력함.
- [Vinyals et al. (2019). Grandmaster level in StarCraft II using multi-agent reinforcement learning (AlphaStar)](https://www.nature.com/articles/s41586-019-1724-z) — 대규모 리그 플레이.
- [Silver et al. (2017). Mastering the game of Go without human knowledge (AlphaGo Zero)](https://www.nature.com/articles/nature24270) — 제로-섬 게임에서 순수 자기-대결.

- [Zhang, Yang & Başar (2021). Multi-Agent Reinforcement Learning: A Selective Overview](https://arxiv.org/abs/1911.10635) — 수렴 결과와 함께 협력적, 경쟁적 및 혼합 MARL을 다루는 서베이.
