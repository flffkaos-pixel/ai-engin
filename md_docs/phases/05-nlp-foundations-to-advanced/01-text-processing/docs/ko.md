# 텍스트 처리 — 토큰화, 정규화, 정제

> 텍스트는 정돈되지 않았습니다. 전처리 없이 모델에 투입하면 혼란이 나옵니다.

**유형:** 빌드 | **언어:** Python | **시간:** ~45분

## 개념
- 토큰화: 텍스트 → 단어/서브워드 단위 분할
- 정규화: 소문자화, 불용어 제거, 어간 추출/표제어화
- 정제: HTML 태그, 특수 문자, 이모지 처리

## 빌드
```python
import re
def clean(text):
    text = re.sub(r'<[^>]+>', '', text)  # HTML 제거
    text = re.sub(r'[^\w\s]', '', text)  # 특수문자 제거
    return text.lower()
```
