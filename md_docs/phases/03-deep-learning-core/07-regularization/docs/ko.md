# 정규화

> 모델이 훈련 데이터를 너무 사랑할 때, 정규화가 개입합니다.

**유형:** 빌드
**언어:** Python
**선수 과목:** Lesson 03.03
**시간:** ~75분

## 개념

### L1 / L2 정규화

- **L2 (Ridge)**: `loss += λΣw²` — 모든 가중치 축소, 0 근처로
- **L1 (Lasso)**: `loss += λΣ|w|` — 희소성, 작은 가중치 → 정확히 0

### 드롭아웃

훈련 시 랜덤 뉴런 비활성화(p 비율). 각 미니배치마다 다른 하위 네트워크 → 앙상블 효과. 추론 시 모든 뉴런 활성화, 출력에 (1-p) 곱함.

일반적 p: 입력층 0.2, 은닉층 0.5.

### 조기 종료

검증 오차가 증가하기 시작하면 훈련 중단. 최고 검증 성능 가중치 저장.

### 배치 정규화

각 레이어 출력을 평균 0, 표준편차 1로 정규화 → 내부 공변량 이동 감소 → 더 높은 학습률 가능, 드롭아웃 의존도 감소.

## 빌드하기

```python
def dropout(X, p=0.5, training=True):
    if not training: return X * (1 - p)
    mask = np.random.binomial(1, 1-p, X.shape) / (1-p)
    return X * mask

# L2 정규화
l2_loss = lambda w, lam: lam * np.sum(w**2)
```

## 주요 용어

| 용어 | 실제 의미 |
|------|----------|
| 드롭아웃 | 랜덤 비활성화 → 앙상블 효과 |
| L2 정규화 | 큰 가중치 페널티 → 일반화 |
| 배치 정규화 | 활성화 정규화 → 안정적 훈련 |
