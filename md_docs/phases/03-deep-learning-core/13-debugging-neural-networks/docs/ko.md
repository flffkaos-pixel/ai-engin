# 신경망 디버깅

> 신경망은 조용히 실패합니다. 충돌하지 않고 쓰레기를 출력합니다.

**유형:** 빌드
**언어:** Python
**선수 과목:** Lesson 03.01~12
**시간:** ~90분

## 개념

### 체계적 디버깅

1. **데이터 확인**: 형태, 범위, NaN, 클래스 분포
2. **순전파**: 단일 배치로 과적합 가능한지 확인 (loss → 0)
3. **기울기 확인**: 수치 기울기 vs 해석적 기울기
4. **활성화 통계**: 각 레이어의 평균/std 히스토그램
5. **학습 곡선**: train/val loss 그래프

### 일반적인 문제

| 증상 | 원인 | 해결책 |
|------|------|--------|
| loss NaN | 발산 학습률 | lr 감소, 기울기 클리핑 |
| loss 진동 | lr 너무 큼 | lr 감소, 배치 크기 증가 |
| loss 평탄 | lr 너무 작음/죽은 ReLU | lr 증가, LeakyReLU |
| val loss 증가 (train 감소) | 과적합 | 정규화, 데이터 증강 |
| train/val 모두 높음 | 과소적합 | 더 큰 모델, 더 많은 epoch |

### 기울기 확인

```python
# 수치 기울기
def numerical_grad(f, x, eps=1e-5):
    grad = np.zeros_like(x)
    for i in range(len(x)):
        x[i] += eps
        f_plus = f(x)
        x[i] -= 2*eps
        f_minus = f(x)
        x[i] += eps
        grad[i] = (f_plus - f_minus) / (2*eps)
    return grad
```

### 활성화 통계

각 레이어 후 평균, 표준편차, 0 비율 기록 → 기울기 소실/폭발 식별.
